## SECTION A — 精确命题

### A1 移相锁乘积定理（Shifted-Lock Product Theorem）
任取 τ > 0，令 t = τ/(b+c)。则
- at = τ/s
- bt = τθ
- ct = τ − τθ
- dt = τw

所以 t 成功，当且仅当 (s, r, w) ∈ **𝒜_τ × ℛ_τ × 𝒲_τ**，其中
- 𝒜_τ = {s : frac(τ/s) ∈ A}
- ℛ_τ = {r : frac(τθ) ∈ A 且 frac(τ − τθ) ∈ A}
- 𝒲_τ = {w : frac(τw) ∈ A}

**τ = k ∈ ℤ 时就是 LB(k)**：此时 frac(τ − τθ) = 1 − frac(kθ)，c 的条件由 b 的条件自动推出。每个 𝒜_k、ℛ_k、𝒲_k 都是闭区间的有限并（在有界范围内），所以 LB(k) 就是 R009 中盒子 LB(k; m_a, m_b, m_d) 的并。

### A2 障碍定理（Integer-w Obstruction）
若 d = j(b+c)，j ∈ ℤ，则对**每个** k ∈ ℤ，t = k/(b+c) 都有 dt = jk ∈ ℤ，所以 ‖dt‖ = 0。
在 Ω 中，w = j 只可能取 j ∈ {1, 2, 3}，而且三张曲面都与 Ω 相交（见 §B2）。

**推论**：设 𝓑 是有限个 LB 闭盒的并。则 𝓑 与曲面 {w = j} 不相交，所以存在开集 U ⊃ {w = j} ∩ Ω，使 U ∩ 𝓑 = ∅。

### A3 半锁盒 HB = 移相锁 τ = 3/2
若 15/8 ≤ s ≤ 15/2，r ∈ (1, 8/7] ∪ [4, 13/2]，且 4/5 ≤ w ≤ 6/5，则 **t = 3/(2(b+c))** 成功。

### A4 接通区域 C₁ 与选择规则
令 C₁ = Ω ∩ {15/8 ≤ s ≤ 5，1 < r ≤ 8/7，4/5 ≤ w ≤ 9/5}。对 C₁ 中的任意点：
- 若 frac(w) ∈ [1/5, 4/5]，输出 **t = 1/(b+c)**（LB(1)）；
- 否则输出 **t = 3/(2(b+c))**（HB）。

两种输出都成功。整个判断是一次比较，不搜索。

## SECTION B — 证明

### B1 A1
直接代入：bt + ct = τ，dt = τ·d/(b+c) = τw，at = τa/(b+c) = τ/s。成功 ⟺ 四个小数部分都落在 A 内 ⟺ 三个独立条件同时成立。∎

### B2 A2 与曲面和 Ω 相交
第一部分已在命题中证明。
**相交**：取 a = 1，d = j(b+c)。Ω 需要 4 < d < 4c：
- d > 4 ⟺ s > 4/j；
- d < 4c ⟺ j(b+c) < 4c ⟺ j(1 + 1/r) < 4，j = 1, 2, 3 分别要求 r > 1/3、r > 1、r > 3。
- 还需要 d > c，即 j(b+c) > c，对 j ≥ 1 自动成立。

每个 j 都有满足条件的点，例如：
- j=1：(1, 3, 4, 7)，s = 7，r = 4/3
- j=2：(1, 2, 3, 10)，s = 5，r = 3/2；核对 4 < 10 < 12 ✓
- j=3：(1, 1.2, 4, 15.6)，r = 10/3 > 3，s = 5.2，d = 15.6 < 4c = 16 ✓

**推论的证明**：有限个闭集的并是闭集；它不含曲面上的点，所以该点有一个邻域与它不相交。∎

**实例 (1,3,4,7)**：w = 7/7 = 1。对 k = 1, …, 7，‖7·k/7‖ = 0；又因速度都是整数、周期为 1，所以所有 k 都失败。这一组速度并非无解：t = 1/5 时四个距离为 1/5, 2/5, 1/5, 2/5。成功时间 1/5 = τ/(b+c) 对应的是 τ = 7/5，不是整数。

### B3 A3（半锁盒）
t = 3/(2(b+c))，τ = 3/2。
- **a**：at = 3/(2s) ∈ [1/5, 4/5] ⟺ 15/8 ≤ s ≤ 15/2。✓
