二、精确命题

记 ||x|| 为 x 到最近整数的距离。m≥2，正速度为 v₁,…,vₘ。

假设（Hₘ）：对任意至多 m−1 个互异正整数 b，存在可取得的 τ>0，使每个 ||bτ||≥1/m。若已有相应的 F₂,…,Fₘ，这个假设成立，因为更低人数给出的门槛至少为 1/m。

假设速度的有理秩 r=dim_Q span_Q{v₁,…,vₘ}≥2。清除有理系数分母后，可写成

[
v_i=a_i\cdot\alpha,\qquad a_i\in\mathbb Z^r\setminus{0},
]

其中 α₁,…,αᵣ 在 Q 上线性无关；各行 aᵢ 的有理秩为 r。

结论： 存在有限 t>0，使

[
\min_i|v_i t|>\frac1{m+1}.
]

更精确地，任意 ε>0 都可找到 t>0，使最小距离大于 1/m−ε。这里说的是可任意接近的下界，不声称 1/m 一定能在某个实际时间达到。

三、核心合并引理及证明

引理。 对秩至少为 2 的有限非零整数行向量 a₁,…,aₘ，存在整数向量 w，使

[
b_i=a_i\cdot w\ne0\quad(\forall i),
\qquad |b_p|=|b_q|\quad(p\ne q).
]

因此 |b₁|,…,|bₘ| 至多有 m−1 种取值。

证明。

1. 选一个有理二维线性投影 P，使每个 Paᵢ 非零，并且原来不平行的任意一对，投影后仍不平行。这样的 P 存在：每个禁忌都是一个非零多项式的零集；有限个非零多项式的乘积不能在所有有理点消失。
  这里还可给出有限生成方法。把每个非零条件写为 ||Paᵢ||₂²≠0，把每个不平行条件写为 det(Paᵢ,Paⱼ)≠0。乘积的总次数至多 D=m(m+1)。逐个取 P 的 2r 个整数元素于 {0,…,D}，必有一个使乘积非零。理由是：每个变量次数至多 D 的非零多项式，不可能在这个完整网格上恒为零；逐变量用一元根数界即可证明。
2. 把所有 ±Paᵢ 的不同射线按圆周顺序排列，取相邻两条。因为集合中心对称，且不全在一条直线上，相邻夹角严格小于 π。取对应的带符号原行 u=±aₚ、v=±a_q；它们的投影之和位于两射线之间的内部，而这个内部没有任何 ±Paᵢ 射线。
3. 因而 g=u+v 非零，且不与任何 aᵢ 平行。在有理超平面 g⊥ 中，每个 aᵢ⊥ 的交集都是一个真子空间。有限个这样的真子空间不能覆盖整个 g⊥，所以存在有理 w∈g⊥，使所有 aᵢ·w≠0；清分母取得整数 w。
  这一步同样可以有限生成：取 g⊥ 的整数向量有理基 u₁,…,uᵣ₋₁，令 w(s)=u₁+su₂+⋯+s^(r−2)uᵣ₋₁。每个 aᵢ·w(s) 都是非零多项式，次数至多 r−2。因此 s=0,…,m(r−2) 中至少一个避开全部零点。
4. 从 g·w=0 得到带符号的两行投影互为相反数。由于 u、v 各自可能换过号，换回原行得到 bₚ=±b_q，故 |bₚ|=|b_q|。同时所有 bᵢ 都非零。证毕。

四、从合并到安全时间

对上面的整数 bᵢ，删除重复绝对值。剩下的不同正整数至多 m−1 个。由 Hₘ 取得 τ>0，使

[
|b_i\tau|\ge\frac1m\quad(\forall i).
]

定义相位目标 x*=τw mod 1∈Tʳ，则

[
|a_i\cdot x^*|\ge\frac1m.
]

取

[
\gamma=\frac1{m(m+1)},\qquad
B=\max_i\sum_j|a_{ij}|,\qquad
\eta=\frac{\gamma}{2B}.
]

若实际时间满足各坐标 ||tαⱼ−x*ⱼ||<η，便有

[
|v_i t|>\frac1m-B\eta
=\frac1{m+1}+\frac\gamma2.
]

因此只须保证原来的连续时间轨迹进入这个相位盒。下面直接证明，并给出有限上界；不把轨道稠密性当作未经说明的跳步。

相位盒必被命中：独立积分证明

设 0<η<1/2，定义周期三角帽函数

[
h_\eta(x)=\max{1-|x|/\eta,0},\qquad
H(t)=\prod_{j=1}^r h_\eta(\alpha_jt-x_j^*).
]

H(t)>0 恰好表示进入上述开盒。三角帽等于长度 η 的区间指示函数与自身的周期卷积再除以 η。直接积分得到傅里叶系数

[
c_0=\eta,\qquad
c_k=\frac{\sin^2(\pi k\eta)}{\eta\pi^2 k^2}\quad(k\ne0).
]

系数非负且绝对可和，和为 hη(0)=1。因此 H 的多重级数绝对且一致收敛，可以逐项积分。由于 α 的有理线性无关，对任意非零整数向量 q，都有 q·α≠0，而

[
\left|\frac1T\int_0^T e^{2\pi i(q\cdot\alpha)t},dt\right|
\le\frac1{\pi T|q\cdot\alpha|}\longrightarrow0.
]

所以 H 的时间平均趋于常数项 ηʳ>0。必有有限 t>0 使 H(t)>0。

这里不存在“只在轨道闭包中安全，实际时间仍碰不到”的等号漏洞：目标自带严格正余量，使用的是一个开盒。

可核查的有限上界与提取

取

[
K=\left\lceil\frac{8r}{\eta^{r+1}}\right\rceil,
\quad
\mu=\min_{0<|q|_\infty\le K}|q\cdot\alpha|>0,
\quad
T=\frac8{\mu\eta^r}.
]

在多重傅里叶和中，至少一坐标超出 K 的系数绝对值总和至多

[
\frac{2r}{\pi^2\eta K}<\frac{\eta^r}4.
]

剩下的非零频率对时间平均的贡献绝对值至多 1/(πμT)<ηʳ/8。故

[
\frac1T\int_0^T H(t)dt>\frac58\eta^r.
]

令 L=(Σⱼ|αⱼ|)/η。由乘积的差分界，H 是 L-Lipschitz 连续函数。取

[
M=\left\lceil\frac{8LT}{\eta^r}\right\rceil,
\qquad t_j=jT/M\quad(0\le j\le M).
]

区间内某一点 H 大于 5ηʳ/8；距离它小于等于 T/M 的网格点满足 H>ηʳ/2。因此有限网格必能提取实际安全时间。t₀=0 不会入选，因为原始各速度在 t=0 的相位都为零，而盒内的距离严格大于目标门槛。

计算型输入可以使用经认证的有理下界 0<μ₀≤μ，以及有理上界 L₀≥L，分别代入 T、M。这样网格时间本身可取有理数。逐项计算 H 至误差小于 ηʳ/16，选择估计值超过 3ηʳ/8 的点，必能成功且不需判断端点等号。

范围说明： 上界可能极大；这个提取器是有终止保证的有限搜索，尚非最终要求的免扫描直接构造。它的作用是闭合“存在相位目标→有限实际时间”的证明链。

五、精确算例：四组不可公度速度

输入

[
V=(1,\sqrt2,1+\sqrt2,1+2\sqrt2).
]

取 α=(1,√2)，四行分别是 (1,0)、(0,1)、(1,1)、(1,2)。令 w=(1,−2)，得到整数速度

[
Aw=(1,-2,-1,-3).
]

绝对值合并为 {1,2,3}，取 τ=1/4 即有距离至少 1/4。相位目标是 (1/4,1/2)。

这个目标可明确靠近。取

[
\boxed{t=41/4}.
]

下列有理夹逼由平方直接验证：

[
(707/500)^2<2<(283/200)^2.
]

因此 y=(41√2/4) mod 1 满足

[
987/2000<y<403/800.
]

四个相位依次为 1/4、y、1/4+y、(1/4+2y) mod 1。对应的最近整数距离分别至少为

[
1/4,\quad987/2000,\quad197/800,\quad237/1000.
]

全部严格大于 1/5。这是直接可核验的实际正时间。算例只展示机制，不作为普遍定理的替代证据。

六、它怎样缩小工作面

1. 五人非空性。 若合并引理和转回时间的证明通过，五人的不可公度输入全部有正长安全区间；零测度或孤立安全点的难关，在五人情形只能落在可公度输入中。这里采用项目 F₂、F₃、F₄ 作为前提。
2. 可公度核心。 若所有 vᵢ/v₁ 都是有理数，清分母并除去公因子后，写成 vᵢ=c aᵢ，其中 aᵢ 为正整数且 gcd(a₁,…,aₘ)=1。安全时间由整数问题的 s 换算成 t=s/c。五人的未决非空性核心因而可集中成四个互异正整数的命题。
3. 逐人数的关系。 每完成一个人数的整数核心，可以解决同人数的可公度输入，并经本机制打开下一人数的不可公度输入。超过当前人数仍须相应的整数前提；本稿不把五人的结论推广成任意人数已证。
4. 直接性。 上述有限提取仍须升级。即使把五人非空性全部关上，也不能自动宣布最终 Time Forge 统一直接公式完成。

本机制为何在有理秩 1 停住也很清楚：此时所有非零一维投影都保留原整数速度的比例，不能额外合并两种不同的绝对速度。缺少的正是第二个相位方向。
