先说结论。不要再交一个新的覆盖盒子，也不要再数要检查几次。T4 已经能对任意三个正速度交出一个时间。下一跑者要的不是把这个点轻轻推开，而是从这个点交出一段区间。点推不动的时候，公式应该停下来写 UNFINISHED，而不是换成扫描。
1. 最有价值的一步
两块已经能接上，但还不是公式。T4 负责生成：任意 0 < a < b < c，交出 t0。征询信第 6 页的提取式负责从一段已知安全区间里读出一个时间。缺的是中间这一段：从 T4 的点变成一段区间。LN 是「推一下就够」的已证特例，不是这条路的尽头。
2. 瓶颈
卡住的命题可以写死：
给定 t0 = T4(a,b,c)。新速度 d 若离 1/5 太远，把 d t0 推到最近的 1/5 格点，移动量是 Δ = (1/5 − ‖d t0‖) / d。旧跑者保得住，当且仅当 c Δ 不超过 t0 处多出来的余量。余量常常正好是 1/4 − 1/5 = 1/20。d 不够快时，这一推会把旧跑者推破。这时安全时间仍然可能存在，只是它不是 t0 附近的那一下。
隐藏假设是：把一个点交给下一位跑者就够了。这个假设已经被下面的例子否定。它否定的是「单点微调」这条规则，不是五跑者本身，也不是最终的统一公式。
3. 继续什么，停下什么
继续把 T4 的八个分支从「一个点」改成「一段有公式的区间」。LN 保留。d ≥ 4c 只是充分条件；真正该检查的是上面的 c Δ。这仍是证明候选，不是新认证。
停下新的速度盒子、枚举选择器和检查次数。信里已经把计数差异冻结了。再数一次不会变出公式。
不要停目标。也不要用把全部分量扫一遍来代替公式。存在性和直接构造不是同一件事。
4. 机制 SLOT
状态：IDEA。只对总人数五、门槛 1/5，0 < a < b < c < d。
	•	t0 = T4(a,b,c)。
	•	若 ‖d t0‖ ≥ 1/5，输出 t0。
	•	否则令 k 为离 d t0 最近的整数，σ 为余数的符号，t1 = (k + σ/5) / d，Δ = |t1 − t0|。
	•	若 c Δ ≤ min{‖a t0‖, ‖b t0‖, ‖c t0‖} − 1/5，输出 t1。
	•	否则输出 UNFINISHED。不扫描，不另猜一个时间。
5. 它交出什么，还欠什么
交得出时间时，就是 t0 或 t1，都是封闭算式。欠的证明是：八个分支里，c Δ 太大的那一支，各自再给一段显式区间，让第 6 页的提取式对 u = d 成功。最弱的地方是等号：旧距离正好 1/4 时，余量正好 1/20，点的两侧不一定都还有空隙。
