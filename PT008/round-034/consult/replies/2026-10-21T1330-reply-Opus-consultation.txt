### Q4　我自己的机制

**M1　地标选择（landmark selection）与最左安全时间**
- **地标**：λ_{i,q} = (q + 1/n)/v_i，即第 i 位跑者刚跑完 q 圈再多 1/n 圈的时刻。
- **定理（§3.1）**：若安全时间存在，每个安全分量的左端点都是地标，最左安全时间 τ_n 也是地标。
- **操作规则（跳跃迭代）**：t₀ = 0；只要有跑者 i 在坏区（‖v_i t‖ < 1/n），就令 t ← max_{坏的 i} (round(v_i t) + 1/n)/v_i；没有坏跑者时停下，输出 t = τ_n。
- **性质**：规范（canonical）——同一输入只有一个输出；尺度等变 τ(λv) = τ(v)/λ；不必先求出全部分量再扫描，每步只算 n − 1 个数（下文穷举中最多 21 步）。
- **最小非平凡推导**：(1, 2, 3, 41/10)，δ = 1/5：0 → 1/5（v₁ 的地标，q=0）→ 12/41（v₄ 的地标，q=1）→ 2/5（v₃ 的地标，q=1），停。τ = 2/5，各距离 (2/5, 1/5, 1/5, 9/25)，有两处等号。
- **"ONE FORMULA FOR ALL" 因此可以这样写**：所有 n 共用一行公式 t = (q + 1/n)/v_i；全部难度在于**选择子（selector）** σ_n(v) = (i, q)。τ_n 给出最自然的一个选择子；它对一切 n 都可计算——**当且仅当** LRC_n 成立。

**M2　分支定理与局部显式公式**

- **F_loc（§3.3）**：极值射线附近、对**所有 n** 成立的显式双分支公式。在盒子 |v_i − i| ≤ 1/(2n) 内（及其正倍数锥上）：
  - 若 v_{n−1} ≤ (n−1)·v₁：F_loc(v) = 1/(n·v₁)；
  - 否则：F_loc(v) = (n−1)²/(n·v_{n−1})。
- **LOC2（§3.3）**：每个带"简单孤立点"的紧实例附近，同型的双分支地标公式成立。结合 NO-CONT′：**这些紧实例处，局部最少分支数恰为 2**。普查到的 8 个紧实例已全部 CHECKED。

**M3　半门槛全局锻造（TF-½）**
- **定理（§3.4）**：对一切 n 与一切正实数速度，门槛 1/(2n) 的最左安全时间满足 τ_½ ≤ ((n+1)/(2n))·Σ_i 1/v_i，跳跃迭代在 ((n+1)/(2n))(Σ1/v_i)(Σv_i) + n − 1 步内精确算出。

## 3　证明（全部 PROOF CANDIDATE）

记 k = n − 1，δ ∈ (0, 1/2]，S_δ(v) = {t > 0 : ‖v_i t‖ ≥ δ，∀i}。坏区 B_i = {t : ‖v_i t‖ < δ} = ∪_q ((q−δ)/v_i, (q+δ)/v_i) 是开集，所以 S_δ(v) 是闭集；在任何有界时间窗内，S_δ(v) 是有限个闭区间之并。

### 3.1　COLLAPSE（归一引理）：生成与有限完成归结为存在性

**引理 1（地标性）**　若 S ≠ ∅，则 τ := min S 存在，并且每个安全分量的左端点（含 τ）都形如 (q + δ)/v_i，q ≥ 0 为整数。

*证明*：t < δ/v_min 时最慢的跑者有 ‖v_min t‖ = v_min t < δ，故 S ⊂ [δ/v_min, ∞)；S 闭，下确界可达。设 L 为某分量的左端点。L 左侧邻近的点都不安全，而速度只有有限个，故有某个 i，使 L 左侧任意近处都有 i 的坏点。B_i 开且 L ∉ B_i，于是 ‖v_i L‖ = δ。若 v_i L ≡ −δ (mod 1)，则 L 左侧近处 ‖v_i t‖ > δ，矛盾；所以 v_i L ≡ +δ，即 v_i L = q + δ；由 L > 0 得 q ≥ 0。∎

**引理 2（跳跃迭代）**　t₀ = 0；若 t_j 处有坏跑者，令 t_{j+1} = max_{i 坏} (round(v_i t_j) + δ)/v_i。则
(a) t_j 严格递增，且 [t_j, t_{j+1}) ∩ S = ∅；
(b) 若 S ≠ ∅，迭代至多 Σ_i (v_i τ + 1) 步就停在 τ；
(c) 若 S = ∅，迭代永不停止，且 t_j → ∞。

*证明*：(a) 若 i 在 t_j 处坏，取 q = round(v_i t_j)，则坏区 ((q−δ)/v_i, (q+δ)/v_i) 覆盖 [t_j, (q+δ)/v_i)；取最大的那个右端，[t_j, t_{j+1}) 的每一点都被同一个坏区覆盖。(b) 由 (a) 归纳得 t_j ≤ τ；j ≥ 1 时 t_j 是 (0, τ] 中的地标，这样的地标对每个 i 至多 ⌊v_i τ − δ⌋ + 1 个；严格递增的序列只能取有限个值。停下时没有坏跑者，即 t_J ∈ S，又 t_J ≤ τ = min S，故 t_J = τ。(c) 有界区间内地标有限，严格递增的地标序列不可能收敛。∎

**推论（四个瓶颈归一）**
- **②生成性 ⟸ ①**：存在性一旦成立（不论用什么证明），τ_n 就由引理 2 精确生成。
- **③ 拆成两件**：③a"确定且有限完成"⟸ ①；③b"步数只依赖 n 的均匀复杂度"是额外性质——半门槛下已可达（§3.5），精确门槛下未知，且蕴含 ①。
- **④推广性**：τ_n 的定义与算法对一切 n、一切实数速度统一；唯一依赖 n 的是 ①_n。
- **计算模型**：见 §3.2 推论——必须精确。

### 3.2　NO-CONT′：必需分支的位置恰为紧实例集

**定义**　v* 称为**紧实例**，若 S_δ(v*) ≠ ∅ 且其中每一点都是孤立点（等价于测度为零，即 MZ-ZERO）。**选择子**：定义在 v* 的某邻域 U 上、满足 F(v) ∈ S_δ(v) 的函数 F。

**定理**（n ≥ 3，δ = 1/n）
(i) 若 v* 是紧实例，则任何选择子都在 v* 处不连续。
(ii) 若 S_δ(v*) 有内点，且 U 上存在选择子，则存在一个在 v* 处连续的选择子。
因此（在选择子存在的前提下）"所有选择子都在该点不连续"的点集，恰为紧实例集。

*证明 (i)*：设 F 在 v* 连续，t₀ = F(v*)。t₀ 是孤立点。用引理 1 的论证分别看左右两侧：存在速度 a 使 v*_a t₀ ≡ +δ（左侧紧），存在速度 b 使 v*_b t₀ ≡ −δ（右侧紧）；因 δ < 1/2，+δ ≢ −δ，故 a ≠ b。（这正是 LM 所说的"两速度算术结构"。）令 v(ε) = v* − ε·e_a。对充分小的 |s| < η 与 0 < ε < ε₀：
- 速度 b 不变：‖v*_b (t₀ + s)‖ ≥ δ ⟺ s ≤ 0；
- 速度 a：(v*_a − ε)(t₀ + s) ≡ δ + v*_a s − ε(t₀ + s)，安全 ⟺ v*_a s ≥ ε(t₀ + s) > 0，从而 s > 0。

两者矛盾，所以 v(ε) 在 (t₀ − η, t₀ + η) 内没有安全时间；但连续性要求 F(v(ε)) → t₀。∎

*证明 (ii)*：在内部取 t₁ 使所有 ‖v*_i t₁‖ > δ（等号点是离散的，可以避开）；有限个严格不等式在 v* 附近保持成立，所以在一个小球内令 F ≡ t₁，球外用任一选择子即可。∎

**推论 1（固定精度必败）**　若一个算法只通过舍入值 r(v) 读入，且在 v* 的某邻域内 r(v) = r(v*)（例如 v* 是整数，可精确表示），则它在 v*，或在任意近的某个 v 上，输出不安全时间。
*证明*：邻域内输出恒为 t̂。若 t̂ 对 v* 不安全，已经出错；否则 t̂ 是孤立点，取其左侧紧速度 a，令 v = v* − ε·e_a，0 < ε < δ/(2t̂)，则 ‖(v*_a − ε) t̂‖ = δ − ε t̂ < δ。∎

**推论 2（可计算分析，computable analysis；证明草图）**　即使允许自适应精度、甚至允许多值输出，只读近似值的算法也不能在任何紧实例的邻域内总是正确：它读完有限个近似值后就必须承诺一个很小的输出窗口，而与这些近似值相容的输入里，同时包含"t₀ 附近没有安全点"的 v(ε)。

**极值点数据（CHECKED，§4.2）**　V* = (1, …, n−1) 处 τ = 1/n。把 v₁ 降低 10⁻⁶ 后，t₀ ± δ/4 内安全分量数为 0，τ 跳到 j/n，其中 j 是大于 1 的最小的与 n 互素的整数（n = 4 跳到 3/4，n = 10 跳到 3/10，n = 47 跳到 2/47）；把 v₁ 升高 10⁻⁶，τ 连续地停在约 1/n。

### 3.3　局部显式公式：F_loc（全 n）与 LOC2（每个紧实例）

**命题 F_loc**　n ≥ 2，盒子 B_n = {v : |v_i − i| ≤ 1/(2n)，i = 1, …, n−1}。定义
- 分支 A（v_{n−1} ≤ (n−1)·v₁）：t = 1/(n·v₁)，即地标 λ_{1,0}；
- 分支 B（v_{n−1} > (n−1)·v₁）：t = (n−1)²/(n·v_{n−1})，即地标 λ_{n−1, n−2}。

则对一切 i 都有 ‖v_i t‖ ≥ 1/n。F_loc 是 −1 次齐次的，所以在锥 {λv : v ∈ B_n，λ > 0} 上同样成立。

*证明要点*（ε = 1/(2n)，k = n − 1）：
- 分支 A：v₁t = 1/n（等号）；v_k t ≤ k/n = 1 − 1/n 来自分支条件，且 v_k t ≥ (k − ε)/(n(1 + ε)) ≥ 1/n；中间 2 ≤ i ≤ k − 1：|v_i t − i/n| ≤ (1 + i)ε/(n(1 − ε)) < 1/n，而 i/n ∈ [2/n, 1 − 2/n]。
- 分支 B：v_k t = (n−1)²/n = (n − 2) + 1/n（等号）；v₁t < k/n = 1 − 1/n 来自分支条件，且 v₁t ≥ k²(1 − ε)/(n(k + ε)) ≥ 1/n；中间 i：目标 ik/n ≡ −i/n，距离 ≥ 2/n，误差 ≤ (k/n)(k + i)ε/(k − ε) ≤ 1/n，只需 ε ≤ k/(2k² − k + 1)，而 1/(2n) 满足它。∎

CHECKED：n = 2…47 共 7014 个点（含 n ≤ 12 时盒子的全部顶点），0 失败；盒子半径放大到 2/(2n) 起开始出现失败——它确实是局部公式。

**命题 LOC2（证明草图）**　设 v* 是整数紧实例，t₀ ∈ (0, 1) 是一个**简单孤立点**：恰有一个左侧紧速度 a（a t₀ ≡ +δ）和一个右侧紧速度 b（b t₀ ≡ −δ）。整数速度有**镜像对（mirror pair）**对称 t ↦ 1 − t，在点 1 − t₀ 处两个紧速度互换。记相对扰动 ρ_i = v_i / v*_i − 1。则在 v* 的某个邻域内：
- 若 ρ_b ≤ ρ_a：t = (⌊a t₀⌋ + δ)/v_a = t₀/(1 + ρ_a)；
- 否则：t = (⌊b(1 − t₀)⌋ + δ)/v_b = (1 − t₀)/(1 + ρ_b)；

是正确的选择子。理由：被选速度恰在 +δ 处；另一个紧速度因 (1+ρ_b)/(1+ρ_a) ≤ 1（或其镜像）落在安全一侧；其余速度在 v* 处有正余量，小扰动不破坏。分支面是 v_a/a = v_b/b。结合 NO-CONT′：**这些紧实例处，局部最少分支数恰为 2**。F_loc 正是 LOC2 在极值族上的情形，并给出了显式半径。

CHECKED：§4.4 普查到的 8 个紧实例，各 2000 次相对扰动（≤ 10⁻³），全部 0 失败。

### 3.4　TF-½：全 n 的半门槛窗口界

**定理**　对一切 n ≥ 2 与一切 v ∈ (0,∞)^{n−1}，取 δ = 1/(2n)：τ_½(v) ≤ ((n+1)/(2n))·Σ_i 1/v_i；跳跃迭代至多 ((n+1)/(2n))(Σ_i 1/v_i)(Σ_i v_i) + n − 1 步。

*证明*：在 [0, T] 中，B_i 由 [0, δ/v_i) 与 Q 个长 2δ/v_i 的区间组成，Q < v_i T + δ，所以 |B_i ∩ [0, T]| < 2δT + δ(1 + 2δ)/v_i。对 i 求和：[0, T] 中坏点的测度 < 2kδT + δ(1 + 2δ)·Σ1/v_i。代入 δ = 1/(2n) = 1/(2(k+1))，得好点测度 > (1/(k+1))·[T − ((k+2)/(2(k+1)))·Σ1/v_i]，在 T = ((n+1)/(2n))·Σ1/v_i 时为正；所以 [0, T] 中有安全点，τ_½ ≤ T。步数由引理 2(b) 得出。∎

CHECKED：400 组随机有理输入（n = 2…47，速度比最高到 1000）全部满足；实际 τ 最多只到这个界的 1/3。

### 3.5　尺度阶梯：TF-½ 的均匀复杂度构造

参数：δ = 1/(2n)，H = 4k，G = 28k³。
1. 速度升序排列；在相邻比 ≥ G 处切开，得簇 C_1, C_2, …（簇内总比 R_C < G^{k−1}）。
2. 维护一个闭区间 J，初始为 [0, ∞)。对簇 C（最小速度 V_C）：在窗口 W = [min J, min J + H/V_C] 内求 C 的全部安全分量，取最长者作为新的 J。
3. 输出最后那个 J 的左端点（它是一个地标）。

*正确性*：W 内，每个 v ∈ C 的坏区至多 vH/V_C + 2 个，所以每个速度贡献的坏测度 ≤ 2δ|W| + 4δ/V_C；对 C 求和后，好测度 > (H − 2k)/((k+1)V_C) ≥ 1/V_C。分量数 ≤ k(4kR_C + 3)，所以最长分量 > 1/(V_C·k(4kR_C + 3))。下一簇满足 V_{C′} ≥ G·R_C·V_C，而 G ≥ 16k³ + 12k² 保证最长分量 ≥ H/V_{C′}，下一个窗口放得进去。每簇需检查的区间数 ≤ k(4kG^{k−1} + 3)——**只依赖 n**。∎

CHECKED：200 组随机多簇输入（最多 5 簇）加 40 组单簇（k ≤ 20），全部输出安全时间，所有中间下界都成立。

## 附录　核心算法（可直接移植）

```python
from fractions import Fraction as F
from math import floor

def nint(x):
    return floor(x + F(1, 2))

def tau(V, d):
    """最左安全时间：门槛 d 下第一个让所有跑者都安全的地标 (q + d)/v_i。
    V 用精确分数；若安全时间不存在，循环永不停止——那正是 ①。"""
    t = F(0)
    while True:
        best = None
        for v in V:
            x = v * t
            q = nint(x)
            if abs(x - q) < d:            # 跑者在坏区
                e = (q + d) / v           # 跳到这个坏区的右端（地标）
                if best is None or e > best:
                    best = e
        if best is None:
            return t
        t = best

# 例：tau([F(1), F(2), F(3), F(41, 10)], F(1, 5))  ->  Fraction(2, 5)
```
