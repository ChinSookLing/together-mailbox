# Part I · 完整陈述（供主席认证）

**通用记号**：
- ‖z‖ 为 z 到最近整数的距离；frac(z) = z − ⌊z⌋。
- n 位跑者对应 n−1 个非零速度，门槛为 1/n。F_n(W) 指对 n−1 个速度 W 已认证的构造，满足：输出 > 0，且对每个 w ∈ W，‖w·F_n(W)‖ ≥ 1/n。
- F₄ 即已认证的 T4（八段闭式；对任意 0 < u₁ < u₂ < u₃ 成立；齐次性 F₄(gU) = g⁻¹F₄(U)）。
- 对一般的 n，δ = 1/(n+1)，A_δ = [δ, 1−δ]，μ = 1/n − 1/(n+1) = 1/(n(n+1))。n = 4 时 δ = 1/5，A = [1/5, 4/5]，μ = 1/20。

## §1 定理 PS_n（周期平移 (period shift)；一般层级）

**假设**：
- (H1) n ≥ 3（因此 δ ≤ 1/4）。
- (H2) V 是 n 个两两不同的正实数，u ∈ V 为"局外人"，W = V∖{u}。
- (H3) W 可公度：存在 g > 0，使 W ⊂ gℤ。令 P = 1/g，于是对所有 w ∈ W，wP ∈ ℤ。
- (H4) 已有 t₀ = F_n(W)。

**令** x = frac(uP)，y = 1 − x，φ₀ = frac(u t₀)。

**选择器**（闭式，至多一次取上整）：
- (S0) φ₀ ∈ A_δ：j = 0。
- (S1) φ₀ ∉ A_δ 且 0 < x ≤ ½：j = ⌈frac(δ − φ₀)/x⌉。
- (S2) φ₀ ∉ A_δ 且 ½ < x < 1：j = ⌈frac(φ₀ − (1−δ))/y⌉。
- (E) φ₀ ∉ A_δ 且 x = 0：**本局外人不适用**。

**输出**：t = t₀ + jP。

**结论**：在 (S0)–(S2) 下，t > 0，且对所有 v ∈ V，‖vt‖ ≥ δ = 1/(n+1)。

**证明**：
1. **W 中各速度**：wP ∈ ℤ，所以 w(t₀ + jP) ≡ wt₀ (mod 1)，故 ‖wt‖ = ‖wt₀‖ ≥ 1/n > δ。
2. **u**：ut = ut₀ + j·uP，所以 frac(ut) = frac(φ₀ + jx)。
   - (S0)：直接成立。
   - (S1)：φ₀ ∉ A_δ，所以 Δ = frac(δ − φ₀) ∈ (0, 2δ)。（φ₀ ∈ [0, δ) 时 Δ = δ − φ₀ ∈ (0, δ]；φ₀ ∈ (1−δ, 1) 时 Δ = 1 + δ − φ₀ ∈ (δ, 2δ)。）由上整的定义，jx ∈ [Δ, Δ + x)。又 φ₀ + Δ ≡ δ (mod 1)，所以 frac(ut) ∈ [δ, δ + x)。由于 x ≤ ½ ≤ 1 − 2δ（这里用到 δ ≤ 1/4），有 [δ, δ + x) ⊂ A_δ。
   - (S2)：每走一步 P，u 的相位按模 1 减少 y，且 0 < y < ½。令 Δ′ = frac(φ₀ − (1−δ)) ∈ (0, 2δ)，则 jy ∈ [Δ′, Δ′ + y)，所以 frac(ut) ∈ (1−δ−y, 1−δ]。由于 y < ½ ≤ 1 − 2δ，这个区间 ⊂ A_δ。
3. **正性**：j ≥ 0，P > 0，所以 t ≥ t₀ > 0。∎

**步数界**：j < 2δ/e + 1，其中 e = min(x, 1−x) = ‖uP‖。这个界与 s 无关。

**F₅ 实例（即 R019 的 PS）**：n = 4，u = a，W = {b, c, d} = g{B, C, E}，δ = 1/5，t₀ = F₄(b, c, d)。

**例外集**：E_PS(u) = {uP ∈ ℤ 且 frac(u·F_n(W)) ∉ A_δ}。

**作用范围**：(H3) 对一般实数速度是一个限制。若 W 中有两个速度之比为无理数，就不存在 P（R020 §A5 的障碍）。

## §2 选择器 PS\*_n（局外人轮换）

**假设**：V 是 n 个两两不同的正**有理数**，n ≥ 4。

**规则**：
- 把 V 按升序排好，依次取 u = v₁, v₂, …, v_n，对每个 u 套用 PS_n。其中 g_u 取 V∖{u} 的有理最大公约数（即使 V∖{u} ⊂ gℤ 的最大 g），P_u = 1/g_u。
- 输出第一个不落入 (E) 的分支所给的 t。
- 若 n 个分支都落入 (E)，报告 V ∈ E\*。

**结论**：输出满足 §1 的结论。证明见 §1；PS_n 的证明没有用到 u 在 V 中的位置。

**例外集（精确）**：E\* = ⋂_{u∈V} E_PS(u)。在有理输入下 (H3) 总是成立，所以 E\* 恰好是这样的 V：对每个 u，都有 g_u | u（作为有理数，即 u/g_u ∈ ℤ），并且 frac(u·F_n(V∖u)) ∉ A_δ。

**计算成本**：若 F_n 本身也用 PS\* 递归求得，最坏情况下调用树有 n·(n−1)·…·5 个叶子，每个叶子是一次 F₄。这个数有限，但随 n 呈阶乘增长。若改为固定局外人（例如总取最慢者），调用链只有 n − 4 层。

## §3 推论 LS（相位格选择 (lattice selection)）

**假设**：0 < a < b < c < d，并且 (b, c, d) = g(B, C, E)，其中 g > 0，B < C < E 为正整数。令 S = b + c，s = S/a，θ₀ = B/(B+C)，w₀ = E/(B+C)，这正是实际形状，偏差为 0。

**令**：
- τ\* = (B + C)·F₄(B, C, E)，写成最简分数 p\*/m；
- Q = m(B + C)；
- ρ\* = p\* mod Q。

**LS-1（单余数）**：取 R = {ρ\*}。则
- (P2) 成立：Q/m = B+C，Qθ₀/m = B，Qw₀/m = E，都是整数；
- ρ\* ≠ 0，ρ\* ∈ R；
- 余量 μ_b, μ_c, μ_d ≥ 1/20；
- G = Q。

所以当 **s ≥ 5(B+C)/3** 时，已认证的 CLR v2 输出成功的时间 t。

**LS-R（完整余数表）**：取 R = {ρ ∈ {1, …, Q−1}：在 τ = ρ/m 处，三个距离都 **> 1/5**}。这一步是有限查表，共 Q − 1 项，Q 由公式给出，不是无界搜索。
- 由 LS-1，ρ\* ∈ R，所以 R ≠ ∅；
- 三个最小值 μ 都 > 0；
- 令 G 为 R 的最大循环间隔。

当 **s ≥ 5G/(3m)** 时，CLR v2 成功。由于 G ≤ Q，LS-R 的适用范围包含 LS-1。

**证明**：
1. 在 τ\* 处：τ\*θ₀ = B·F₄(B,C,E)，τ\*(1−θ₀) = C·F₄(B,C,E)，τ\*w₀ = E·F₄(B,C,E)。由 T4，三个距离都 ≥ 1/4 = 1/5 + 1/20。
2. 对 k ≡ ρ\* (mod Q)：k/m = τ\* + i(B+C)，i ∈ ℤ，三个相位分别增加 iB、iC、iE，都是整数，所以相位不变（CLR v2 引理 1）。
3. **ρ\* ≠ 0**（采纳 Qwen 的补充）：若 ρ\* = 0，则 τ\* = i(B+C)，于是 τ\*θ₀ = iB ∈ ℤ，距离为 0，与 ≥ 1/4 矛盾。
4. 偏差为 0，所以 CLR v2 的条件 (ii)、(iii) 自动成立，只剩条件 (i)。∎

**作用范围**：LS 与 PS 的支撑集相同（簇可公度）。LS 只在 PS 不适用（E_PS）或 PS 不方便的地方才增加内容。按主席的四分类，LS 是"安全集非空性已证的选择器"，并且带有 s 的下界。

## §4 定理 APS（近似周期平移 (approximate period shift)；n = 4）

**假设**：0 < a < b < c < d，给定整数 0 < B < C < E。令
- P = B/b；
- r_c = cP − C，r_d = dP − E；
- x = frac(aP)，e = min(x, 1−x) > 0；
- t₀ = F₄(b, c, d)（用真实速度）。

用 §1 的选择器（δ = 1/5，u = a）算出 j。

**判据**：若 j·|r_c| ≤ ‖ct₀‖ − 1/5 且 j·|r_d| ≤ ‖dt₀‖ − 1/5，则 t = t₀ + jP 成功。

**保证版**：若 (2/(5e) + 1)·max(|r_c|, |r_d|) ≤ 1/20，则判据自动成立。

**证明**：
- b：bP = B，相位不变。

# Part II · 归纳传递 F_n → F_{n+1}

## §5 框架
要构造 F_{n+1}(V)，其中 V 有 n 个速度。选一个"新跑者" u ∈ V，令 W = V∖{u}，已有 t₀ = F_n(W)。

问题是：关于旧构造，需要保留什么信息，什么可以改变，才能把 u 加进来？

## §6 四类信息之间的关系（证明）
- **(1) 成功时间点**：t₀，满足对所有 w ∈ W，‖wt₀‖ ≥ 1/n。
- **(2) 正余量**：对新门槛 δ = 1/(n+1)，‖wt₀‖ ≥ δ + μ_w，且 μ_w > 0。
- **(3) 单侧安全区间**：存在 [t₀, t₀ + ℓ]（或双侧），W 在其上处处 ≥ δ。
- **(4) 可选相位族**：一个集合 T，T 中每一点都对 W 安全。

**命题 H（层级关系）**：
- (1) 在第 n 层成立 ⇔ (2) 在第 n+1 层成立，且 μ = 1/(n(n+1))。这只是同一个不等式的两种写法。
- (2) ⇒ (3)：取半宽 h = μ/w_max。由 Lipschitz 性，|‖w(t₀+τ)‖ − ‖wt₀‖| ≤ w|τ| ≤ μ。
- **所以 (1)、(2)、(3) 携带的信息相同。真正新的信息只有 (4)。**
- 并且 (1)、(2) 会**自动再生**：F_{n+1} 的输出本身就是第 n+2 层的 (1)/(2)，余量为 1/((n+1)(n+2))。而 (4) **不会**自动再生。

## §7 定理 FO（快局外人 (fast outsider)）：(1)–(3) 何时足够

**假设**：
- n ≥ 2；
- W 为 n−1 个正实数，t₀ = F_n(W)；
- u > 0，且 **u ≥ n·w_max**，其中 w_max = max W。

**选择器**：令 φ = frac(ut₀)，δ = 1/(n+1)。
- 若 φ ∈ A_δ：t = t₀。
- 若 φ < δ：t = t₀ + (δ − φ)/u。
- 若 φ > 1 − δ：t = t₀ − (φ − (1−δ))/u。

**结论**：t > 0，且对 V = W ∪ {u}，所有距离 ≥ δ。

**证明**：
1. 平移量 |t − t₀| ≤ δ/u ≤ δ/(n·w_max) = 1/(n(n+1)·w_max) = μ/w_max = h。
2. **u**：相位被精确移到 δ 或 1−δ。
3. **W**：‖wt‖ ≥ ‖wt₀‖ − w·h ≥ 1/n − μ = δ。
4. **正性**：由 ‖w_max t₀‖ ≥ 1/n 得 w_max·t₀ ≥ 1/n，所以 t₀ ≥ 1/(n·w_max) > μ/w_max = h，从而 t ≥ t₀ − h > 0。∎

**最优性（在"只用 (1)–(3)"的意义下）**：
- 若 φ = 0，把 u 移进安全弧至少要平移 δ/u。
- 只靠 Lipschitz 性保证 W 的安全，最多允许平移 μ/w_max。
- 所以最坏情形需要 u ≥ (δ/μ)·w_max = n·w_max。FO 的门槛不能再降低。

**与已认证构造的关系**：n = 4 时，FO 的条件是 d ≥ 4c，这正是已认证的 **LN**。所以本席**不主张新覆盖**。FO 的贡献是：它给出 LN 的一般 n 形式，是一个**真正统一的 n → n+1 步骤**，但条件是新跑者足够快。

**(1)–(3) 不足的显式例子**（手算）：V = (1, 2, 3, 4)，u = 1，W = (2, 3, 4)。
- t₀ = F₄(2, 3, 4) = 1/8（T4 的 S1：4 ≤ 3·2）。
- h = (1/20)/4 = 1/80，区间 [1/8 − 1/80, 1/8 + 1/80] = [9/80, 11/80]。
- u 在这个区间上的相位 ∈ [9/80, 11/80]，都 < 1/5。

所以 (1)–(3) 所保证的区间里**没有任何一点**可用。（此组由已认证的 TN 处理。）

## §8 定理 TL（格传递 (lattice transfer)）：(4) 何时足够

**假设**：
- n ≥ 3；
- W、u、t₀ 同 §5，且 ‖wt₀‖ ≥ δ + μ_w，μ_w ≥ 0；
- P > 0，带符号残差 r_w = wP − round(wP)；
- x = frac(uP)，e = ‖uP‖ > 0。

取可选族 T = {t₀ + jP : j ≥ 0}，用 §1 的选择器算出 j。

**结论**：若对所有 w，j·|r_w| ≤ μ_w，则 t = t₀ + jP 成功。

**保证版**：若 (2δ/e + 1)·max_w |r_w| ≤ min_w μ_w，则判据自动成立。

**证明**：同 §1 与 §4。W 的相位偏移为 j·r_w，由 Lipschitz 性控制；u 的相位只用到 x。∎

**特例**：
- r_w ≡ 0（精确周期）：即 PS_n，μ_w 可以为 0。
- n = 4，P = B/b：即 APS。

## §9 定理 OB（短整数关系障碍 (short-relation obstruction)）
**陈述**：若存在整数 c_w，使 u = Σ_{w∈W} c_w·w，且 K = Σ|c_w| ≤ 2δ/μ = 2n，则对**每一个** P > 0，§8 的保证版都不成立（这里 μ_w ≡ μ = 1/(n(n+1))，即层级余量）。

**证明**：
1. ‖·‖ 满足次可加性，且 ‖cz‖ ≤ |c|·‖z‖，所以 e = ‖uP‖ = ‖Σ c_w·wP‖ ≤ Σ|c_w|·‖wP‖ ≤ K·max|r_w|。
2. 若 e > 0，则 (2δ/e + 1)·max|r_w| > (2δ/e)·(e/K) = 2δ/K ≥ μ。
3. 若 e = 0，选择器本身不适用。∎

**精确版**（非保证版，用于判断）：在给定 φ₀ 下，需要 j ≥ Δ/e，所以 j·max|r_w| ≥ Δ/K。于是必要条件为 **K ≥ Δ(φ₀)/min_w μ_w**。

**含义**：
- K 有限且 r = 0 的情形，正是 E_PS（x = 0）。PS 的例外集是 OB 的边界情形。
- 整数速度（有理输入化整后正是这种情形）中，每个 u 都有有限的 K，而且通常很小。例：(1, 2, 3, 4) 的四个局外人：1 = 3 − 2，2 = 3 − 1，3 = 1 + 2，4 = 1 + 3，K 都是 2 ≤ 8。所以对 (1, 2, 3, 4)，**任何局外人、任何 P** 的保证型格传递都不可能；又因为没有快局外人（4 < 4·3），FO 也不适用。

## §11 结论：哪一类信息足以完成归纳步
1. **(1) 成功时间点**：不足（§7 的例子）。
2. **(2) 正余量**：与 (1) 等价（命题 H）。只在 u ≥ n·w_max 时足够（FO），而且这个门槛在只用 (2) 的前提下是最优的。
3. **(3) 单侧安全区间**：长度 ℓ 的区间在 ℓ·u ≥ 2δ 时足够（u 的相位扫过一段闭弧，长度 ≥ 2δ，不可能整个落在长为 2δ 的开不安全弧里）。但 F_n 只能提供 ℓ = 2μ/w_max，这就退化回 FO。
4. **(4) 可选相位族**：足够的充分条件是 TL 判据，或者在 u 的安全窗口内间隔 ≤ (1−2δ)/u。
   - F_n 加上**由速度算出**的精确周期，正好提供格 t₀ + Pℤ，也就是 PS。
   - 但 OB 表明：当存在 K ≤ 2n 的短整数关系时，单点加周期这一类可选族**必然不够**。

**所以，没有任何一类信息能对所有输入完成归纳步。**

一个统一的归纳要求 F_n 输出的不是一个点，而是一个**带间隔界的安全族**：对 W 安全的时间集，在任意长度为 L_n(W) 的窗口中至少有一点，且 L_n 有显式上界。这样，任何满足 u·L_n(W) ≤ 1 − 2δ 的慢跑者都能加入。

本席**无法证明**这样的 L_n 存在并且可以递归再生。对整数 W，W 的安全集以 1 为周期；所需的间隔条件本质上就是 W ∪ {u} 的原问题，存在循环论证的危险。——**UNFINISHED**（IDEA：寻找能自动再生的"间隔界"不变量）。
