# Part II · Track A：例外集的结构

## §1 E\*_n 的精确定义
固定一个下层构造 F（即一个 F_n）。对 n 个两两不同的正有理数 V，
**E\*_n(F) = { V : 对每个 u ∈ V，都有 u/g_u ∈ ℤ，且 frac(u·F(V∖u)) ∉ A_δ }**，
其中 g_u 是 V∖{u} 的有理最大公约数。

（若允许实数输入，再并上 {V：每个 V∖{u} 都不可公度}。这一部分只是方法的定义域问题，见 R020 §A5。）

**引理 N（化整形式）**：E\*_n 在正数倍缩放下不变。
若 V 为本原整数组（gcd(V) = 1），则：u/g_u ∈ ℤ ⇔ g_u | u ⇔ g_u | gcd(V) = 1 ⇔ **V∖{u} 本原**。

所以 **V ∈ E\*_n(F) ⇔ V 的每个 (n−1)-子集都本原，且 n 个候选点 F(V∖u) 对相应的 u 都不安全。**

**证明**：
- 缩放不变：若 V 换成 λV，则 g_u 变为 λg_u；又因 F 是齐次的（F(λW) = F(W)/λ，T4 满足；一般 F 默认采用齐次版本），所以 u·F(V∖u) 不变。
- 第二部分：g_u 整除 V∖{u} 中的每个元素，若又 g_u | u，则 g_u | gcd(V)。∎

**E\*_n 依赖于 F**：同一个 V，换一个合法的 F，可能就不再是例外（§3）。

## §2 更换局外人不一定能解决：显式例外族（一般 n）

**定理 TF（紧族 (tight family)）**：设 n ≥ 2，V_n = (1, 2, …, n)，λ > 0。
- (i) V_n 在门槛 1/(n+1) 下的解，恰好是 t ≡ k/(n+1) (mod 1)，且 gcd(k, n+1) = 1。
- (ii) 在每一个解处，**恰好有两位跑者**的距离等于 1/(n+1)，其余都更大。
- (iii) 所以对任何解 t 和任何局外人 u，V_n∖{u} 中至少有一位跑者的距离是 1/(n+1) < 1/n。
- (iv) 因此，对**每一个**下层构造 F，都有 λV_n ∈ E\*_n(F)。

**证明**：
1. **鸽笼**：对 v = 0, 1, …, n，令 z_v = frac(vt)，共 n+1 个点在圆周上。它们把圆分成 n+1 段，段长之和为 1，所以最短段 ≤ 1/(n+1)。z_i 与 z_j 的圆周距离等于 ‖(i−j)t‖，而 |i − j| ∈ {1, …, n} = V_n。
2. **等号情形**：若 t 是解，则所有两两距离 ≥ 1/(n+1)，所以 n+1 段每段都 ≥ 1/(n+1)，而总和为 1，故每段**恰好**等于 1/(n+1)，点等距分布。于是 {z_v} = {0, 1/(n+1), …, n/(n+1)}，特别地 t ≡ k/(n+1)。又 z_v 两两不同，所以 gcd(k, n+1) = 1。反过来，每个这样的 k 都给出等距分布，所以确实是解。这就证明了 (i)。
3. **(ii)**：v ↦ vk mod (n+1) 是 {1, …, n} 上的双射，所以恰有一个 v₁ 满足 v₁k ≡ 1，恰有一个 v₂ 满足 v₂k ≡ −1。它们的距离都是 1/(n+1)，其余都 ≥ 2/(n+1)。由于 n+1 ≥ 3，1 ≢ −1，所以 v₁ ≠ v₂。
4. **(iii)**：去掉任何一个 u，v₁、v₂ 中至少有一个留下。
5. **(iv)**：PS_n 的输出 t 满足"t 是 V 的解，且 V∖{u} 的距离全部 ≥ 1/n"（§1 第 1 项 (a)）。由 (iii)，这对 V_n 不可能。所以对每个 u 都只能落入例外分支。缩放：λV_n 的解是 t/λ，所有距离不变。∎

**n = 4 的实例**：(1, 2, 3, 4) 及其倍数 (2, 4, 6, 8)、(3, 6, 9, 12) 等。

**第二个形状（CHECKED，不是一般证明）**：(1, 3, 4, 7)，即 V3，及其倍数。本席用精确区间运算算出，它在 1/5 下的全部解为 t ∈ {1/5, 2/5, 3/5, 4/5}（mod 1），每个解处都恰有两位跑者距离为 1/5：
- t = 1/5：四个距离为 1/5, 2/5, 1/5, 2/5；
- t = 2/5：2/5, 1/5, 2/5, 1/5。

（3/5、4/5 与之对称。）所以它也是结构性的。它不在 TF 的证明范围内（TF 的鸽笼论证用到连续的差集），所以只记 CHECKED。

## §3 结构核与选择规则造成的例外

**定义**：C_n = { V：V 在 1/(n+1) 下有解，并且每一个解 t 都至少有两位跑者满足 ‖vt‖ < 1/n }。C_n 不依赖于任何 F。

**定理 CORE**：对有理输入，**⋂_F E\*_n(F) = C_n ∪ {无解的 V}**（交集取遍所有合法的下层构造 F）。

**证明**：
- **⊇**：若 V ∈ C_n，则对任何解 t 和任何 u，V∖{u} 中至少剩一位跑者 < 1/n，所以 PS 不可能成功（同 TF (iv)）。无解的 V 显然在每个例外集中。
- **⊆**：设 V 有解且 V ∉ C_n。则存在解 t 和 u，使 V∖{u} 在 t 处全部 ≥ 1/n。定义 F′ 在 W = V∖{u} 上取值 t（这是 W 的一个合法输出），在其他输入上与 F 相同。轮到这个 u 时，PS 的 (S0) 立即给出 j = 0。若排在前面的某个局外人已经成功，V 同样不是例外。所以 V ∉ E\*_n(F′)。∎

**计算**（本席精确区间运算；范围同 R020，即 1 ≤ 速度 ≤ 30 的整数四元组；只处理 1,689 个例外，不另作新枚举）：
- 1,689 个例外中，**11 个属于 C₄**：(1,2,3,4)、(2,4,6,8)、(3,6,9,12)、(4,8,12,16)、(5,10,15,20)、(6,12,18,24)、(7,14,21,28)，以及 (1,3,4,7)、(2,6,8,14)、(3,9,12,21)、(4,12,16,28)。也就是**只有两个形状**，即 TF 的 V₄ 与 V3。
- 其余 **1,678 个是选择规则造成的**：只要把 T4 换成同一子集上另一个旧门槛下安全的时间，PS 就能成功。按可用的局外人分：取 a 的 1,649 个，取 b 的 17 个，取 c 的 12 个（1,649 + 17 + 12 = 1,678）。

**结论**：E\*_n(F) = C_n（结构障碍）⊔（E\*_n(F)∖C_n）（**由 F 的选择造成的**）。
- 对"让旧跑者保持旧门槛"的一类传递（下称 **OTP 类**，包括 PS_n、PS\*_n 及其任何换 F 的版本），C_n 是**真正的障碍**。
- 对一般构造，C_n **不是**障碍：C_n 中的 V 本身有解，例如 (1, 2, 3, 4) 在 t = 1/5 处成功。

## §4 所有局外人都失败，能推出什么代数关系
1. **对 E\*_n(F)**：由引理 N，**每个 u 都属于 V∖{u} 的整数生成格**。（化整后：每个 (n−1)-子集都本原；等价地，所有 x_u = 0；再等价地，每个 u 都有有限的 OB 常数 K(u)。）
   这是必要条件，但并不罕见：在同一范围内，27,405 组中有 18,090 组满足它（本席在本会话中的同一枚举，R021 §9）。所以它不是一个有力的刻画。
2. **对 C_n**：关系更强，即"每个解都至少有两位跑者低于旧门槛"。
   - 在 TF 中，这来自 V 包含一个 (n+1) 元差集的全部正差。
   - **补充引理**：若 D ⊂ ℤ，|D| = n+1，且 D 的正差集合恰好就是 V（|V| = n），则 D 是等差数列，V = λV_n。
   - **证明**：设 D 的元素从小到大为 d₀ < d₁ < … < d_n。
     1. d_j − d₀（j = 1, …, n）是 n 个两两不同的正差，而正差总共只有 n 个，所以**每个**正差都形如 d_j − d₀。
     2. 对 m 归纳证明 d₀, …, d_m 是公差 s = d₁ − d₀ 的等差数列。m = 1 显然成立。
     3. 设 d₀, …, d_m 已是等差数列（m < n）。由第 1 步，d_{m+1} − d_m = d_k − d₀；又它 < d_{m+1} − d₀，所以 k ≤ m，即 d_{m+1} − d_m = ks，且 1 ≤ k ≤ m。
     4. 于是 d_{m+1} − d_i = (m + k − i)s（i = 0, …, m），这些值覆盖 ks, (k+1)s, …, (m+k)s。若 k ≥ 2，则 ks ≤ (m+1)s < (m+k)s，所以 (m+1)s 是一个正差。由第 1 步，它应等于某个 d_j − d₀；但 j ≤ m 时 d_j − d₀ ≤ ms，j = m+1 时等于 (m+k)s，j ≥ m+2 时更大，都不等于 (m+1)s，矛盾。所以 k = 1。∎
   - 所以"差集型"机制只产生 TF 族；(1, 3, 4, 7) 型的核成员来自另一种机制：**UNFINISHED**。

## §5 更强的归纳不变量能否消除 E\*_n
1. **I_old（下层传入 W 在旧门槛 1/n 下的完整安全集）**：由 CORE，它恰好消除 E\*_n(F)∖C_n，也就是 1,678 个那一部分，但**消除不了** C_n。原因是 TF：C_n 的每个解都要求某位旧跑者处在 [1/(n+1), 1/n) 之间。
2. **I_new（下层传入 W 在新门槛 1/(n+1) 下的完整安全集）**：这一步是精确的：V 的解集 = S_{1/(n+1)}(W) ∩ S_{1/(n+1)}(u)，所以能消除一切有解的 V。但它**不会自动保持**：到下一层需要 S_{1/(n+2)}(V)，而 S_{1/(n+2)}(W) 并不能从 S_{1/(n+1)}(W) 得到。结果是必须传入"所有未来门槛下的安全集"，这等于在每一层直接解原问题。
   - 对有理速度，这是一个有限的确定性算法：化整后对 Σv 个区间求交，规模由速度给出，不是无界搜索。
   - 但"交集非空"这一保证本身就是该层的孤独跑者 (lonely runner) 命题。据本席所知（WEB OFF，未核验），该命题只在跑者数较小时已被证明，所以这不能算一般 n 的保证构造。
3. **最小必要条件（证明）**：由 TF，**任何**能对 C_n 成功的传递，其输出都必须让某位旧跑者处在 [1/(n+1), 1/n) 之间。所以从 F_n 传给 F_{n+1} 的不变量**必须包含旧跑者在新门槛 1/(n+1) 下的信息**，不能只有旧门槛下的安全点或安全集。
   - FO 与 TL 满足这一点（它们允许旧跑者漂移到 δ）；
   - PS、PS\* 不满足。
4. **IDEA（双门槛不变量）**：让 F_n 输出一对信息：旧门槛下的安全点 t₀，以及 W 在新门槛下包含 t₀ 的安全区间的**实际**端点。这些端点对有理速度可以精确计算。这比 H 的保证窗口更长，可能把 FO 推进到中速局外人。它能否逐层保持：**UNFINISHED**。

## 主席必答题
**Does the proposed result provide a guaranteed mechanism for the induction step, or does it only describe a sufficient subset of inputs?**

**CONDITIONAL。**
- **缺少的假设（OT，旧门槛可传递性）**：V 存在一个解 t 和一个局外人 u，使 V∖{u} 在 t 处全部 ≥ 1/n；并且下层构造恰好提供这样的 t（或者 PS 的平移步长非零）。
- **它是否自动保持**：**不保持**。由 TF，对**每一个** n，都有输入 λ(1, 2, …, n) 违反 OT。所以任何只保持旧门槛的传递，在每一层都会遇到同一种障碍。

- **所以**：现有结果描述的是一个**充分输入子集**。真正的归纳步所缺的，是一个携带新门槛信息、并且能逐层再生的不变量。这仍是 UNFINISHED。
