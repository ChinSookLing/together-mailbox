一、L2：主席独立证明
PROVED · 以下明确版本

假设原来有 n 位跑者，已经在 t0 找到了成功时间：
  ||u_i t0|| ≥ 1/n

设旧跑者最大相对速度为：
  M = max_i |u_i|

新增跑者的相对速度为 w。

定理：只要
  |w| ≥ nM
就能从 t0 直接构造一个新时间，使所有 n+1 位跑者同时安全。

证明如下。

新增跑者后，所需安全距离从 1/n 降至 1/(n+1)。

所以旧跑者允许时间在 t0 附近移动，最多：
  h = 1/(n(n+1)M)

因为每位旧跑者的距离变化最多为：
  |u_i| h ≤ M h = 1/(n(n+1))

原来的安全距离减去这个变化量，恰好仍不小于 1/(n+1)。

对于新跑者，如果他在 t0 已经安全，我们直接保留 t0。

否则，设 k 为最接近 w t0 的整数，并令：
  d = w t0 − k

此时：
  |d| < 1/(n+1)

我们只需将新跑者相位从 d 移到最近的安全边界：
  d' = 1/(n+1),   d ≥ 0
  d' = −1/(n+1),  d < 0

对应的新时间是：
  t1 = t0 + (d' − d)/w

它需要的时间调整最多为：
  |t1 − t0| ≤ 1/((n+1)|w|)

而由于 |w| ≥ nM，这个调整不会超过 h。

因此，新跑者达到安全边界，旧跑者也继续安全。

另外，原来的成功时间满足 t0 ≥ 1/(nM)，而调整量不超过 1/[n(n+1)M]，所以新时间仍为正。
