# Part II · Track A · Edge Transfer

记号：V 为有限个正速度，0 < δ < ½，S = {t > 0 : ‖ut‖ ≥ δ，∀u ∈ V}。round(X) = ⌊X + ½⌋。

## A1 算法 ETS（边沿转移扫描）
1. **起点**：t := δ/m，其中 m = min V（最慢者的第一个下沿）。
2. **识别**：U(t) = {u ∈ V : ‖ut‖ < δ}，即此刻会失败的跑者。若 U(t) 为空，输出 t。
3. **转移**：对 u ∈ U(t)，令 τ_u = (round(ut) + δ)/u，即 u 下一次变安全的时刻（u 的下一个下沿）。令 t := max_{u∈U(t)} τ_u，回到第 2 步。

每一步只做有限次取整和比较；不枚举整条下包络线，只沿着"此刻失败的那些跑者"的边沿前进。

## A2 定理 ETS（PROOF CANDIDATE）
- (a) **良定义**：u ∈ U(t) 时 ‖ut‖ < δ < ½，所以 round(ut) 是 ut 唯一的最近整数，且 τ_u > t。
- (b) **不跳过成功时间**：若 t ≤ t* 且 t* ∈ S，则新的 t ≤ t*。
- (c) **终止并输出第一个成功时间**：若 S ≠ ∅，则 ETS 在有限步内停止，输出 min S。它是一个成功分量的左端点（与 LE 一致），且该处某跑者以下沿活跃。
- (d) **步数上界**：对任意 t* ∈ S，步数 ≤ Σ_{u∈V} (⌊u t*⌋ − ⌊u t₀⌋ + 1)。

**证明**：
- (a) 令 k = round(ut)，则 ut ∈ (k − δ, k + δ)，所以 τ_u = (k + δ)/u > t。
- (b) 设新 t 由 u 给出。在 [t, τ_u) 上 u 的相位 ∈ [ut, k + δ) ⊂ (k − δ, k + δ)，所以 u 不安全，这一段里没有成功时间。因此 t* ≥ τ_u。
- (c) 首先 min S ≥ δ/m：若 t* < δ/m，则 m t* < δ，m 不安全，矛盾；所以 S ⊂ [t₀, ∞)。
  每一步的新 t 都是某个下沿时间 E⁻(u, k)，严格递增，并且由 (b) 不超过 t*。[t₀, t*] 中的下沿时间只有有限个，所以有限步内停止。停止时 t ∈ S；又由 (b)，t ≤ 每一个成功时间，所以 t = min S。
- (d) [t₀, t*] 中 u 的下沿时间个数 ≤ ⌊ut*⌋ − ⌊ut₀⌋ + 1；每一步占用一个不同的下沿时间。∎

**关于终止的前提（必须写明）**：(c) 需要 S ≠ ∅。在 PT-008 内部，这一点只在已认证规则覆盖的区域内成立；对任意实数速度，它就是五跑者存在性定理本身。据我所知该定理在外部文献中已成立，但 WEB OFF 未查证，PT-008 也未自证。所以 ETS 对一般输入是"**条件性终止**"的确定性算法；它**永不输出错误结果**。

## A3 推论 ET-w：每条转移路径给出显式公式与充分区域（PROOF CANDIDATE）
固定一条路径 w = ((u₁, k₁), …, (u_n, k_n))。对使 ETS 恰好沿 w 运行并在第 n 步停止的所有速度向量，输出为 **t = (k_n + δ)/u_n**。每个 k_i 都由当前相位决定：k_i = round(u_i t_{i−1})。
该集合由有限条显式不等式（相位条件与取整条件）描述，在其中输出都成功。
若在 V 处所有判断都严格成立（没有平局；除落点跑者外，没有相位恰好在 ±δ），则这些不等式在 V 的一个**开邻域**内仍成立，所以同一公式覆盖整个邻域。

## A7 主席四项要求的对照
1. **初始边沿**：最慢者的下沿 δ/m。
2. **识别失败者**：U(t)，即 ‖ut‖ < δ 的跑者。
3. **切换**：跳到失败者中最远的下一个下沿；这一选择由代数式 τ_u 决定，不枚举交点。
4. **终止**：在 S ≠ ∅ 的前提下证明终止，并输出第一个成功时间。**失败位置精确如下**：S = ∅ 时不终止（五跑者情形下，这需要否定存在性定理）。步数上界依赖 t*，**没有只用比例表示的上界**。

**一般 n**：A1–A3 对任意 N 与任意 δ < ½ 成立，证明不依赖 N。ET1 中 a 的自动安全估计需按 δ = 1/N 重算。
