## SECTION A — 精确命题

### A0 设定
- 跑道周长 1；共有 **N ≥ 3** 名跑者，其中一名作为参考，速度为 0。
- 其余跑者的相对速度为非零实数，取绝对值，并把相同的绝对值合并，得到有限集合 U ⊂ (0, ∞)，**|U| ≥ 2**。
- 记 **m = min U**，**w = max U**，**M = max(U ∖ {w})**（次快）。若 |U| = 2，则 M = m。
- 门槛 **δ = 1/N**。目标：t > 0，使 ‖ut‖ ≥ δ 对所有 u ∈ U 成立。
- 记号：‖x‖ = min_{k∈ℤ} |x − k|；**round(X) = ⌊X + ½⌋**。

### A1 引理 TN（主席已裁定 PROVED，此处只为完整列出）
若 w ≤ (N−1)m，则 t = 1/(m+w) 成功。

### A2 引理 GW(N)
假设 (G1) M < (N−1)m，且 (G2) w ≥ 2mM/((N−1)m − M)。算法：
1. t_L = δ/m，X = w·t_L = w/(Nm)。
2. 若 ‖X‖ ≥ δ：输出 **t = t_L**。
3. 否则：k = round(X)，输出 **t = (k + δ)/w**。

结论：t ≥ t_L > 0，且 ‖ut‖ ≥ δ 对所有 u ∈ U 成立。

### A3 定理 K_N
假设 (K) **M ≤ (N−1)²·m/(N+1)**。算法：
- 若 w ≤ (N−1)m：t = 1/(m+w)（TN）；
- 否则：t = GW(N) 的输出。

结论：对所有满足 (K) 的 U（w 可以是任意大于 M 的实数），t > 0 且成功。

各 N 的门槛 (N−1)²/(N+1)：N = 3 时为 1；N = 4 时为 9/5；N = 5 时为 8/3；N = 6 时为 25/7。

## SECTION B — 手工证明

### B1 TN
1/N ≤ m/(m+w) ⟺ m + w ≤ Nm ⟺ w ≤ (N−1)m。所以 mt = m/(m+w) ∈ [1/N, ½)（因 m < w）。
wt = 1 − mt ∈ (½, 1 − 1/N]。对 u ∈ U，mt ≤ ut ≤ wt，所以 ut ∈ [δ, 1−δ]，‖ut‖ ≥ δ。t > 0。∎

### B2 窗口
令 **W = [δ/m, (1−δ)/M]**。
- **非空**：δ/m ≤ (1−δ)/M ⟺ M ≤ ((1−δ)/δ)·m = (N−1)m。由 (G1)（严格不等号），W 有正长度。
- **窗口内安全**：对 u ∈ U ∖ {w}，有 m ≤ u ≤ M。对 t ∈ W：
  ut ≥ m·(δ/m) = δ，ut ≤ M·(1−δ)/M = 1−δ，
  所以 ut ∈ [δ, 1−δ]，‖ut‖ ≥ δ。∎

### B3 GW(N)
**情形 1：‖X‖ ≥ δ。** t = t_L ∈ W。由 B2 与假设，全部成立。

**情形 2：‖X‖ < δ。**
- **k 唯一，无平局**：N ≥ 3 时 δ ≤ 1/3 < ½。平局要求 ‖X‖ = ½，与 ‖X‖ < δ 矛盾。所以 k = round(X) 是 X 唯一的最近整数，且 |X − k| = ‖X‖ < δ。k **由 X 直接算出**，不从整数集合中搜索。
- **w 的距离**：wt = k + δ，所以 ‖wt‖ = ‖δ‖ = δ（因 δ ≤ ½）。
- **单向右移**：X < k + δ，所以 t = (k+δ)/w > X/w = t_L。位移 t − t_L = (k + δ − X)/w，其中 0 < k + δ − X < 2δ（因 X > k − δ）。所以 **0 < t − t_L < 2δ/w**。
- **仍在窗口内**：只需 t_L + 2δ/w ≤ (1−δ)/M。计算：
  (1−δ)/M − δ/m = ((N−1)m − M)/(NmM)。
  所以条件 ⟺ 2δ/w ≤ ((N−1)m − M)/(NmM) ⟺ 2/(Nw) ≤ ((N−1)m − M)/(NmM) ⟺ **w ≥ 2mM/((N−1)m − M)**。这正是 (G2)。（由 (G1)，分母为正。）
  因此 t ∈ (t_L, (1−δ)/M] ⊂ W，由 B2，其余速度都安全。
- **正性**：t > t_L = δ/m > 0。∎

### B4 K_N
**(K) ⇒ (G1)**：(N−1)²/(N+1) < N−1 ⟺ N−1 < N+1，恒成立。所以 M ≤ (N−1)²m/(N+1) < (N−1)m。

**分支 w ≤ (N−1)m**：由 B1。

**分支 w > (N−1)m**：需验证 (G2)。只需证 (N−1)m ≥ 2mM/((N−1)m − M)，然后由 w > (N−1)m 得到 (G2)。
(N−1)m·((N−1)m − M) ≥ 2mM ⟺ (N−1)²m − (N−1)M ≥ 2M ⟺ (N−1)²m ≥ (N+1)M ⟺ (K)。
再由 B3 得结论。∎

**边界情形**
- **(K) 取等号**：仍成立，因为上面每一步都是 ≥。
- **w = (N−1)m**：走 TN，等号合格（B1）。
- **|U| = 2**（M = m）：(K) ⟺ N+1 ≤ (N−1)² ⟺ N ≥ 3。所以 K₃ 处理任意两速度集合，与 F₃ 一致。

### B5 展示计算
- **N = 5，U = {1, 3/2, 5/2, 23/5}**：M = 5/2 ≤ 8/3 ✓；w = 4.6 > 4 = (N−1)m，走 GW。
  t_L = 1/5，X = 23/25 = 0.92，‖X‖ = 0.08 < 0.2；k = round(0.92) = ⌊1.42⌋ = 1；t = (1 + 1/5)/4.6 = 1.2/4.6 = **6/23**。
  距离：‖6/23‖ = 6/23 ≈ 0.261；‖9/23‖ = 9/23 ≈ 0.391；‖15/23‖ = 8/23 ≈ 0.348；‖4.6·6/23‖ = ‖1.2‖ = 0.2。全部 ≥ 1/5。✓
- **N = 6，U = {1, 2, 3, 7/2, 31/4}**：M = 3.5 ≤ 25/7 ≈ 3.571 ✓；w = 7.75 > 5，走 GW。
  t_L = 1/6，X = 31/24 ≈ 1.2917，‖X‖ ≈ 0.2917 ≥ 1/6，所以 **t = 1/6**。
  距离：1/6，1/3，1/2，‖7/12‖ = 5/12，‖31/24‖ = 7/24 ≈ 0.292。全部 ≥ 1/6 ≈ 0.167。✓

## SECTION C — 构造之外的输入（精确）

TN ∪ GW(N) 覆盖的范围，恰好是下面集合 E_N 的补集：

**E_N = {M ≥ (N−1)m}　∪　{ (N−1)²m/(N+1) < M < (N−1)m，且 (N−1)m < w < 2mM/((N−1)m − M) }**

**证明这确实是补集**：
- 若 M ≥ (N−1)m：W 为空或只剩一点，GW 不适用；而 w > M ≥ (N−1)m，TN 也不适用。
- 若 M < (N−1)m：TN 覆盖 w ≤ (N−1)m，GW 覆盖 w ≥ 2mM/((N−1)m − M)。两者之间的空隙非空，当且仅当 2mM/((N−1)m − M) > (N−1)m，即 M > (N−1)²m/(N+1)（B4 的反向）。∎

**两个 E₅ 中的例子**（它们有解，只是不在本构造内）：
- **{1, 2, 5, 6}**：M = 5 ≥ 4。成功时间 t = 1/4，距离 1/4，1/2，1/4，1/2。
- **{1, 2, 3, 9/2}**：M = 3 ∈ (8/3, 4)，w = 4.5 ∈ (4, 2·3/(4−3) = 6)。成功时间 t = 3/4，距离 ‖3/4‖ = 1/4，‖3/2‖ = 1/2，‖9/4‖ = 1/4，‖27/8‖ = 3/8。

  （这两个成功时间是本席用小程序在分母 ≤ 60 的有理数中查得，再逐一手算核对的。它们**不**来自任何构造，只用来说明 E_N 不是"无解区"。）

**其他排除**：
- N = 2，以及 |U| = 1（全部速度绝对值相同）：不在 GW 的定义域内。后者用 t = 1/(2m) 即可。
- 速度为 0 的非参考跑者：按设定排除。
