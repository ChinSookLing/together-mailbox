# Part I · Track A · Selection Gate

记号：V = (a, b, c, d)，0 < a < b < c < d，δ = 1/5，A = [1/5, 4/5]。F₄ 为已认证的 T4。

## A1 假设
- (H1) 速度为**有理数**（或更一般地：对所用的局外人 u，其余三个速度可公度）。
- (H2) 对 u ∈ V，记 V∖u 为另外三个速度，g_u 为它们的有理最大公约数（使 V∖u ⊂ g_uℤ 的最大 g_u > 0），P_u = 1/g_u。

## A2 选择器 PS\* 与所选时间
对 u 依次取 a, b, c, d：
1. t_u = F₄(V∖u)，x_u = frac(u·P_u)，φ_u = frac(u·t_u)。
2. 若 φ_u ∈ A：n = 0。
3. 否则若 0 < x_u ≤ ½：n = ⌈frac(1/5 − φ_u)/x_u⌉。
4. 否则若 ½ < x_u < 1：n = ⌈frac(φ_u − 4/5)/(1 − x_u)⌉。
5. 否则（x_u = 0 且 φ_u ∉ A）：本分支失败，换下一个 u。

输出第一个成功分支的 **t = t_u + n·P_u**。相位格为 τ = (b+c)t ∈ (b+c)t_u + (b+c)P_u·ℤ，它的分母由 T4 的分支与 g_u **直接决定**，不扫描。

## A3 选择器有定义且终止
- 有理数的最大公约数由有理数上的辗转相除得到，有限步。
- F₄ 是 8 段闭式。
- 每个分支只做一次取上整。
- 最多 4 个分支。

所以 PS\* 至多 4 次闭式计算后，要么输出 t，要么报告 V ∈ E\*。

## A4 每位跑者安全
即 R019 定理 PS，局外人换成 u。证明中**没有用到 u 是最慢者**：
- V∖u 中三人的相位在平移 P_u 下精确不变，由 T4 都 ≥ 1/4；
- u 的相位是公差为 x_u 的等差数列（模 1），按 2–4 步落入 A；
- t > 0。∎

## A5 例外集的精确刻画与符号障碍
**E\* = ⋂_{u∈V} E_u**，其中 **E_u = {V∖u 不可公度} ∪ {u·P_u ∈ ℤ 且 frac(u·F₄(V∖u)) ∉ A}**。

**障碍（证明）**：若 b, c, d 中三个数 ℚ-线性无关，则不存在 P > 0 使 bP, cP, dP 都是整数。否则 b/c = (bP)/(cP) ∈ ℚ，矛盾。所以对一般实数速度，**每一个** E_u 都因"不可公度"而成立，PS\* 不适用。这就是"不能对任意实数给出显式 m"的原因。

**有理情形中 x_u = 0 的含义**：u 是 g_u 的整数倍。对整数四元组，若任意三者互素，则 g_u = 1，x_u = 0 对所有 u 成立。此时 PS\* 退化为 4 个固定候选时间 F₄(V∖u)，不再平移。

## A6 反例搜索：E\* 的规模，以及能否转移到已认证构造（本席计算，限所述范围）
范围：1 ≤ a < b < c < d ≤ 30 的整数四元组，共 27,405 组。
- PS\* 成功的 25,716 组中，输出全部经精确分数复核为成功。
- **E\* 中共 1,689 组**，例如 (1, 2, 3, 4)、(1, 3, 4, 5)、(1, 3, 4, 7)。
- **转移到已认证规则**：本席逐一检查了 TN、LN、WL、TE-AL/AU、Q-B2、R013、P1、NW。1,689 组中有 1,201 组至少被其中之一覆盖，剩 488 组。
- 这 488 组再交给**已认证的 CLR v2**，参考形状取实际形状，偏差为 0：
  - 格 m = (B+C)·F₄(B, C, E) 的分母（即 LS 的选法）；
  - Q = m(B+C)；
  - R = 严格安全余数集，三项距离都 > 1/5；
  - 由 LS，R ∋ ρ\* 且余量 ≥ 1/20 > 0，所以 R **必非空**。

  结果：**482 组成功**。只有 **6 组**因不满足 CLR v2 的条件 s ≥ 5G/(3m) 而未转移：
  **(1,2,9,30)、(1,5,6,18)、(5,13,16,29)、(5,13,18,29)、(7,10,20,29)、(7,11,19,29)**。
  例如 (1,2,9,30)：m = 1，Q = 11，G = 7，s = 11 < 35/3。
- 本席**未检查** SLN1、SLN-odd、HB、C1、B4⁺ 对这 6 组的覆盖：**UNFINISHED**。

## A7 与已认证构造的差别
- **PS\*** 对可公度簇不需要 s 的下界，例外集精确可判；CLR v2 需要 s ≥ 5G/(3m)。两者互补：PS\* 失败时（x_u = 0），CLR v2 + LS 往往成功（A6）。
- **LS** 给 CLR v2 的安全余数集提供了**非空性证明**（余量 ≥ 1/20），使 CLR v2 成为"安全集已证非空的有界选择器"。剩下的唯一失败方式是 s < 5G/(3m)。
- **按主席四分类**：
  - PS\*：**条件性选择器**（条件为有理输入；有精确例外集）。
  - CLR v2 + LS：**需要非空安全集的选择器**，而非空性由 LS 证明。
  - 两者都**不是**真正普适的选择规则。

## A8 通向一般 n（一行）
PS 的证明只用到"V∖u 有成功时间"和"V∖u 可公度"，所以对一般 n 给出 **F_n(V) = F_{n−1}(V∖u) + n·P_u**。这里不需要 F_{n−1} 的余量，因为平移是精确周期。这是可公度情形下真正的 n−1 → n 递推（PROOF CANDIDATE），例外集仍按 A5 刻画。

### R2 证明审查
- **(i) q′ = 1**：正确，kw ∈ ℤ。
- **(ii) q′ ≥ 2：GAP FOUND，三处**：
  1. **步骤 3 用错了集合**。连续整数性质属于 A_q，但需要投影的是 S_θ = p⁻¹·A_q mod q，它一般不是连续整数。
     （可以修补：g | q 且 gcd(p, q) = 1，所以 p 在 ℤ/g 中可逆，|π(S_θ)| = |π(A_q)| = min(|A_q|, g)。原文没有给出这一步。）

  3. **小 g 的情形推理有误**。原文写"g = 3 时 2 + 1 = 3 个类，必相交"，但 2 + 1 = g 并不推出相交（需要 > g）。
