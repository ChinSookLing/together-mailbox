## §2 · Q-ERC1 修复（R019 证明缺口的补全）

**定理 Q-ERC1（重述）。** θ=p/q（最简，q≥3），w=r/q′（最简）。则整数格安全集非空：G_1≠∅ ⇔ q′≥2；G_1=∅ ⇔ q′=1（即 w∈ℤ）。

q′=1 ⇒ G_1=∅ 显然（‖kw‖=0）。下设 q′≥2，证 G_1≠∅。

**引理（相位轨道）。** 令 g=gcd(q,q′)，q₂=q′/g。固定 k₀ 使 ‖k₀θ‖≥1/5。则
 { frac((k₀+jq)w) : j∈ℤ } = { frac(k₀w)+j/q₂ : j } (mod 1)。
*证：* (k₀+jq)w = k₀w + j·qr/q′。写 q=gq₁，q′=gq₂，gcd(q₁,q₂)=1；gcd(r,q₂)=1。故 qr/q′=q₁r/q₂，且 q₁r 是 mod q₂ 的单位，{j·q₁r/q₂}={j/q₂}。∎

**情形 A：q₂≥2。** 轨道是间距 1/q₂≤1/2 的 q₂ 等分点；弧 A 长 3/5>1/2≥1/q₂，故轨道必交 A。取该 j，则 ‖(k₀+jq)w‖≥1/5，且 ‖(k₀+jq)θ‖=‖k₀θ‖≥1/5（因 qθ=p∈ℤ）。故 G_1≠∅。
（k₀ 的存在：q≥3 ⇒ |A_q|≥2>0，取任一即可。）

**情形 B：q₂=1 ⇔ q′|q。** 需 k mod q 使 kp mod q∈A_q 且 kr mod q′∈A_{q′}，其中 A_n={⌈n/5⌉,…,⌊4n/5⌋}。
先记两个事实：
 (F1) |A_q|≥q/2 对一切 q≥3。（|A_q|=⌊4q/5⌋−⌈q/5⌉+1 ≥ 3(q−1)/5；q≥6 时 ≥q/2；q=3,4,5 直接算 2,3,4。）
 (F2) |A_q|=q/2 仅当 q=6（由 3(q−1)/5≤q/2 ⇒ q≤6，逐查只有 6）。

- 若 |A_q|≥q′：j=kp mod q 跑遍 A_q（≥q′ 个连续整数），j mod q′ 跑遍 ℤ/q′；rp⁻¹ 是 mod q′ 单位，故 kr mod q′=r·p⁻¹j 跑遍 ℤ/q′，必落入非空的 A_{q′}。✓
- 若 |A_q|<q′：因 q′|q 且 q′<q ⇒ q′≤q/2≤|A_q|（F1），矛盾。故只能 q′=q。
- q′=q：两集 p⁻¹A_q、r⁻¹A_q ⊂ℤ/q 各含 |A_q|≥q/2 个元素。若 |A_q|>q/2，两子集必交。若 |A_q|=q/2，由 (F2) 只可能 q=6：A₆={2,3,4}，θ<½ 且 gcd(p,6)=1 ⇒ p=1；r∈{1,5}。p⁻¹A₆={2,3,4}；r=1 时 r⁻¹A₆={2,3,4}，交非空；r=5 时 5·{2,3,4}={4,3,2}，交非空。✓

综上 G_1≠∅。∎

**状态：PROOF CANDIDATE**（R019 的陈述正确，此处补齐了 CRT/密度步骤的严格证明）。

## §3 · Q-ERC2 审计：撤回未证充分条件，给出精确约化

R019 的 Q-ERC2 声称「充分条件 m/gcd(n,m)≥3」，其证明用了「三条件密度相乘 (3/5)³>0 ⇒ 交集非空」，**这在一般情形不成立**（密度为正不蕴含有限循环群上交集非空）。本席**撤回该充分条件**，改为精确约化：

设 w=n∈ℤ，θ=p/q，格 1/m，最小周期 Q=mq。令 **h=m/gcd(n,m)**。
- **d 条件精确化：** ‖kn/m‖≥1/5 ⇔ kn mod m∈A_m。因 kn mod m 只取 {0,gc,…}（步长 gc=gcd(n,m)），除以 m 即 {j/h}，故
 **d 安全 ⇔ k mod h ∈ A_h。**
- **b,c 条件：** 固定 r=k mod m（须使 r mod h∈A_h），令 k=r+jm。则
 kp mod mq 随 j 在陪集 β+mℤ/(mq)（β=rp mod m）上跑 q 个值；
 且 **b、c 相位分子之和 ≡ q·r (mod mq)**（因 kp+k(q−p)=kq≡qr mod mq）。
 故对每个合法 r，问题约化为：
 ∃v∈β+mℤ/(mq) 使 v∈A_{mq} 且 (qr−v) mod mq∈A_{mq}。  (★)

(★) 是一维区间交问题：A_{mq} 与 (qr−A_{mq}) 都是长度约 3mq/5 的区间，其交含约 mq/5 个连续整数；只要某个这样的连续段长度 ≥m，等差数列 β+mℤ 必命中。这给出**可检验的符号判据**，但本席**未**把它化简成一个对所有 q 成立的干净下界——那一步 **UNFINISHED**。

**结论：** Q-ERC2 的「iff」部分是同义反复，撤回；精确约化 (★) 成立（**CHECKED**，本段推导）；普适充分下界 **UNFINISHED**。非空性的真正普适保证由 §4 的 Q-GATE 给出。

## §4 · 定理 Q-GATE（确定性、有界的非空余数集选择器）

**陈述。** 对任意实数 0<a<b<c<d，令 t₀=F₄(b,c,d)（已认证 T4），τ\*=S·t₀，M=max(1−θ,w)，Q₀=⌈20M⌉。设 p/q 为 τ\* 的**最后一个分母 ≤Q₀ 的连分数渐近分数**（若 τ\* 本身分母 ≤Q₀，取 p/q=τ\*）。则：
 (i) q≤Q₀；
 (ii) τ=p/q 满足 ‖τθ‖,‖τ(1−θ)‖,‖τw‖≥1/5，即 **q∈{m:G_m≠∅}**（取 k=p）。
故 Q-GATE 在 **m≤⌈20·max(1−θ,w)⌉** 内确定性选出一个非空安全格。

**证明。**
1. 连分数标准不等式：若 p_j/q_j 是分母 ≤Q₀ 的最后一个渐近分数，下一个分母 q_{j+1}>Q₀，则
 |τ\*−p_j/q_j| < 1/(q_j q_{j+1}) < 1/q_{j+1} < 1/Q₀。
 （τ\* 有理且分母 >Q₀ 时，末项取等 1/(q_j q_{j+1})，仍 <1/Q₀；分母 ≤Q₀ 时误差 0。）
2. 因 Q₀=⌈20M⌉≥20M，有 1/Q₀ ≤ 1/(20M)。
3. 对 u∈{θ,1−θ,w}：|τu−τ\*u|=u|τ−τ\*| < u/Q₀ ≤ M/Q₀ ≤ 1/20。
4. T4 给 ‖τ\*u‖≥1/4，故 ‖τu‖ > 1/4−1/20 = 1/5。三项同 τ 同时成立。∎

**有终止步数上界：** 渐近分数分母至少按 Fibonacci 增长，故步数 ≤O(log Q₀)；每步是一次取整与一次倒数。这是**有限有界算法，不是无界搜索**。

**超越 LS/CLR v2 之处：** LS 与 CLR v2 都要求**有理参考形状**并直接取 τ\* 的分母（可能很大）。Q-GATE 用渐近分数把分母压到 ≤⌈20M⌉，且**对无理形状同样成立**（T4 对实数成立，连分数对无理数无限但截断有限）。这是 CLR v2 不能覆盖的情形。

**手算例（本席计算，仅演示机制，不作新覆盖主张）：** 取 a=1/7, b=1, c=101/100, d=2。则 S=201/100，θ=100/201，1−θ=101/201，w=200/201，M=200/201，Q₀=⌈4000/201⌉=20。T4 走 S1（d=2≤3b=3），t₀=1/4，τ\*=201/400。
连分数 201/400=[0;1,1,99,2]，渐近分数分母 1,1,2,199,400；末个 ≤20 的是 **1/2**（分母 2）。
验算：τθ=1/2·100/201=50/201≈0.249≥0.2；τ(1−θ)=101/402≈0.251≥0.2；τw=100/201≈0.498≥0.2。✓
LS 会取 τ\*=201/400 ⇒ m=400；Q-GATE 给 **m=2**。
（该点 b/a=7∈[6,9]、c/a=7.07∈[6,9]、d/a=14∈[11,14]，故同属已认证 TE-AL，t=1/(5a)=7/5 也成功。**新覆盖未主张**。）

**状态：PROOF CANDIDATE。**

## §5 · 存在性 vs 有效选取（主席要求区分）

- **存在性（簇）：** Q-NONEMPTY（§1.4）——对一切实数形状，安全相位存在。**不依赖**任何格选择，由 T4+稠密性。
- **有效选取（簇）：** Q-GATE（§4）——确定性、步数有界、分母有显式上界。这把存在性**升级**为可计算选取。
- **存在性 ≠ 有效选取的场合：** 对无理形状，Q-GATE 给出簇安全相位，但**没有精确周期可平移**，故无法用 §6 的微调装 a。此时「簇安全相位存在且可选」成立，「四位同时安全的确定性选取」**不**成立。这正是两者必须分开陈述的原因。

## §6 · a 装入门（未闭合，精确陈述）

给定簇安全 τ₀（来自 Q-GATE 或 LS），要再满足 ‖τ₀/s‖≥1/5。

- **有理形状：** 有精确周期 L=lcm(q,q′)，τ→τ+L 保持簇相位不变，a 相位每步增加 frac(L/s)。若 frac(L/s)≠0，用 PS 式单向微调（步数 ≤2/(5·min(x,1−x))+1）可装入 a。这**等价于**把 Q-GATE 的基相位接上 PS 的平移（本席手算主席反例形状 (7/20,2,5,6)：τ₀=7/8，L=7，x=frac(7/20)=7/20，n=⌈(25/160)/(7/20)⌉=1，t=9/8，四距离 63/160,1/4,3/8,1/4 ✓）。
- **例外：** frac(L/s)=0 且 frac(τ₀/s)∉A，则此轨道装不进 a。
- **无理形状：** 无 L，无法平移；a 门 **UNFINISHED**。

**结论：** 有理形状下 Q-GATE+PS 给出完整选择器（除 frac(L/s)=0 例外）；无理形状下仅簇门闭合。**一般 F₅：UNFINISHED。**

## §7 · 独立审阅：Opus LS（第一审）

**结论究竟是什么：** 对有理参考形状写成整数簇 0<B<C<E，令 τ\*=(B+C)F₄(B,C,E)，m=τ\* 的分母，Q=m(B+C)。断言 (P2) 成立、ρ\*=mτ\* mod Q 属安全余数集、三余量 ≥1/20，从而 CLR v2 的 R 非空。

**逐项核验（本席手算）：**
- (P2)：Q/m=B+C∈ℤ；Qθ₀/m=B∈ℤ；Qw₀/m=E∈ℤ。✓
- ρ\*∈R：在 τ\* 处，τ\*θ₀=B·F₄，τ\*(1−θ₀)=C·F₄，τ\*w₀=E·F₄；T4 给三者 ‖·‖≥1/4，余量 ≥1/4−1/5=1/20。✓
- **0∉R 自动成立：** 若 ρ\*=0，则 τ\*=j(B+C)，τ\*θ₀=jB∈ℤ ⇒ ‖τ\*θ₀‖=0，与 ≥1/4 矛盾。✓（Opus 未明写，但成立。）

**是否依赖未声明的存在性假设：** 否。只依赖已认证 T4（对实数无条件）与 CLR v2 引理 1。无隐藏假设。

**是否比 CLR v2 多解决一种情况：** **是。** CLR v2 把「R 非空」当作**输入数据**；LS 用 T4 **构造**出非空 R，去掉了该输入假设。这是实质性的加强。

**限制（必须写明）：** LS 只给出**单个**余数 ρ\*。若 CLR v2 只用这一个余数，则 |R|=1，G=Q=m(B+C)，条件 (i) 化为 **s≥5(B+C)/3**。所以 LS 是「存在性证书 + 单余数选择器」，其覆盖需 s 足够大；它**没有**计算完整 R_m 以缩小 G。

**四分类定位：** **已证充分条件**（对有理参考形状构造非空 R）。作为覆盖规则是**需非空安全集的选择器**之特例，但因自行构造非空集，强于单纯 #3。**非普适**（仅限有理参考形状，且覆盖受 s≥5(B+C)/3 限制）。

**审阅结论：PROOF VERIFIED**（附上述范围限定）。

## §8 · 独立审阅：Opus PS（第二审）

**结论究竟是什么：** 簇可公度 (b,c,d)=g(B,C,E)，P=1/g，t₀=F₄(b,c,d)，x=frac(aP)，φ₀=frac(at₀)。选择器 S0/S1/S2 输出 t=t₀+nP，n 闭式；例外 E_PS：x=0 且 φ₀∉A。断言四位 ≥1/5。

**证明核验：**
- b,c,d：uP=B,C,E∈ℤ ⇒ 相位不变，T4 给 ≥1/4≥1/5。✓
- a，S1（0<x≤½）：Δ=frac(1/5−φ₀)∈(0,2/5)，n=⌈Δ/x⌉ ⇒ nx∈[Δ,Δ+x)，frac(at)∈[1/5,1/5+x)⊂[1/5,7/10)⊂A。✓
- a，S2（½<x<1）：y=1−x∈(0,½)，Δ′=frac(φ₀−4/5)∈(0,2/5)，n=⌈Δ′/y⌉ ⇒ frac(at)∈(4/5−y,4/5]⊂A。✓
- 正性：n≥0，t₀>0。✓
- 步数界 n<2/(5e)+1（e=min(x,1−x)），**与 s 无关**。✓
- 例外 E_PS 正确：x=0 时 a 相位恒不变，机制内确实无解。✓

**未声明的存在性假设：** 无。只用 T4（无条件）。

**是否比 CLR v2 多解决一种情况：** **是，且方向不同。** CLR v2 需 s≥5G/(3m)（s 下界）；PS **对一切 s 成立**（除 E_PS），因为可沿周期任意平移 a。CLR v2 的尖管随 s 收窄，PS 不收窄。这是 CLR v2 不覆盖的大 s 区域。

**限制：** 支撑集是**可公度簇**，在 (s,θ,w) 空间中是可数多条线，**测度为零**，非开区域。

**四分类定位：** **已证充分条件 + 定义域内的真选择器**（给定可公度簇与 x≠0，闭式终止）。**非普适**（E_PS 例外 + 仅限可公度）。

**审阅结论：PROOF VERIFIED。**

## §9 · 独立审阅：Opus APS（第二审）

**结论究竟是什么：** 给参考整数 B<C<E，P=B/b（使 bP=B 精确），残差 r_c=cP−C，r_d=dP−E，x=frac(aP)，e=min(x,1−x)>0。用 PS 选择器（t₀ 取真实速度）得 n；若 n|r_c|≤‖ct₀‖−1/5 且 n|r_d|≤‖dt₀‖−1/5，则 t=t₀+nP 成功。保证版：(2/(5e)+1)·max(|r_c|,|r_d|)≤1/20。

**证明核验：**
- b：bP=B∈ℤ ⇒ 相位不变，‖bt‖=‖bt₀‖≥1/4。✓
- c：c(t₀+nP)=ct₀+nC+n r_c，相位偏移 n r_c；‖ct‖≥‖ct₀‖−|n r_c|≥1/5（由判据）。d 同理。✓
- a：同 PS，只用 x。✓
- 保证版：n<2/(5e)+1 ⇒ n|r_c|<(2/(5e)+1)max|r|≤1/20≤‖ct₀‖−1/5（T4 给 ‖ct₀‖≥1/4）。✓

**未声明的存在性假设：** e>0 已在陈述中**显式声明**为条件，非隐藏。但 **B,C,E 的确定性选择未给出**——Opus 自认 UNFINISHED，本席确认这是真实缺口：APS 的充分性成立，但「如何选 B 使残差小且 e 不太小」没有闭式规则。

**是否比 CLR v2 多解决一种情况：** **机制不同，可能新增覆盖。** CLR v2 是「三个近似锁 + 公共周期」；APS 是「b 精确锁 + c,d 近似锁」，漂移按**累积步数** n·r 控制，而非 CLR 的 τ·Δθ。对「b 与参考精确可公度、c,d 不精确」的形状，两者参数化不同。但**符号覆盖差集未算**，本席不能断言新增。

**四分类定位：** **条件性选择器**（需外部给定满足漂移界的参考三元组；选择 B 的规则缺失）。充分性证明成立，但**非**普适选择规则。

**审阅结论：PROOF VERIFIED**（作为条件性选择器；参考选择 UNFINISHED）。
