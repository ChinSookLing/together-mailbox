## §0 设定与基本事实（三条定理共用）

**设定**：
- V 为 k ≥ 1 个**两两不同的正实数**，不要求可公度；
- f_v(t) = ‖vt‖；g_V(t) = min_{v∈V} f_v(t)；
- 对 δ ∈ (0, ½]，S_δ(V) = { t > 0 : g_V(t) ≥ δ }。

**F1**：f_v 在每个区间 [j/(2v), (j+1)/(2v)]（j ∈ ℤ_{≥0}）上是线性的：
- j 为偶数时，f_v(t) = vt − j/2，斜率为 +v；
- j 为奇数时，f_v(t) = (j+1)/2 − vt，斜率为 −v。

断点集 D_v = (1/(2v))ℤ_{≥0} 在 ℝ 中局部有限。

**F2**：D = ⋃_v D_v 局部有限。在 D 的相邻两点之间，所有 f_v 都是线性的。g_V 是这些线性函数的最小值，所以 g_V 连续、分段线性，在每个有界区间内只有有限个断点，每一段的斜率都属于 {±v : v ∈ V}，**都不为零**。

**F3**（局部的单一表示）：对任意 t\* > 0，存在 ε > 0 和速度 v_L、v_R ∈ V，使得在 (t\* − ε, t\*) 上 g_V = f_{v_L}，在 (t\*, t\* + ε) 上 g_V = f_{v_R}，且 f_{v_L}、f_{v_R} 在这两段上都是线性的。

**F3 的证明**：取 ε 足够小，使 (t\* − ε, t\*) 不含 D 中的点。在这一段上，k 个 f_v 都是线性的。两个不同的线性函数至多相交一次，所以再缩小 ε，可使它们在 (t\* − ε, t\*) 上的大小次序固定，从而最小者是同一个 f_{v_L}。右侧同理。∎

## §1 定理 LM（下包络的局部极大点）

**陈述**：设 V 为任意有限个两两不同的正实数，t\* > 0 是 g_V 的局部极大点，即存在 ε > 0，使得 |t − t\*| < ε 时 g_V(t) ≤ g_V(t\*)。则：
- (a) 若 g_V(t\*) < ½，则存在 v ≠ v′ ∈ V 和整数 j ≥ 1，使 **t\* = j/(v + v′)**；
- (b) 若 g_V(t\*) = ½，则对每个 v ∈ V，t\* ∈ (2ℤ_{≥0} + 1)/(2v)。

**证明**：
1. 由 F3，取 v_L、v_R 与 ε。由 F2，g_V 在两侧的斜率 s_L、s_R 都不为零。因为 t\* 是局部极大点，s_L ≥ 0、s_R ≤ 0，所以 s_L > 0 > s_R。
2. 于是在左侧，f_{v_L} 处于上升段：由 F1，f_{v_L}(t) = v_L t − i，i ∈ ℤ_{≥0}。在右侧，f_{v_R} 处于下降段：f_{v_R}(t) = i′ − v_R t，i′ ∈ ℤ_{≥1}。
3. 由连续性，g_V(t\*) = v_L t\* − i = i′ − v_R t\*，所以 (v_L + v_R)t\* = i + i′。
4. 若 v_L = v_R = v，则 f_v 在 t\* 处由升转降，即 t\* 是 f_v 的峰，f_v(t\*) = ½，从而 g_V(t\*) = ½。所以在 (a) 的假设下 v_L ≠ v_R。又因为 t\* > 0，有 j = i + i′ ≥ 1。这证明 (a)。
5. (b)：g_V(t\*) = ½ 意味着每个 f_v(t\*) = ½，即 frac(vt\*) = ½。∎

## §2 定理 HS（与门槛无关的命中骨架）

**定义**：C(V) = { j/(v+v′) : v ≠ v′ ∈ V，j ∈ ℤ_{≥1} } ∪ { (2j+1)/(2v) : v ∈ V，j ∈ ℤ_{≥0} }。

**陈述**：对任意有限个两两不同的正实数 V 和任意 δ ∈ (0, ½]，S_δ(V) 的每一个连通分量 K 都与 C(V) 相交。特别地，S_δ(V) ≠ ∅ ⇔ S_δ(V) ∩ C(V) ≠ ∅。

**证明**：
1. **K 是 (0, ∞) 中的紧区间**（可能退化成一点）。设 v₀ = min V。S_δ(V) ⊂ { t > 0 : f_{v₀}(t) ≥ δ } = ⋃_{i≥0} [(i+δ)/v₀, (i+1−δ)/v₀]。右边是互不相交的紧区间，相邻两个之间相隔 2δ/v₀ > 0（δ = ½ 时退化为点 (2i+1)/(2v₀)）。所以 K 包含在其中某一个之内，是有界的；又 S_δ(V) 是闭集，所以 K 是闭的。
2. **局部有限结构**：由 F2，{g_V ≥ δ} 在每个有界区间内是有限个闭区间（含退化区间）的并。因此 K 的每个端点在 K 之外的那一侧，都有一个小邻域落在 S_δ(V) 之外，即那里 g_V < δ。
3. 设 g_V 在 K 上的最大值在 t\* 处取得（K 紧，g_V 连续）。
   - **若 t\* 是 K 的内点**：则 t\* 是 g_V 的局部极大点。
   - **若 t\* 是 K 的端点**（或 K 退化成一点）：由第 2 步，紧邻 K 外侧有 g_V < δ，再由连续性，端点处 g_V(t\*) = δ。于是在 K 上 max g_V = δ，又 g_V ≥ δ，所以 g_V 在 K 上恒等于 δ。由 F2，g_V 的斜率不为零，不可能在非退化区间上为常数，所以 K = {t\*}。此时 g_V 在 t\* 两侧都 < δ，t\* 是严格局部极大点。
4. 由 LM，t\* ∈ C(V)，而 t\* ∈ K。∎

## §3 定理 ACC（算术候选证书）

### 3.1 可公度版本 ACC-com
**假设**：存在 g > 0，使 V ⊂ gℤ。取最大的这样的 g，P = 1/g，N_v = v/g ∈ ℤ，σ = Σ N_v。

**定义**：
- C_P(V) = C(V) ∩ (0, P/2]；
- κ(V) = max_{t∈C_P(V)} g_V(t)；
- **F^{ACC}(V) = min{ t ∈ C_P(V) : g_V(t) = κ(V) }**。

**陈述**：
- (i) κ(V) = sup_{t>0} g_V(t)，并且 F^{ACC}(V) 达到这个上确界；
- (ii) 对任意 δ ∈ (0, ½]：S_δ(V) ≠ ∅ ⇔ κ(V) ≥ δ；此时 F^{ACC}(V) ∈ S_δ(V)；
- (iii) **精确计数**（计重数）：|C_P(V)| ≤ Σ_{v<v′} ⌊(N_v + N_{v′})/2⌋ + Σ_v ⌊(N_v + 1)/2⌋ ≤ k(σ + 1)/2；
- (iv) 计算量为 O(k·|C_P(V)|) = O(k²(σ+1)) 次精确运算，只需对每个候选点求一次 g_V。

**证明**：
1. **(i)**：
   - g_V 以 P 为周期（每个 vP ∈ ℤ），并且 g_V(−t) = g_V(t)，所以 g_V(P − t) = g_V(t)。因此 g_V 在 (0, ∞) 上的值都在 (0, P/2] 上取到；连续函数在 [0, P/2] 上有最大值，而 g_V(0) = 0，所以最大值在某个 t₀ ∈ (0, P/2] 处取得。
   - t₀ 是 g_V 在 ℝ 上的全局最大点，因而是局部极大点；由 LM，t₀ ∈ C(V)，所以 t₀ ∈ C_P(V)。
   - 因此 κ(V) ≥ g_V(t₀) = sup g_V；反方向显然。
   - F^{ACC}(V) 是 C_P(V) 中达到 κ 的最小者，在有限集上定义良好。
2. **(ii)**：由 (i)，S_δ ≠ ∅ ⇔ sup g_V ≥ δ ⇔ κ ≥ δ。
3. **(iii)**：
   - j/(v+v′) ≤ P/2 ⇔ j ≤ (N_v + N_{v′})/2；
   - (2j+1)/(2v) ≤ P/2 ⇔ 2j + 1 ≤ N_v。

   求和后，再用 Σ_{v<v′}(N_v + N_{v′}) = (k−1)σ 与 Σ(N_v + 1) = σ + k，得 ((k−1)σ + σ + k)/2 = k(σ+1)/2。
4. **(iv)**：每个候选点求一次 g_V 需要 O(k) 次运算。∎

**勘误**：R025 写的上界 kσ/2 **不正确**。反例 V = {1}：C_P = {1/2}，有 1 个候选，而 kσ/2 = 1/2。正确的上界是 k(σ+1)/2。
- 按计重数公式：V₁ = 30，V₂ = 83，V₃ = 341；去重后的实际数目为 20 / 77 / 321（Hesper 已确认）。
- 粗上界 k(σ+1)/2 分别为 32、86、344（本席本轮计算）。

### 3.2 实数版本 ACC-real
**定义**：把 C(V) 按从小到大排列，相等的点合并。这是 k(k−1)/2 + k 条等差数列的确定性合并。依次检查，输出第一个满足 g_V(t) ≥ δ 的 t。

**陈述**：
- (i) 当且仅当 S_δ(V) ≠ ∅ 时，算法终止。
- (ii) 输出的 t 位于 S_δ(V) 的**最早**连通分量中。
- (iii) 若已知某个 T ≥ inf S_δ(V)，则步数 ≤ k(T + 1/v_min)Σv + k/2（由 HS 的计数式）。

**证明**：
- (i)：若 S_δ 为空，没有候选点满足条件，算法不终止。若非空，由 HS，最早的分量 K₁ 含有某个候选点 c₁；而 (0, c₁] 中只有有限个候选点，所以算法在有限步内终止。
- (ii)：任何满足条件的候选点都属于 S_δ，因而属于某个分量。比 c₁ 更早的候选点若满足条件，只能属于 K₁（K₁ 之前没有分量）。
- (iii)：K₁ 位于 v_min 的某一段安全弧内，所以 c₁ ≤ inf S_δ + 1/v_min ≤ T + 1/v_min。再把 T + 1/v_min 代入 HS 的计数式，得到 k(T + 1/v_min)Σv + k/2。∎

## §4 骨架的 n → n+1 更新规则

**定理 UP（精确更新）**：对任意 u > 0（u ∉ V），有
C(V ∪ {u}) = C(V) ∪ { j/(u+v) : v ∈ V，j ≥ 1 } ∪ { (2j+1)/(2u) : j ≥ 0 }，
并且在每个点上 g_{V∪u}(t) = min(g_V(t), ‖ut‖)。

**证明**：直接由 C 的定义，以及 g 是最小值函数。∎

- 新增的只有 k + 1 条等差数列，不需要重新扫描时间轴。门槛从 1/n 降到 1/(n+1) 时，骨架**不变**（HS 对所有 δ 成立）。
- **可公度时的代价**：设 P′ 为 V ∪ {u} 的周期。新的候选集 C_{P′}(V ∪ u) 包括：
  - 旧数列截断到 (0, P′/2]；
  - 新增 Σ_v ⌊(N′_u + N′_v)/2⌋ + ⌊(N′_u + 1)/2⌋ 个点，其中 N′ 以 P′ 为单位计算；
  - 每个点的值用一次 min 更新。

**定理 PR（按最终门槛剪枝是安全的）**：固定最终的跑者数 N_f，令 δ_f = 1/N_f。在递推的任何阶段，丢掉所有满足 g_V(t) < δ_f 的候选点 t，不会丢失最终层的任何成功候选。

**证明**：
1. 每加入一个速度，g 只会变小或不变（取最小值），所以对之后的任何 V′ ⊇ V，都有 g_{V′}(t) ≤ g_V(t) < δ_f。
2. 门槛 1/m 随层数增加而递减，到最终层为 δ_f；所以这样的 t 在之后任何一层（门槛 ≥ δ_f）都不可能安全。
3. 新出现的候选点只来自新增的数列，由 UP 单独生成，不受剪枝影响。∎

**结论**：对固定的 N_f，带剪枝的骨架是一个**真正的** n → n+1 更新规则：确定性、显式，不需要重新扫描时间轴。
- 它保证 (A) 与 (B) 能逐层传递；
- 但它**不保证**剪枝之后集合非空，那就是 (C)。

## §1 · 区间证书与 ACC 的比较

### §1.1 两证书的定义

$$C(V)=\Bigl\{\tfrac{j}{v{+}v'}:v\ne v'\in V,\,j\in\mathbb{Z}_{>0}\Bigr\}\cup\Bigl\{\tfrac{2j{+}1}{2v}:v\in V,\,j\in\mathbb{Z}_{\ge0}\Bigr\}.$$

**区间证书与 ACC 的输出关系：** 区间证书的中点**不一定**是全局最大点，但必在某安全区间内（若 $S_{\delta'}\ne\emptyset$）。ACC 输出全局最大点，**必然**在某安全区间内。两者都给出安全时间（若非空），但 ACC 给的是**最优**安全时间。

## §4 · 骨架候选能否直接选取（不全枚举）

### §4.1 可公度下：断点求值优于全候选枚举

**全候选枚举（ACC 原文）：** 在 $C(V)\cap(0,P/2]$ 中逐点求 $m_V$，取最大。候选数 $|C(V)\cap(0,P/2]|\le k\sigma/2$（Opus §3）。复杂度 $O(k^2\sigma)$。

**断点求值（本席观察）：** 由 LM，全局最大点是局部极大点，属 $C(V)$；由 SPC (S1)，$m_V$ 的最大值在**断点**处取得。断点数 $|B_V|\le k(\sigma+1)$（SZ），且 $B_V\subset C(V)$（LM）。故只需在 $B_V$ 上求值，复杂度 $O(k\sigma)$，**优于**全候选枚举。

**命题（本席）：** 可公度下，选最优安全候选只需枚举 $B_V$（$O(k\sigma)$ 次 $m_V$ 求值），不需枚举全部 $C(V)$。

### §4.2 能否「直接命中」而不枚举？

**问：** 是否存在闭式规则，一步给出最优候选（跳过所有枚举）？

**答：可公度下，否（一般情形）。** 理由：最优断点的位置依赖 $V$ 的具体数值，不同 $V$ 的最优断点来自不同的 $(v,v')$ 对。无统一闭式。

**但：** 对**特殊族**可直接命中。例：
- TF 族 $V=\lambda(1,\ldots,N)$：最优 $=1/(\lambda(N{+}1))$，闭式。
- $V_2=(1,2,9,30)$：最优 $9/31=9/(1{+}30)$，来自最慢 $+$ 最快对。

**一般闭式直接选取：UNFINISHED。**
