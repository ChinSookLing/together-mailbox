## §1 ACC 修正上界的逐式证明（自审写法，供复核）

**设定**：
- V ⊂ gℤ，取最大的 g；P = 1/g；N_v = v/g ∈ ℤ_{≥1}，gcd(N_v) = 1；σ = Σ N_v；k = |V|；
- C_P(V) = C(V) ∩ (0, P/2]，按计重数计算（同一个点若出现在两个数列中，计两次）。

**引理 CNT**：|C_P(V)| ≤ Σ_{v<v′} ⌊(N_v + N_{v′})/2⌋ + Σ_v ⌊(N_v + 1)/2⌋ ≤ k(σ + 1)/2。并且当所有 N_v 都是奇数时，第二个不等式取等号。

**证明**：
1. **第一类**：t = j/(v+v′)，j ≥ 1。条件 t ≤ P/2 等价于 j ≤ (v+v′)P/2 = (N_v + N_{v′})/2。符合条件的正整数 j 恰好有 ⌊(N_v + N_{v′})/2⌋ 个。
2. **第二类**：t = (2j+1)/(2v)，j ≥ 0。条件 t ≤ P/2 等价于 2j + 1 ≤ vP = N_v，即 j ≤ (N_v − 1)/2。符合条件的非负整数 j 恰好有 ⌊(N_v − 1)/2⌋ + 1 = ⌊(N_v + 1)/2⌋ 个。
3. **求和**：用 ⌊x⌋ ≤ x，得
   - Σ_{v<v′} (N_v + N_{v′})/2 = (k−1)σ/2，因为每个 N_v 恰好出现在 k−1 对之中；
   - Σ_v (N_v + 1)/2 = (σ + k)/2。

   相加：((k−1)σ + σ + k)/2 = k(σ + 1)/2。
4. **取等**：所有 N_v 都是奇数时，N_v + N_{v′} 是偶数，N_v + 1 也是偶数，两处取整都没有损失。∎

**取等实例**（手算）：V = {1, 3}，g = 1，P = 1。
- 第一类，v + v′ = 4，j ≤ 2：候选为 1/4、2/4；
- 第二类，v = 1：j ≤ 0，候选为 1/2；v = 3：j ≤ 1，候选为 1/6、3/6。

计重数共 5 个，等于 k(σ+1)/2 = 2·5/2 = 5。去重后为 {1/6, 1/4, 1/2}，共 3 个（1/2 出现了三次）。

**对 DeepSeek R026 ACC 计数核验的意见：GAP FOUND**。
- DeepSeek 把第二类的个数写成"约 N_v/2"，于是得到 kσ/2。但准确的个数是 ⌊(N_v+1)/2⌋：当 N_v 为奇数时，它等于 (N_v+1)/2 > N_v/2。
- 反例 V = {1}：候选只有 1/2 这一个，而 kσ/2 = 1/2。
- DeepSeek 对 ACC 其余部分（构造、更新、选择、ACC = SPC）的核验不受影响。

## §2 定理 UP（完整版）

**假设**：V 为 k 个两两不同的正实数，u > 0，u ∉ V。

**UP-1（几何部分，任意实数）**：
- C(V ∪ {u}) = C(V) ∪ N(V, u)，其中 N(V, u) = { j/(u+v) : v ∈ V，j ≥ 1 } ∪ { (2j+1)/(2u) : j ≥ 0 }；
- 对一切 t > 0，g_{V∪u}(t) = min(g_V(t), ‖ut‖)。

**证明**：
- 第一式：C 的定义只取决于速度对和单个速度；V ∪ {u} 的速度对，恰好是 V 内部的速度对加上 (u, v)。
- 第二式：最小值函数的性质。∎

**UP-2（周期性；可公度时的展开）**：若 V ⊂ gℤ，P = 1/g，则 C(V) 在平移 t ↦ t + P 下不变，在 t ↦ P − t 下也不变；g_V 同样如此。

**证明**：
- j/(v+v′) + P = (j + N_v + N_{v′})/(v+v′)；P − j/(v+v′) = (N_v + N_{v′} − j)/(v+v′)。两者仍是第一类点（后者只要分子 ≥ 1）。
- (2j+1)/(2v) + P = (2j + 1 + 2N_v)/(2v)，分子仍为奇数；P − (2j+1)/(2v) = (2N_v − 2j − 1)/(2v)，分子同样为奇数。
- g_V 的周期性和对称性见 R023 引理 S。∎

**UP-3（可公度更新的算法与复杂度）**：
- **假设**：u/g ∈ ℚ，新周期 P′ = q′P（q′ ∈ ℤ_{≥1}，见 R024 §1），以 P′ 为单位的整数为 N′_v = q′N_v，N′_u = uP′；σ′ = Σ N′_v + N′_u。
- **输入**：旧表 {(t, g_V(t)) : t ∈ C_P(V)}，以及 u。
- **步骤**：
  1. 由 UP-2，把旧数列中位于 (0, P′/2] 的点，经平移、反射还原到 (0, P/2]，查出 g_V 的值，不需要重新计算；
  2. 列出 N(V, u) ∩ (0, P′/2]；
  3. 旧点的值为 min(g_V, ‖u·‖)；新点直接计算 g_{V∪u}。
- **正确性**：由 UP-1 与 UP-2，输出恰好是 C_{P′}(V ∪ u) 及其上 g_{V∪u} 的值。
- **复杂度**：
  - 旧点 ≤ Σ_{v<v′∈V} ⌊(N′_v + N′_{v′})/2⌋ + Σ_{v∈V} ⌊(N′_v + 1)/2⌋ 个，每个 O(1) 次运算；
  - 新点 ≤ Σ_v ⌊(N′_u + N′_v)/2⌋ + ⌊(N′_u + 1)/2⌋ 个，每个 O(k+1) 次运算。
  - 总计 O(|旧点| + (k+1)·|新点|)，其中总点数 ≤ (k+1)(σ′+1)/2（由 CNT）。

**必须写明**：UP-3 需要列出新半周期内的**全部**候选点。旧点的数目随 q′ 线性增长，即需要展开 q′/2 个旧周期。

**UP-4（实数，有界窗口）**：对任意 T > 0，C(V ∪ u) ∩ (0, T] 可以由 C(V) ∩ (0, T] 加上 N(V, u) ∩ (0, T] 得到。个数 ≤ (k+1)T(Σv + u) + (k+1)/2。（由 R026 HS 的计数式：每条数列在 (0, T] 中的点数不超过 T 乘以它的密度。）

## §3 定理 PR（完整版）

**假设**：
- 速度序列 V₁ ⊂ V₂ ⊂ … ⊂ V_K，其中 |V_k| = k；
- 第 k 层的门槛 δ_k = 1/(k+1)，单调递减；
- 最终门槛 δ_f = δ_K。

**剪枝规则**：Ĉ₁ = C(V₁) ∩ S_{δ_f}(V₁)；Ĉ_{k+1} = { t ∈ Ĉ_k ∪ N(V_k, u_{k+1}) : g_{V_{k+1}}(t) ≥ δ_f }。

**定理 PR**：
- (i) **恒等式**：对每个 k，Ĉ_k = C(V_k) ∩ S_{δ_f}(V_k)；
- (ii) **不丢失中间层的成功候选**：C(V_k) ∩ S_{δ_k}(V_k) ⊆ Ĉ_k；
- (iii) **最终层**：S_{δ_f}(V_K) ≠ ∅ ⇔ Ĉ_K ≠ ∅。

**证明**：
1. **(i)**，对 k 归纳。k = 1 是定义。
   - **⊆**：设 t ∈ Ĉ_{k+1}。若 t ∈ Ĉ_k，由归纳假设 t ∈ C(V_k) ⊂ C(V_{k+1})；若 t ∈ N(V_k, u)，由 UP-1，t ∈ C(V_{k+1})。又 g_{V_{k+1}}(t) ≥ δ_f，所以 t ∈ S_{δ_f}(V_{k+1})。
   - **⊇**：设 t ∈ C(V_{k+1})，且 g_{V_{k+1}}(t) ≥ δ_f。由 UP-1，t ∈ C(V_k) 或 t ∈ N(V_k, u)。若 t ∈ C(V_k)，则 g_{V_k}(t) ≥ g_{V_{k+1}}(t) ≥ δ_f，所以由归纳假设 t ∈ Ĉ_k。两种情形下 t 都在候选池里，并且通过了门槛，所以 t ∈ Ĉ_{k+1}。
2. **(ii)**：δ_k ≥ δ_f，所以 S_{δ_k} ⊆ S_{δ_f}，再用 (i)。
3. **(iii)**：由 (i) 与 HS。∎

**复杂度**：每层只比 UP 多一次比较。剪枝可以缩小集合，但本席**没有**证明 |Ĉ_k| 有比 UP 更好的上界。

**适用范围**：
- 可公度：用 UP-3，在 (0, P′/2] 内执行；
- 实数：用 UP-4，在 (0, T] 内执行，此时 (iii) 改为 S_{δ_f} ∩ (0, T] 中存在分量 ⇔ Ĉ_K^T ≠ ∅；
- 不需要任何非空假设，但**也不提供**非空保证。

## §4 局部极大点能否给候选排序，使"早"的候选必然达标

### 4.1 被否定的两种排序（手算反例）
- **"总有一个成功候选与 v_min 配对"**，即形如 j/(v_min + v′)：**DISPROVED**。反例 V = (1, 3, 4)，δ = 1/4。
  - j/(1+3)：1/4 时 ‖4·1/4‖ = 0；2/4 时 ‖4·1/2‖ = 0。
  - j/(1+4)：1/5 < 1/4；2/5 时 ‖3·2/5‖ = 1/5 < 1/4。
  - 两族都不安全；而 3/7 = 3/(3+4) 是安全的，三个距离为 3/7、2/7、2/7。
- **"总有一个成功候选与 (v_min, v_max) 配对"**：**DISPROVED**。反例 V = (1, 2, 4)，δ = 1/4。
  - j/5：1/5 < 1/4；2/5 时 ‖4·2/5‖ = 1/5 < 1/4。（只需检查 j ≤ 2，因为周期为 1，由对称性 3/5、4/5 同理。）
  - 而 1/3 = 1/(1+2) 是安全的，三个距离为 1/3、1/3、1/3。

### 4.2 首窗假设 FW（新提出）
**FW_k**：对任意 k 个两两不同的正实数 V，S_{1/(k+1)}(V) ∩ (0, 1/v_min) ≠ ∅。

也就是说，在最慢跑者的**第一个**安全窗口 [δ/v_min, (1−δ)/v_min] 内，就已经有全员安全的时间。

**FW_1、FW_2 已手证**：
- **k = 1**：t = 1/(2v)。
- **k = 2**：设 a < b，δ = 1/3。
  - **若 b ≥ 2a**：窗口 [1/(3a), 2/(3a)] 的长度为 1/(3a) ≥ 2/(3b)，所以 b 的相位在这段窗口内扫过的弧长 ≥ 2/3，因此有一点满足 ‖bt‖ ≥ 1/3。（这是 R024 GLC(i) 的论证。）
  - **若 a < b < 2a**：取 t = 1/(a+b)。由 b < 2a 与 a < 2b，t 落在窗口内；并且 ‖at‖ = a/(a+b) ≥ 1/3，‖bt‖ = 1 − b/(a+b) = a/(a+b) ≥ 1/3。∎
- **k ≥ 3**：UNFINISHED。
- **计算印证**（CHECKED，非证明）：
  - k = 2, 3, 4，速度为 1…15 的全部整数组（分别有 105、455、1,365 组），首窗**无一失败**；
  - k = 5，速度为 1…13 的全部整数组（1,287 组），只检查第一类候选，首窗也无一失败；
  - MZ 族 λ(1, …, N) 的解 1/(λ(N+1)) 在首窗内。
- **可能已有文献**：本席 WEB OFF，未核验。

**FW 不是什么**：FW 比 NE **更强**（FW ⇒ NE）。所以它并没有绕开存在性问题，只是把存在性问题加强成一个**有界**的形式。

### 4.3 定理 FWS（首窗选择器；在 FW 下的显式有限选择）
**定义**：
- C₁(V) = C(V) ∩ (0, 1/v_min]；
- **F^{FW}(V) = C₁(V) 中使 g_V 最大的最小者。**

**定理 FWS**：
- (i) |C₁(V)| ≤ Σ_{v<v′} ⌊(v+v′)/v_min⌋ + Σ_v ⌊v/v_min + ½⌋ ≤ kΣv/v_min + k/2。这个上界只依赖速度比，与缩放无关。
- (ii) 若 FW_k 对 V 成立，则 F^{FW}(V) ∈ S_{1/(k+1)}(V)。
- (iii) 计算量为 O(k·|C₁(V)|) 次比较。需要能对实数做精确比较（例如代数数速度）。

**证明**：
- (i)：由 HS 的计数式，取 T = 1/v_min。
- (ii)：
  1. 由 FW，存在 t₀ ∈ S ∩ (0, 1/v_min)。t₀ 所在的分量 K 位于 v_min 的某一个安全弧 [(i+δ)/v_min, (i+1−δ)/v_min] 中；由于 t₀ < 1/v_min，只能 i = 0，所以 K ⊂ (0, 1/v_min]。
  2. 由 HS，K ∩ C(V) ≠ ∅，所以 C₁(V) 中有一点 c 满足 g_V(c) ≥ δ。
  3. F^{FW} 取最大值，所以 g_V(F^{FW}) ≥ g_V(c) ≥ δ。∎

**必须写明**：
- FWS 枚举 (0, 1/v_min] 中的**全部**候选点，个数随 v_max/v_min 增长；
- 它不是"直接公式"；
- 它的成功依赖**未证明的** FW_k。

### 4.4 FW 能否在归纳中保持
- 加入一个**更快**的 u（u > v_max）时，v_min 不变，首窗不变。由 PR，首窗内的剪枝骨架可以逐层更新（UP-4，取 T = 1/v_min）。但"更新后仍然非空"正是 FW_{k+1}，不能从 FW_k 推出。
- 加入一个**更慢**的 u 时，首窗扩大为 (0, 1/u)，需要重新展开。
- 结论：**FW 不会自动保持**。
