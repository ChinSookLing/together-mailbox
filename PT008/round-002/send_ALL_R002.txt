1. 研究目标（Mission）
PT-008 · Time Forge 试图寻找一种统一构造时间公式（Unified Constructive Time Formula），能够从任意有限数量跑者的不同速度中，直接产生一个符合孤独跑者条件的时间。
我们不把判定公式、隐式最优化问题或穷举搜索称为构造公式。
Round 002 从 XY 三角波出发，研究新增跑者时，能否通过调整旧成功时间得到新成功时间。
本轮目标不是解决一般孤独跑者猜想，而是建立严格可靠的局部构造机制，并找出它失效的原因。

2. 完整数学设定（Setting）
圆形跑道周长为 1。所有跑者同时从同一起点出发，速度恒定且两两不同。
选择一位参考跑者，其他相对速度组成有限集合：
V = {u_1, ..., u_{n-1}},  n >= 2.
所有 u_i != 0，且相互不同。
令
d_u(t) = ||u t||,   ||x|| = min_{k in Z} |x - k|.
时间 t >= 0，允许任意连续实数，不得在缺少周期性证明时限制为 [0,1)。
假设已经知道一个成功时间 t0，满足
d_u(t0) >= 1/n  对所有 u in V.
新增相对速度 w not in V ∪ {0}，总人数变成 (n+1)，门槛变为 1/(n+1)。
目标是构造 t1 >= 0，使
min_{u in V ∪ {w}} ||u t1|| >= 1/(n+1).

3. 主席提出的证明候选 L2
L2 · Fast-Newcomer Moving-Window Lemma
设
M = max_{u in V} |u|,   h = 1/(n(n+1)M).
则原有跑者在整个区间
I = [t0 - h, t0 + h]
内，都满足新门槛。
进一步，如果
[boxed]  |w| >= nM,
则存在 t1 in I，使新增跑者也安全。
而且可以明确构造 t1，不需要时间网格搜索。
评级：PROOF CANDIDATE。

4. 主席证明草稿
第一部分：旧跑者仍然安全。
距离到最近整数的函数具有 Lipschitz 性质：
| ||x|| - ||y|| | <= |x - y|.
因此对于所有旧速度 u：
d_u(t) >= d_u(t0) - |u| |t - t0|.
在窗口内：
d_u(t) >= 1/n - M h = 1/(n+1).

第二部分：窗口不会延伸到负时间。
因为任意旧速度满足
||u t0|| <= |u| t0 <= M t0,
且至少达到 1/n，所以
t0 >= 1/(nM) > h.
因此 I ⊂ (0, ∞)。

第三部分：让新跑者安全。
记 delta = 1/(n+1).
如果 ||w t0|| >= delta，直接令 t1 = t0。
否则，取最接近 w t0 的整数 k。
选择方向 sigma in {-1, 1}，令
t1 = (k + sigma*delta) / w,
选择使 |t1 - t0| 最小的方向。
于是：
|t1 - t0| = (delta - ||w t0||) / |w| <= 1/((n+1)|w|).
若 |w| >= nM，则
|t1 - t0| <= h.
所以全部旧跑者仍然安全，新跑者恰好达到距离 delta。
证明待 Opus 独立审阅；主席不得自行标为 PROVED。
