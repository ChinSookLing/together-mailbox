## SECTION A — 精确命题

### A1 窗口锚定引理 WL（五跑者）
设 c < 4a，且 **d ≥ 2ac/(4a − c)**。令 t_L = 1/(5a)，X = d·t_L。
- 若 ‖X‖ ≥ 1/5，输出 t = t_L；
- 否则令 k = round(X)，输出 **t = (k + 1/5)/d**。

则 t > 0，且四个距离都 ≥ 1/5。

### A2 簇定理 K5
设 **c ≤ 8a/3**。定义
- d ≤ 4a 时：t = 1/(a+d)（TN，PROVED）；
- d > 4a 时：t = WL(a,c,d)。

则 F₅ 对所有满足条件的 0 < a < b < c < d 成立。

### A3 一般 n 的窗口锚定 GW(n)
n 名跑者（n ≥ 3），非零速度为 m = u₁ < … < M = u_{n−2} < w = u_{n−1}，门槛 δ = 1/n。
若 M < (n−1)m，且 **w ≥ 2mM/((n−1)m − M)**，则：
- t_L = δ/m；
- 若 ‖wt_L‖ ≥ δ，取 t = t_L；否则取 t = (round(wt_L) + δ)/w。

所得 t 满足全部 ‖u_i t‖ ≥ δ。

### A4 一般 n 的簇定理 K_n
若 **M ≤ ((n−1)²/(n+1))·m**，则：w ≤ (n−1)m 时取 t = 1/(m+w)（TN）；否则取 GW(n)。这对任意 w > M 都给出显式 F_n。
- n = 4：门槛为 9/5；
- n = 5：门槛为 16/6 = 8/3；
- n = 6：门槛为 25/7。

### A5 递归类 𝒦_n（跨轮问题）
𝒦₃ = 全部两速度集合（F₃，PROVED）。对 n ≥ 4，若 V 满足以下之一，则 V ∈ 𝒦_n：
- (i) V 满足 K_n 的簇条件；
- (ii) w ≥ (n−1)·M，且 V∖{w} ∈ 𝒦_{n−1}。

对 𝒦_n 中的每个 V，F_n 由以下递归给出：(i) 用 K_n；(ii) 用 Nudge(F_{n−1}(V∖{w}); w, 1/n)。

### A6 (a,c) 锚点引理 AC1
若 c ≤ 4a 且 frac(d/(a+c)) ∈ A，则 t = 1/(a+c) 成功。

### A7 障碍：不看 b 的 (a,c) 锚相
称一条规则"不看 b"，如果它输出的 t = τ/(a+c) 只依赖 a、c、d，并且要求对 (a,c) 之间**所有** b 都成功。
在 c = 4a 处，满足要求的 τ 只有 τ = 1；而当 frac(d/(5a)) ∉ A 时，τ = 1 失败。所以在 c = 4a 上，不存在这样的规则。

## SECTION B — 证明

### B1 WL（A1）
**窗口**：W = [1/(5a), 4/(5c)]。由 c < 4a，W 非空。对 t ∈ W：
- at ∈ [1/5, 4a/(5c)] ⊂ [1/5, 4/5)，因为 a < c；
- ct ∈ [c/(5a), 4/5] ⊂ (1/5, 4/5]，因为 a < c < 4a；
- bt 介于 at 与 ct 之间，所以也在 A 内。

**d 的处理**：
- 若 ‖X‖ ≥ 1/5，t = t_L ∈ W，完成。
- 否则 X ∈ (k − 1/5, k + 1/5)，其中 k = round(X)。目标点 k + 1/5 ≥ X，所以 t = (k + 1/5)/d ≥ X/d = t_L，即**只向右移**。位移 t − t_L = (k + 1/5 − X)/d < (2/5)/d。
- ‖dt‖ = ‖k + 1/5‖ = 1/5。

**仍在 W 内**：只需 t_L + 2/(5d) ≤ 4/(5c)，即 1/a + 2/d ≤ 4/c，即 2/d ≤ (4a − c)/(ac)，即 d ≥ 2ac/(4a − c)。这正是假设。
t ≥ t_L > 0。∎

### B2 K5（A2）
- d ≤ 4a：由 TN（PROVED，最大速度 d ≤ (5−1)·a）。
- d > 4a：需要验证 WL 的条件。
  - c ≤ 8a/3 < 4a。✓
  - d > 4a ≥ 2ac/(4a − c)。最后一步 ⟺ 4a(4a − c) ≥ 2ac ⟺ 16a² ≥ 6ac ⟺ c ≤ 8a/3。✓

所以 WL 适用。∎

### B3 GW(n) 与 K_n（A3、A4）
**GW(n)**：窗口 W = [δ/m, (1−δ)/M]。对 t ∈ W，u_i t ∈ [δ, (1−δ)] 对 i ≤ n−2 成立，因为 u_i 介于 m 与 M 之间。W 非空 ⟺ M/m ≤ (1−δ)/δ = n−1。
其余与 B1 相同：位移 < 2δ/w。仍在 W 内 ⟺ δ/m + 2δ/w ≤ (1−δ)/M。代入 δ = 1/n 并整理：
2/w ≤ ((n−1)m − M)/(mM)，即 w ≥ 2mM/((n−1)m − M)。∎

**K_n**：w ≤ (n−1)m 时用 TN（PROVED）。否则 w > (n−1)m，而
(n−1)m ≥ 2mM/((n−1)m − M) ⟺ (n−1)((n−1)m − M) ≥ 2M ⟺ M ≤ (n−1)²m/(n+1)。
所以 GW 适用。另外 (n−1)²/(n+1) < n−1，所以 W 非空。∎

### B4 𝒦_n（A5）
对 n 归纳。
- (i) 由 K_n 直接成立。
- (ii) 由归纳假设，t₀ = F_{n−1}(V∖{w}) 对 n−1 名跑者成功，即全部距离 ≥ 1/(n−1)。再由 L2（PROVED；旧人数 n−1，M 为旧速度中的最大值，条件 |w| ≥ (n−1)M），Nudge 后得到新门槛 1/n。∎

本命题**只**证明对类 𝒦_n 成立，**不**声称 𝒦_n 覆盖全部速度集合。

### B5 AC1（A6）
t = 1/(a+c)，θ = a/(a+c)。c ≤ 4a ⟺ θ ≥ 1/5，且 θ < ½。
- at = θ ∈ A，ct = 1 − θ ∈ A；
- bt ∈ (θ, 1−θ) ⊂ A；
- dt = d/(a+c)，由假设其小数部分在 A 内。∎

### B6 障碍（A7）
c = 4a 时 θ = 1/5，b 可以取 (a,c) 中任意值，所以 b/(a+c) 遍历 (1/5, 4/5)。要对所有这样的 b 成功，需要 τ·(1/5, 4/5) 落在同一条安全弧 [j + 1/5, j + 4/5] 内：
- 长度条件 3τ/5 ≤ 3/5，所以 τ ≤ 1；
- 下端条件 τ/5 ≥ j + 1/5，j ≥ 0，所以 τ ≥ 1。

故 τ = 1，此时 dt = d/(5a)。若 frac(d/(5a)) ∉ A，规则失败。∎

（这只说明**这一类**规则失败；并不说明成功时间不存在。）

### B7 展示计算
- **(1, 1.5, 2, 5)**：c = 2 ≤ 8/3，d > 4。t_L = 1/5，X = 1，‖X‖ = 0；k = round(1) = 1，t = 1.2/5 = **6/25**。
  距离：‖6/25‖ = 0.24，‖9/25‖ = 0.36，‖12/25‖ = 0.48，‖30/25‖ = ‖1.2‖ = 0.2。✓
- **(1, 2, 8/3, 5)**（c 取边界值）：t_L = 1/5，X = 1，t = 6/25。

- **(1, 5/4, 7/4, 41/10)**：X = 41/50 = 0.82，‖X‖ = 0.18 < 0.2；k = round(0.82) = 1，t = 1.2/4.1 = **12/41**。
  距离：12/41 ≈ 0.293，15/41 ≈ 0.366，‖21/41‖ = 20/41 ≈ 0.488，‖1.2‖ = 0.2。✓

## SECTION C — 适用边界与剩余区域

1. **K5 覆盖**：{c ≤ 8a/3}，对所有 b、d。这是走廊中一块**无界**的连续区域。
2. **WL 额外覆盖**：{8a/3 < c < 4a，d ≥ 2ac/(4a − c)}。
3. **走廊中的精确剩余**（相对 K5 ∪ WL）：
   - **R₁** = {8a/3 < c < 4a，4a < d < 2ac/(4a − c)}；
   - **R₂** = {c ≥ 4a，4a < d < 4c}。

   AC1、C1 及其他已知盒子覆盖 R₁、R₂ 的部分，本席不声称其并集。
