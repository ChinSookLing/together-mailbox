- **Q2（非平凡区域）**：最小盒 k=1 的成功区域是 s ∈ [5/4, 5]、r ∈ (1, 4]、w ∈ (½, 4/5]。五跑者紧情形 {1,2,3,4} 正好位于这个盒的一个**角**上（t = 1/5）。——**PROOF CANDIDATE**

## SECTION A — 精确命题

### A1 锁相盒引理 LB(k; m_a, m_b, m_d)
设 k ≥ 1 与 m_a, m_b, m_d ≥ 0 都是整数。若
- (a) k/(m_a + 4/5) ≤ s ≤ k/(m_a + 1/5)
- (b) k/(m_b + 4/5) ≤ 1 + r ≤ k/(m_b + 1/5)
- (d) (m_d + 1/5)/k ≤ w ≤ (m_d + 4/5)/k

则 t = k/(b+c) 满足 ‖at‖, ‖bt‖, ‖ct‖, ‖dt‖ ≥ 1/5。
（条件 (a) 中当 m_a = 0 时右端为 5k。）

**坐标的独立性**：取 a = 1，则 b = s/(1+r)，c = rs/(1+r)，d = ws。映射 (a,b,c,d) ↦ (s,r,w) 在相差一个伸缩的意义下是双射。速度顺序 a < b < c < d 对应三个条件：s > 1 + r，r > 1，w > r/(1+r)。

### A2 最小盒 LB(1; 0, 0, 0)
若 5/4 ≤ s ≤ 5，1 < r ≤ 4，且 ½ < w ≤ 4/5，则 t = 1/(b+c) 成功。
（下界 w > ½ 来自 d > c 以及 c/(b+c) > ½，是自动成立的。）

### A3 锁相加微调引理 LN
设 0 < a < b < c < d，且 **d ≥ 4c**。令 t₀ = F₄(a,b,c)（T4，门槛 1/4），X = dt₀。
- 若 ‖X‖ ≥ 1/5，输出 t₀。
- 否则令 k = ⌊X + ½⌋，e = X − k，σ = +1（若 e ≥ 0）或 −1（若 e < 0），输出 **t = (k + σ/5)/d**。

则 t > 0，且四个距离都 ≥ 1/5。

### A4 单相位选 k：PLS 的 δ 推广（PLS_δ）
设 0 < p < q，r > 0，0 < δ ≤ 1/4，θ = p/(p+q)，η = r/(p+q)。
1. k₀ = ⌈δ(p+q)/r⌉
2. x₀ = frac(k₀θ)
3. 若 x₀ ∈ [δ, 1−δ]，令 j = 0；否则 Δ = frac(δ − x₀)，j = ⌈Δ/θ⌉
4. t = (k₀ + j)/(p+q)

若 r(2 + 2δ(p+q)/p) ≤ (1 − 2δ)(p+q)，则 ‖pt‖, ‖qt‖, ‖rt‖ ≥ δ。
**δ = 1/5，(p,q,r) = (b,c,a) 时**，条件化为 **a(12b + 2c) ≤ 3b(b+c)**。

## SECTION B — 证明

### B1 LB 的证明
t = k/(b+c) > 0。
- **a**：at = k/s。由 (a)，at ∈ [m_a + 1/5, m_a + 4/5]，所以 ‖at‖ ≥ 1/5。
- **b**：bt = k/(1+r)。由 (b)，bt ∈ [m_b + 1/5, m_b + 4/5]。
- **c**：ct = k − bt，所以 ‖ct‖ = ‖bt‖ ≥ 1/5。（这就是锁相。）
- **d**：dt = kw。由 (d)，dt ∈ [m_d + 1/5, m_d + 4/5]。∎

三个条件分别只涉及 s、r、w，所以成功区域是一个长方盒。四跑者 T4 的 B(k,m) 是去掉 d 坐标后的二维截面。

### B2 紧情形 {1,2,3,4} 在 LB(1;0,0,0) 的角上
s = (2+3)/1 = 5，r = 3/2，w = 4/5。s = 5 与 w = 4/5 都在盒子的边界上，r = 1.5 在内部。
t = 1/5：‖1/5‖ = 1/5，‖2/5‖ = 2/5，‖3/5‖ = 2/5，‖4/5‖ = 1/5。✓

**内部实例** (1, 2, 5/2, 7/2)：s = 9/2，r = 5/4，w = (7/2)/(9/2) = 7/9 ≈ 0.778 ≤ 0.8。t = 2/9：
- ‖2/9‖ = 2/9 ≈ 0.222
- ‖4/9‖ = 4/9
- ‖5/9‖ = 4/9
- ‖7/9‖ = 2/9

都 ≥ 1/5。✓

### B3 LN 的证明
(i) 由 T4（PROVED），‖at₀‖, ‖bt₀‖, ‖ct₀‖ ≥ 1/4。
(ii) 若 ‖X‖ ≥ 1/5，直接成立。
(iii) 否则 |e| = ‖X‖ < 1/5，k 唯一（平局要求 ‖X‖ = ½）。dt = k + σ/5，所以 ‖dt‖ = 1/5。
  σ 与 e 同号，所以 |t − t₀| = |σ/5 − e|/d = (1/5 − |e|)/d ≤ 1/(5d) ≤ 1/(20c)。
(iv) **旧跑者**：对 u ∈ {a,b,c}，由 Lipschitz 性，‖ut‖ ≥ 1/4 − u/(20c) ≥ 1/4 − 1/20 = 1/5。
(v) **非负**：ct₀ ≥ ‖ct₀‖ ≥ 1/4，所以 t₀ ≥ 1/(4c) > 1/(20c) ≥ |t − t₀|，故 t > 0。∎

这正是 L2（n = 4，M = c，w = d ≥ 4c）套在 T4 上。当 T4 走 B 型锁相分支时，LN 就是"先锁 (b,c)，再微调 d"。

**计算 (1,2,3,12)**：d = 12 ≥ 4c = 12 ✓。T4 走 S1（c = 3a），t₀ = 1/4。X = 3，‖X‖ = 0 < 1/5，k = 3，e = 0，σ = +1，t = (3 + 1/5)/12 = 16/60 = **4/15**。
核对：
- ‖4/15‖ = 4/15 ≈ 0.267
- ‖8/15‖ = 7/15
- ‖12/15‖ = 3/15 = 1/5
- ‖48/15‖ = ‖3.2‖ = 1/5

全部 ≥ 1/5，其中两个恰好取等号。✓

### B4 PLS_δ 的证明
(i) 锁相：‖qt‖ = ‖pt‖ = ‖k*θ‖，其中 k* = k₀ + j。
(ii) 配对安全：坏弧 (1−δ, 1+δ) mod 1 的长度为 2δ，所以 Δ ∈ (0, 2δ)。jθ ∈ [Δ, Δ+θ)，所以 frac(k*θ) ∈ [δ, δ + θ)。而 θ < ½ ≤ 1 − 2δ（因 δ ≤ 1/4），所以 frac(k*θ) ∈ [δ, 1−δ)。
(iii) 下界：k*η ≥ k₀η ≥ δ。
(iv) 上界：k₀ < δ/η + 1，j < 2δ/θ + 1（当 j = 0 时 jη = 0，不等式同样成立），所以
  k*η < δ + 2η + 2δη/θ = δ + 2r/(p+q) + 2δr/p。
  若它 ≤ 1 − δ，即 r(2/(p+q) + 2δ/p) ≤ 1 − 2δ，则 ‖rt‖ ≥ δ。
(v) δ = 1/5，(p,q,r) = (b,c,a)：2a/(b+c) + 2a/(5b) ≤ 3/5。两边乘 5b(b+c)：10ab + 2a(b+c) ≤ 3b(b+c)，即 **a(12b + 2c) ≤ 3b(b+c)**。∎
（δ = 1/4 时化为 a(5b+c) ≤ b(b+c)，与 T4 的 S3 一致。这是一个自洽检查。）

PLS_δ 只控制了一个自由相位 a；d 的相位 k*w 不受控制，所以 PLS_δ **不是** F₅ 的规则，只是 Q1 的半步。

## SECTION C — 适用边界

1. **实数**：LB、LN、PLS_δ 都只用实数的取整运算，不需要公共周期，不限制 t ∈ [0,1)。
2. **LN 的范围**：d ≥ 4c，等号可以取到（见 B3 的例子）。它依赖 T4 与 L2 的已证明范围：T4 适用于任意 0 < a < b < c，L2 适用于任意 n 与 |w| ≥ nM。
3. **LB 的范围**：给定 (k; m)，就是一个显式长方盒。**单个盒子**的覆盖是严格的。**多个盒子的并集能覆盖多少**，本席没有证明。
4. **紧情形**：{1,2,3,4} 位于 LB(1;0,0,0) 的角上，说明锁 (b,c) 的单锁相在最紧的情形里**仍然是正确的结构**。
5. **自测（仅查错，非 CHECKED）**：LN 用精确分数测试 2 万组随机输入（d ≥ 4c），零失败；B2、B3 的例子用精确分数核对。
