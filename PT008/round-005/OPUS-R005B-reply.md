## SECTION A — 候选构造

**引理 PC（配对上整 Pair-Ceiling，δ = 1/4）**
对 0 < p < q，令 k = ⌈(p+q)/(4p)⌉，t = k/(p+q)。则 ‖pt‖ = ‖qt‖ ∈ [1/4, 1/2)。

**分段构造 F₄(a,b,c)**（按顺序检查，条件都是速度比的显式不等式）：

| 规则 | 条件 | 输出 t |
|---|---|---|
| **R1** 快新人 | c ≥ 3b | t₀ = F(a,b)，再对 c 做 Nudge（Round 002 L2，门槛 1/4） |
| **R2** 慢跑者 | b ≥ 3a | 见 B3 的显式两步公式 |
| **R3** (a,c) 配对 | ‖b·k_ac/(a+c)‖ ≥ 1/4，其中 k_ac = ⌈(a+c)/(4a)⌉ | t = k_ac/(a+c) |
| **R4** (a,b) 配对 | ‖c/(a+b)‖ ≥ 1/4 | t = 1/(a+b) |
| — | 其余 | **UNFINISHED** |

**R3 的特例**：c ≤ 3a 时条件**自动成立**，t = 1/(a+c)。紧情形 {1,2,3} 就在这里：t = 1/4。

## SECTION B — 推导与证明

**B1 引理 PC 的证明。** 令 θ = p/(p+q) ∈ (0, ½)。因 pt + qt = k ∈ ℤ，所以 ‖pt‖ = ‖qt‖ = ‖kθ‖。
- 由上整定义，kθ ≥ 1/4。
- 若 k = 1：kθ = θ < ½。
- 若 k ≥ 2：则 (k−1)θ < 1/4，且 θ < 1/4（因为 1/(4θ) > 1），所以 kθ < 1/2。

因此 kθ ∈ [1/4, ½)，‖kθ‖ = kθ ≥ 1/4。∎

**B2 R1 的证明。** F(a,b) 满足 ‖aF‖, ‖bF‖ ≥ 1/3（Round 004 B5）。套用 L2：n = 3，M = b，w = c ≥ 3b = nM，所以 Nudge 后的 t 满足 g ≥ 1/4。∎
**计算 {1,2,6}**：F(1,2) = ⌈3/3⌉/3 = 1/3。6·(1/3) = 2 ∈ ℤ，需要 Nudge：k = 2，t = (2 + 1/4)/6 = 3/8。
核对：‖3/8‖ = 3/8，‖6/8‖ = 1/4，‖18/8‖ = ‖2.25‖ = 1/4。✓

**B3 R2（慢跑者引理）的证明与公式。** 设 b ≥ 3a。
1. 令 J = [1/(4a), 3/(4a)]。在 J 上，at ∈ [1/4, 3/4]，所以 ‖at‖ ≥ 1/4。
2. 令 k = ⌈b/(4a) − 1/4⌉，I = [(k+¼)/b, (k+¾)/b]。在 I 上，‖bt‖ ≥ 1/4。
   - I ⊂ J：左端 (k+¼)/b ≥ 1/(4a)，这由 k 的定义保证。右端 (k+¾)/b < (b/(4a) + 1 + ½)/b = 1/(4a) + 3/(2b) ≤ 1/(4a) + 1/(2a) = 3/(4a)，这里用到 b ≥ 3a。
3. 令 L = c(k+¼)/b。c·I 的长度为 c/(2b) > ½。取 X = L（若 ‖L‖ ≥ 1/4），否则 X = ⌈L − ¼⌉ + ¼。后一种情况下 X ≤ L + ½，所以 X 落在 c·I 内，且 ‖X‖ = 1/4。
4. 输出 **t = X/c**。

t ∈ I ⊂ J，所以三个距离都 ≥ 1/4。∎
**计算 {1,3,10}**：J = [1/4, 3/4]；k = ⌈3/4 − 1/4⌉ = 1；I = [5/12, 7/12]；L = 10·5/12 = 25/6 ≈ 4.167，‖L‖ = 1/6 < 1/4，所以 X = ⌈4.167 − 0.25⌉ + 0.25 = 4.25，t = 0.425。
核对：‖0.425‖ = 0.425，‖1.275‖ = 0.275，‖4.25‖ = 0.25。✓

**B4 R3、R4 的证明。** 由引理 PC，配对的两个跑者都 ≥ 1/4；第三个跑者由规则条件保证。∎
**c ≤ 3a 时 R3 自动成立**：k_ac = 1，t = 1/(a+c)。此时 bt = b/(a+c)。
- b > a ≥ (a+c)/4，所以 bt > 1/4。
- b < c ≤ 3(a+c)/4，因为 c ≤ 3a ⟺ c/4 ≤ 3a/4。所以 bt < 3/4。

因此 ‖bt‖ ≥ 1/4。∎
**R4 在密集区的显式形状**：若 b < 3a 且 3a < c < 3b，则 c/(a+b) ∈ (3/4, 9/4)，所以 R4 ⟺ **5(a+b)/4 ≤ c ≤ 7(a+b)/4**，是一条线性条带。

**B5 Q2 的选择结论：密集区内 (b,c) 取最小 k 必失败。** 密集区 D：b < 3a，3a < c < 3b。
此时 (b+c)/(4b) < (b+3b)/(4b) = 1，所以 k_bc = 1，t = 1/(b+c)。
而 at = a/(b+c) < a/(a+3a) = 1/4，所以 ‖at‖ < 1/4。∎
→ 在 D 中，**最快跑者应与最慢跑者配对（R3），或改用 (a,b) 配对（R4）**。(b,c) 只有在 k ≥ 2 时才可能有用，见 C2。
