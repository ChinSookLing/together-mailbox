## I-4 GLC（间隔–长度覆盖）
**陈述**：设 δ ∈ (0, ½)，S = S_δ(V) 非空；ℓ 为 S 的最长分量长度，r 为 (0, ∞)∖S 的最长分量长度（r < ∞ 时）。对任意实数 u > 0：
- (i) 若 uℓ ≥ 2δ，则 S_δ(V ∪ {u}) ≠ ∅；
- (ii) 若 u·r ≤ 1 − 2δ，则 S_δ(V ∪ {u}) ≠ ∅。

**GLC-FAIL**：在 (H-com) 下，r/ℓ ≥ (2δ/(1−2δ))·(v_max/v_min)。

**证明**：
- (i)：在那个长度为 ℓ 的闭分量上，ut 连续地扫过一段长度 ≥ 2δ 的闭弧。长为 2δ 的开不安全弧装不下它，所以弧上有一点满足 ‖ut‖ ≥ δ。
- (ii)：闭窗口 [δ/u, (1−δ)/u] ⊂ (0, ∞)，长度 ≥ r，不可能包含在补集的某一个开分量里，所以它与 S 相交；交点处 ‖ut‖ ≥ δ。
- **GLC-FAIL**：
  - 当 0 < t < δ/v_min 时，‖v_min t‖ < δ，所以 (0, δ/v_min) 落在补集中；由周期性和对称性，补集中有一个分量长度 ≥ 2δ/v_min，即 r ≥ 2δ/v_min。
  - S 的每个分量都位于 v_max 的某一段安全弧内，所以 ℓ ≤ (1−2δ)/v_max。∎

**局限**：在 R024 §5 的七个测试案例中，GLC 都不成立。

## I-5 DU（密度更新律）

- (i) ρ_δ(V ∪ {u}) ≥ ρ_δ(V) − 2δ；
- (ii) 若 δ′ < δ，则 ρ_{δ′}(V) ≥ ρ_δ(V)；

- (ii)：单调性，S_δ ⊆ S_{δ′}。
- (iii)：由 (i) 得测度为正。∎

## I-6 FU（Fourier 更新律）
**陈述**：设条件同 DU。对 ξ ∈ (1/P′)ℤ，令 Ŝ_V(ξ) = (1/P′)∫₀^{P′} 1_{S_δ(V)}(t)·e^{−2πiξt} dt；c₀ = 1 − 2δ，c_m = −sin(2πmδ)/(πm)（m ≠ 0）。则：
- (i) ρ_δ(V ∪ {u}) = Σ_{m∈ℤ} c_m·Ŝ_V(−mu)，级数收敛；
- (ii) 若 (1−2δ)·ρ_δ(V) > Σ_{m≠0} |c_m|·|Ŝ_V(mu)|（右边有限时），则 S_δ(V ∪ {u}) ≠ ∅。

**证明**：
- 1_{[δ, 1−δ]}(x mod 1) 的 Fourier 系数为 ∫_δ^{1−δ} e^{−2πimx} dx = (e^{2πimδ} − e^{−2πimδ})/(−2πim) = −sin(2πmδ)/(πm)。
- 所以 1_{S_δ(u)}(t) = Σ c_m e^{2πimut}（L² 意义下）。由于 uP′ ∈ ℤ，频率 mu ∈ (1/P′)ℤ。
- 由 Parseval 恒等式，乘积的平均值 = Σ c_m·Ŝ_V(−mu)；两个系数序列都在 ℓ² 中，所以级数收敛。
- (ii) 由三角不等式与 |Ŝ(−ξ)| = |Ŝ(ξ)| 得到。∎

## I-7 MZ（零测度定理；按主席要求限定）
**定理 MZ**：设 N ≥ 2，λ > 0，W = λ(1, 2, …, N)，δ = 1/(N+1)。则：
- (a) S_δ(W) **非空**，且等于 { k/(λ(N+1)) + ℤ/λ : gcd(k, N+1) = 1 }，是可数个孤立点，**Lebesgue 测度为零**；
- (b) 对 V = λ(1, …, N−1)（N ≥ 3），S_δ(V) 的测度为正。

即：从 λ(1, …, N−1) 加入速度 λN 的这一步，前一个安全集测度为正，后一个非空但测度为零。

**证明**：只需对 λ = 1 证明（时间按 1/λ 缩放）。
1. **鸽笼**：对 v = 0, 1, …, N，z_v = frac(vt)，共 N+1 个点在圆周上，相邻的 N+1 段弧总长为 1，所以最短一段 ≤ 1/(N+1)。z_i 与 z_j 的圆周距离等于 ‖(i−j)t‖，且 |i − j| ∈ {1, …, N}。
2. **等号情形**：若 t ∈ S_δ(W)，则所有两两距离 ≥ 1/(N+1)，于是每段弧 ≥ 1/(N+1)；而总长为 1，所以每段**恰好**等于 1/(N+1)，点等距分布，且两两不同。因此 {z_v} = {j/(N+1) : j = 0, …, N}，特别地 t ≡ k/(N+1)。由于 z_v = vk/(N+1) 两两不同，gcd(k, N+1) = 1。
3. **反向**：对这样的 k，v ↦ vk mod (N+1) 是 {1, …, N} 上的双射，所以 ‖vk/(N+1)‖ ≥ 1/(N+1) 对所有 v 成立，t 确实安全。
4. **测度**：S_δ(W) 是可数集，测度为零。这证明 (a)。
5. **(b)**：取 t₀ = 1/N。由第 1–3 步（把 N 换成 N−1），V 在 t₀ 处的距离都 ≥ 1/N > δ。m_V 连续，所以 t₀ 的某个开邻域都在 S_δ(V) 中，测度为正。∎

**范围限定**：
- **"任意连续块"的读法 DISPROVED**：W = (2, 3)，δ = 1/3。t = 1/5 时 ‖2/5‖ = ‖3/5‖ = 2/5 > 1/3，由连续性，S_{1/3}((2,3)) 含开区间，测度为正。
- 计算印证（CHECKED，非证明）：对 N = 2…6，块 (m, …, m+N−1)：m = 1 时测度都为 0；m = 2、3 时测度都为正，例如 (2,3,4,5)：3/25；(3,4,5,6)：23/150。
- "测度为零的安全集是否只出现在 λ(1, …, N)"：UNFINISHED（R023 的 (1,3,4,7) 在 1/5 下也是孤立点，所以至少还有别的情形）。

**推论 MZ-c（按主席裁决限定后的精确形式）**：若某种证书**唯一**的非空判据是"给出 S_δ(V ∪ {u}) 测度的正下界"（例如 DU(iii)、FU(ii)、GLC(i)），则它不能证明从 λ(1, …, N−1) 到 λ(1, …, N) 这一步非空。

# Part II · 算术证书：同时处理区间与孤立点

## §1 引理 LM（局部极大值的算术位置；任意实数速度）
**陈述**：设 V 为任意有限个正实数（**不要求可公度**）。若 t\* > 0 是 m_V 的局部极大点，且 m_V(t\*) < ½，则存在 v ≠ v′ ∈ V 与正整数 j，使 **t\* = j/(v + v′)**。

**证明**：
1. m_V 在 (0, ∞) 上分段线性，每个有界区间内只有有限个断点（‖vt‖ 的断点间距为 1/(2v)），所有斜率都是非零的 ±v。所以存在 ε > 0，使得在 (t\* − ε, t\*) 上 m_V = f_L 且斜率 > 0，在 (t\*, t\* + ε) 上 m_V = f_R 且斜率 < 0。（若某一侧斜率为 0 则矛盾，因为斜率不为零；若左侧斜率 < 0 或右侧斜率 > 0，则 t\* 不是局部极大。）
2. f_L 是某个 ‖vt‖ 的上升段：f_L(t) = vt − i，i ∈ ℤ。f_R 是某个 ‖v′t‖ 的下降段：f_R(t) = i′ − v′t，i′ ∈ ℤ。
3. 若 v = v′，则 ‖vt‖ 本身在 t\* 处由升转降，这只发生在峰值处，值为 ½，与 m_V(t\*) < ½ 矛盾。所以 v ≠ v′。
4. 由连续性 f_L(t\*) = f_R(t\*)，即 vt\* − i = i′ − v′t\*，得 t\* = (i + i′)/(v + v′)。由于 t\* > 0，j = i + i′ 为正整数。∎

（m_V(t\*) = ½ 的情形：所有 ‖vt\*‖ = ½，t\* ∈ (2j+1)/(2v)ℤ，这一类单独列入候选集。）

## §2 定理 HS（候选集与每个安全分量相交）
**定义**：C(V) = { j/(v+v′) : v ≠ v′ ∈ V，j ∈ ℤ_{>0} } ∪ { (2j+1)/(2v) : v ∈ V，j ∈ ℤ_{≥0} }。

**定理 HS**：对任意 δ ∈ (0, ½] 和任意实数速度集 V，S_δ(V) 的**每一个**连通分量 K 都含有 C(V) 中的点。特别地，S_δ(V) ≠ ∅ ⇔ S_δ(V) ∩ C(V) ≠ ∅。

**证明**：
1. **K 是有界闭区间**（可能退化成点）：K ⊂ S_δ ⊂ {‖v_min t‖ ≥ δ}，而后者的每个分量都是有界闭区间 [(i+δ)/v_min, (i+1−δ)/v_min]；又 S_δ 是闭集。
2. m_V 在 K 上取到最大值，设在 t\* 处。
   - **若 t\* 是 K 的内点**：t\* 是 m_V 的局部极大点。
   - **若 t\* 是 K 的端点**：在端点处 m_V = δ（否则由连续性 K 可以继续延伸）。于是 max_K m_V = δ，m_V 在 K 上恒等于 δ。斜率非零，所以 K 只能是单点 {t\*}，而 m_V 在 t\* 两侧都 < δ，t\* 是严格的局部极大点。
3. 由 LM（以及值为 ½ 的情形），t\* ∈ C(V)。∎

**意义**：
- C(V) 是一个**与门槛无关**的算术骨架：正长度的安全区间与孤立的安全点，都至少含有一个骨架点。
- **测试**：
  - V₁ 的孤立点 1/5 = 1/(1+4)，2/5 = 2/(1+4)；
  - V₂ 的最优点 9/31 = 9/(1+30)；
  - V₃ 的最优点 31/90 = 31/(30+60)；
  - TF 的孤立点 k/(N+1) = k/(1+N)；
  - T4 的若干分支输出，如 3/(b+c)、3/(a+c)，也都是这种形式。

## §3 证书 ACC（算术骨架证书）
**定义**：ACC(V) = (V, C(V))。对可公度的 V，只需取 C(V) ∩ (0, P_V/2]，它是有限集，并满足
|C(V) ∩ (0, P_V/2]| ≤ Σ_{v<v′} (N_v + N_{v′})/2 + Σ_v N_v/2 = kσ/2。

**输出**：
- **可公度情形**：F^{ACC}(V) = C(V) ∩ (0, P_V/2] 中使 m_V 最大的最小者。计算量 O(k²σ)。
- **实数情形**：把 C(V) 按大小排成一列（它是 k(k−1)/2 + k 条等差数列的合并，次序确定），输出第一个满足 m_V(t) ≥ δ 的 t。

**命题 ACC=SPC（可公度情形）**：F^{ACC}(V) = F^{SPC}(V)。

**证明**：SPC 的 t\* 是达到全局最大值 κ 的最小断点。一个达到全局最大值的点必是局部极大点，所以由 LM 它属于 C(V)；反过来，C(V) 中达到 κ 的点也都是达到全局最大值的点。因此"最小者"相同。∎

（核对：V₁、V₂、V₃ 以及 120 组随机整数集，两者输出完全一致。候选数分别为 20、77、321，上界 kσ/2 分别为 30、84、342。）

**再生**（加入新速度 u，门槛从 1/n 降到 1/(n+1)）：
- **骨架**：C(V ∪ {u}) = C(V) ∪ { j/(u+v) : v ∈ V } ∪ { (2j+1)/(2u) }。这是**显式**的，只增加 k + 1 条等差数列。
- **门槛**：骨架与门槛无关，**不需要任何更新**（HS 对一切 δ 成立）。
- **值**：在旧候选点处，m_{V∪u}(t) = min(m_V(t), ‖ut‖)；新候选点直接求值。

**状态**：
- **(A) 精确表示**：可公度时是有限的精确表示（PROOF CANDIDATE）。
- **实数速度**：骨架本身是显式、可数、按确定次序排列的集合，并保证与每个安全分量相交（LM、HS 对任意实数成立）。但第一个成功候选点出现在什么位置，**没有显式上界**，所以实数版本是一个"有解必终止"的**无界枚举**，**不能**当作封闭构造，本席明确这样标注。

## §4 精确写出所缺的非空性假设
**NE(V)**：对每个 u > 0，S_{1/(k+2)}(V ∪ {u}) ≠ ∅。

**命题 NE-EQ**：
- (i) 在 NE(V) 成立时，ACC 在这一层**一定**输出安全时间：可公度时直接输出；实数时枚举必终止。
- (ii) "对所有 k 个速度的集合 V 都有 NE(V)"等价于 k+1 个速度（即 k+2 位跑者）的孤独跑者命题。

**证明**：
- (i)：由 HS，S ≠ ∅ 蕴含 S ∩ C ≠ ∅。
- (ii)：任一 k+1 个速度的集合，都可以写成某个 V 加一个 u。∎

**所以**：ACC 把 (C) 精确地化归为"骨架上的某个点安全"。剩下的缺口**正好**就是 NE，没有多余的条件。它**不会**自动保持：NE 在每一层都是一个独立的命题。

**算术信息能提供什么（部分结果）**：在 TF 族上，NE 可以由 §I-7 的鸽笼等距结构**直接**证明，而且 HS 指出了解的位置（k/(1+N)）。对一般的 V，把骨架点安全的论证推广：UNFINISHED。

## §5 主席必答：Does your result supply an automatically regenerating guarantee?
**CONDITIONAL。**
- **自动再生的部分（已证，PROOF CANDIDATE）**：骨架 C(V)。它对**所有门槛**同时有效，加入新速度时显式增加等差数列，并且对正长度区间与孤立点**一律**适用。这是本轮"同时处理两类配置"的答案。
- **不自动再生的部分**：非空性 NE(V)。它等价于该层的存在性命题，本席没有证明它，也没有用已知存在定理去代替它。
- **实数速度**：骨架与 HS 成立；但有界的选择没有给出（UNFINISHED）。
