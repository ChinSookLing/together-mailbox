# Part II · PROOF：首窗精确理论（一般 k，任意实数）

**设定**：
- V 为 k 个两两不同的正实数，a = min V；δ ∈ (0, ¼]；
- J = [δ/a, (1−δ)/a]；
- S_J = { t ∈ J : 对所有 v ∈ V，‖vt‖ ≥ δ }。

**引理 C（有限分解）**：S_J 是有限个互不相交的闭区间 K_i = [L_i, R_i] 的并（允许 L_i = R_i，即孤立点），并且分量个数 r ≤ Σ_{v∈V} (⌈v(1−2δ)/a⌉ + 1)。

**证明**：
1. 对每个 v，{t ∈ J : ‖vt‖ ≥ δ} 是 J 与各段 [(j+δ)/v, (j+1−δ)/v] 的交，段数 ≤ ⌈v|J|⌉ + 1 = ⌈v(1−2δ)/a⌉ + 1。
2. 有限个"有限闭区间族"的交，仍是有限个闭区间。
3. 交集的每个分量，其左端点都是某个族中某个区间的左端点，并且不同分量的左端点互不相同；所以分量数不超过各族区间数之和。∎

**定理 FWB（首窗插入坏集的精确形式）**：对 u > 0，令 I_{i,m} = ((m−δ)/L_i, (m+δ)/R_i)（若左端 ≥ 右端则为空集），m ∈ ℤ_{≥0}。则
**S_δ(V ∪ {u}) ∩ J = ∅ ⇔ u ∈ B(V) := ⋂_{i=1}^{r} ⋃_{m≥0} I_{i,m}**。

并且：
- (i) B(V) ⊂ (0, 2δ/ℓ)，其中 ℓ = max_i (R_i − L_i)（若 ℓ > 0）；
- (ii) B(V) 是有限个开区间的并，可以显式计算；
- (iii) 若 u ∉ B(V)，取第一个满足 q_i := ⌈uL_i − (1−δ)⌉ ≤ ⌊uR_i − δ⌋ 的分量 i，则 **t = max{L_i, (q_i + δ)/u}** ∈ S_δ(V ∪ {u}) ∩ J。

**证明**：
1. 由 L_i ≥ δ/a > 0，ut 在 [L_i, R_i] 上连续，取值区间为 [uL_i, uR_i]。
2. 分量 K_i 上**没有** u 的安全点 ⇔ 对一切 t ∈ K_i 都有 ‖ut‖ < δ ⇔ 区间 [uL_i, uR_i] 包含在不安全带 ⋃_m (m−δ, m+δ) 中。由于这些开带两两之间相隔 1 − 2δ > 0，而区间是连通的，它必须整个落在某**一个**带里：m − δ < uL_i 且 uR_i < m + δ，即 u ∈ I_{i,m}。由 u > 0 与 uR_i > 0，m ≥ 0。
3. S ∩ J 中没有安全点 ⇔ 每个分量都没有 ⇔ u ∈ ⋂_i ⋃_m I_{i,m}。
4. **(i)**：若 uℓ ≥ 2δ，则最长分量对应的 [uL, uR] 长度 ≥ 2δ，装不进长为 2δ 的开带，所以 u ∉ B(V)。
5. **(ii)**：在 (0, 2δ/ℓ) 中，I_{i,m} 非空要求 (m−δ)/L_i < 2δ/ℓ，所以 m 只有有限个；有限个开区间的有限交与并，仍是有限个开区间的并。
6. **(iii)**：主席的区间公式（R030 转向信；Kimi 审阅 PROOF VERIFIED）。∎

**推论 FW-EQ**：设 V′ = V ∪ {u}，u > v_max(V)。由于 a 仍是最慢者，FW_{k+1}(V′) 的候选时间必须满足 0 < t < 1/a 且 ‖at‖ ≥ δ，这等价于 t ∈ J。因此
**FW_{k+1}(V′) ⇔ u ∉ B(V)**。

又因为任何 k+1 个速度的集合，去掉最大者后都是某个 V 加上 u = max，所以
**FW_{k+1} 对一切 (k+1) 元集成立 ⇔ 对一切 k 元集 V，都有 B_{1/(k+2)}(V) ∩ (v_max(V), ∞) = ∅**。

**定理 FW-REG（再生上界；推出 FW-FO）**：若 FW_k(V) 成立，即存在 t_w ∈ (0, 1/a)，使 V 在 t_w 处全部 ≥ δ_k = 1/(k+1)，则在 δ = 1/(k+2) 下：
ℓ ≥ 2(δ_k − δ)/v_max，于是 B(V) ⊂ (0, (k+1)·v_max)。

**证明**：
1. a·t_w ∈ [δ_k, 1 − δ_k]。取 h = (δ_k − δ)/v_max。在 [t_w − h, t_w + h] 上，每个 ‖vt‖ ≥ δ_k − v·h ≥ δ，并且 a·t ∈ [δ, 1−δ]，所以这个区间 ⊂ S_J，从而 ℓ ≥ 2h。
2. 2δ/ℓ ≤ δ·v_max/(δ_k − δ) = (k+1)v_max，因为 δ/(δ_k − δ) = (k+1)。
3. 再用 FWB(i)。∎

**推论**：u ≥ (k+1)v_max 时，首窗插入必定成功。这就是 FW-FO 的结论，现在由 FWB 推出（FW-FO 原先只有一份审阅）。**剩下的缺口被精确定位为：B(V) ∩ (v_max, (k+1)v_max) = ∅**。

## PROOF：实例（手算）
**V = (1, 2, 3)，δ = 1/5，J = [1/5, 4/5]**。

S_J 的分量为 [1/5, 4/15]、{2/5}、{3/5}、[11/15, 4/5]（端点可逐一验证，例如 t = 11/15 时三个距离为 4/15、7/15、1/5）。

逐个分量算出坏集 ⋃_m I_{i,m}：
- **[1/5, 4/15]**：m = 0 给出 (0, 3/4)；m = 1 给出 (4, 9/2)；m ≥ 2 时为空（因为 5m − 1 > 15(m + 1/5)/4 ⇔ m > 7/5）。
- **{2/5}**：(0, 1/2)、(2, 3)、(9/2, 11/2)、…
- **{3/5}**：(0, 1/3)、(4/3, 2)、(3, 11/3)、…
- **[11/15, 4/5]**：(0, 1/4)、(12/11, 3/2)、(27/11, 11/4)、(42/11, 4)、…

求交：
- (4, 9/2) 与第二个分量的坏集 (2, 3) ∪ (9/2, 11/2) 不相交（开区间在 9/2 处不重叠），所以被排除；
- 剩下的只有 (0, 3/4) ∩ (0, 1/2) ∩ (0, 1/3) ∩ (0, 1/4) = (0, 1/4)。

所以 **B(1, 2, 3) = (0, 1/4)**。

**由此得到"对一切实数 u > 0，(1, 2, 3, u) 都有首窗解"**：
- **u ≥ 1/4**：u ∉ B，由 FWB(iii)，在 J ⊂ (0, 1) 中有解，而首窗为 (0, 1/min(1, u)) ⊇ (0, 1)。
- **u < 1/4**：u 是最慢者，首窗为 (0, 1/u)。用 PS 并取 u 为局外人：P = 1，t₀ = 1/5，x = u。由于 ut₀ < 1/20 < δ，取 j = ⌈(δ − ut₀)/u⌉，t = 1/5 + j。由 PS(S1)，u·t ∈ [1/5, 1/5 + u) ⊂ [1/5, 9/20]，所以 ut < 1，t 在首窗内；1、2、3 的相位与 t₀ 处相同，都安全。∎

（这是一族单参数的 FW₄ 实例，只作演示，不作为覆盖交付。）

# Part III · 最弱未证步骤：猜想 C-INIT（比现有障碍更具体）

**猜想 C-INIT_k**：对每个由 k 个正实数组成的 V，若 S_J ≠ ∅，则 **B_{1/(k+2)}(V) = (0, δ/R_max)**，其中 R_max = max S_J。

也就是说，在首窗中困住新跑者的，**只有**"慢到在整个 J 上相位都 < δ"的那一类平凡情形，不存在共振陷阱。

**推论（证明）**：C-INIT_k 加上 FW_k，推出 FW_{k+1}。

**证明**：R_max ≥ t_w ≥ δ_k/a > δ/a，所以 δ/R_max < a ≤ v_max。因此 B ∩ (v_max, ∞) = ∅，再用 FW-EQ。∎

**特别地**：C-INIT₃ 推出 FW₄（因为 FW₃ 已认证）。

**否证方式**：找到 V 与 u ≥ δ/R_max 使 u ∈ B(V)。由 FWB，验证 u ∈ B 只需对有限个分量做精确检查。

**检查**（CHECKED，非证明；本席精确分数代码）：
- k = 2（δ = 1/4，速度 ≤ 30，435 组）：B 都是初始区间，无一例外；
- k = 3（δ = 1/5，速度 ≤ 20，1,140 组）：同上；
- k = 4（δ = 1/6，速度 ≤ 13，715 组）：同上；
- 另有 324 组随机有理三元组，B ∩ (a, ∞) 都为空。
- FWB 本身的一致性检查：在 (1,2,3)、(1,3,4)、(2,5,7)、(3,7,11) 上各取 3,000 个随机有理 u，判断"u ∈ B"与"见证存在"是否一致，零不一致；所有见证都在首窗内且安全。

## IDEA
