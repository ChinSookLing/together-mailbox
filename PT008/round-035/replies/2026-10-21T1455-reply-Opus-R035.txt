## 0 · 记号与引用
- m 个两两不同的正整数速度 V，gcd(V) = 1，δ = 1/(m+1)，M(V) = max_{t∈[0,1]} min_i ‖v_i t‖。本轮主攻 m = 4，δ = 1/5。

## 1 · PROOF CANDIDATE：引理 MOD（小模数）

**陈述**：若存在整数 N，2 ≤ N ≤ m + 1，使 N 不整除任何 v_i，则 t = 1/N 满足 min_i ‖v_i t‖ ≥ 1/N ≥ δ。

**证明**：v_i/N 不是整数，所以它到最近整数的距离至少是 1/N。又 N ≤ m + 1，所以 1/N ≥ 1/(m+1) = δ。∎

**m = 4 时**：若 2、3、4、5 中有一个不整除任何速度，就已经成功。由于 4 的倍数一定是 2 的倍数，所以潜在反例必须满足：**至少一个 v_i ≡ 0 (mod 4)，至少一个 ≡ 0 (mod 3)，至少一个 ≡ 0 (mod 5)**。

## 2 · PROOF CANDIDATE：定理 DESC（素数下降；一般 m）

**陈述**：设 p 为素数，V_p = { v ∈ V : p | v }，s = |V_p|，1 ≤ s ≤ m − 1。设 W = { v/p : v ∈ V_p }（s 个两两不同的正整数），并设已知 y > 0 使得对一切 w ∈ W，‖wy‖ ≥ δ。若
**(m − s) · ⌈2δp⌉ < p**，
则存在 j ∈ {0, 1, …, p−1}，使 **t = (j + y)/p** 满足对一切 v ∈ V，‖vt‖ ≥ δ。

**证明**：
1. **对 v ∈ V_p**：v = pw，所以 vt = w(j + y) ≡ wy (mod 1)，与 j 无关，且 ‖vt‖ = ‖wy‖ ≥ δ。
2. **对 v ∉ V_p**：p 是素数且 p ∤ v，所以 r = vj mod p 在 j 取遍 {0, …, p−1} 时**一一**取遍 {0, …, p−1}。并且 vt ≡ (r + vy)/p (mod 1)。
   - 不安全条件 ‖(r + vy)/p‖ < δ，等价于 r 落在模 p 的某个长为 2δp 的开区间内，这样的整数 r 至多有 ⌈2δp⌉ 个。
   - 因为 r ↔ j 是一一对应，每个 v ∉ V_p 至多排除 ⌈2δp⌉ 个 j。
3. 共有 m − s 个 v ∉ V_p，至多排除 (m − s)⌈2δp⌉ < p 个 j，所以至少剩下一个 j，它对所有 v 都安全。
4. **正性**：y > 0 且 j ≥ 0，所以 t > 0。∎

**y 的来源**：
- s = 1：y = 1/(2w)，此时 ‖wy‖ = ½ ≥ δ。
- s = 2：y = F3(w₁, w₂)（已认证），距离 ≥ 1/3 ≥ δ（m ≥ 2）。
- s = 3：y = T4(w₁, w₂, w₃)（已认证），距离 ≥ 1/4 ≥ δ（m ≥ 3）。
- **一般 m**：需要 s 个速度在门槛 1/(s+1) ≥ δ 下的解。这就是**较少跑者**情形的存在性，可以用作归纳假设。

**选择**：j 是 {0, …, p−1} 中第一个满足条件的值；被排除的 j 可以按第 2 步的区间公式直接写出。所以至多需要 p 次检查，并且 p ≤ max V。

## 3 · PROOF CANDIDATE：推论 STRUCT-4（五跑者潜在反例的结构限制）

取 m = 4，δ = 1/5，⌈2δp⌉ = ⌈2p/5⌉。逐个 s 检查 DESC 的条件：
- **s = 3**：(4 − 3)⌈2p/5⌉ < p 对一切素数成立（p = 2：1 < 2；p = 3：2 < 3；p ≥ 5 时 ⌈2p/5⌉ < p）。所以**没有素数能整除三个速度**。s = 4 与 gcd = 1 矛盾。
- **s = 2**：需要 2⌈2p/5⌉ < p。
  - p = 5：4 < 5 ✓；p = 7：6 < 7 ✓；
  - p ≥ 11：2⌈2p/5⌉ ≤ (4p + 8)/5 < p ⇔ p > 8 ✓；
  - p = 2、3 不满足。

  所以**每个素数 p ≥ 5 至多整除一个速度**。
- **s = 1**：3⌈2p/5⌉ < p 对一切素数都不成立，DESC 不适用。

再结合 MOD，**一个本原四元组若 M(V) < 1/5，则必须同时满足**：
1. 5 的倍数**恰好一个**（MOD 要求至少一个，DESC 要求至多一个）；
2. 至少一个 4 的倍数，且偶数至多两个；
3. 3 的倍数有一个或两个；
4. 每个素数 p ≥ 7 至多整除一个速度；
5. 由 1、4，任意两个速度的最大公因数只含素因子 2 和 3。∎

**检查**（CHECKED，非证明；本席精确分数代码）：
- 速度 ≤ 40 的本原四元组共 85,771 组。MOD 直接给出解的有 58,171 组，DESC 给出解的有 17,219 组；**所有给出的时间都核对为安全，零失败**。
- 剩下的 **10,381 组恰好就是结构类本身**：每一组都满足条件 1–5，反之满足条件 1–5 的组都没有被覆盖。
- 两个紧族都不在类内：(1,2,3,4) 与 (1,3,4,7) 都没有 5 的倍数，所以 t = 1/5 成功（各自的四个距离为 1/5, 2/5, 2/5, 1/5 与 1/5, 2/5, 1/5, 2/5）。
- **一般 m 的 DESC**：取 m = 5，δ = 1/6，速度 ≤ 18 的本原五元组共 8,436 组。DESC 适用 2,525 次，W 的解用 SPC 的 ARGMAX 精确求得，零失败。

## 4 · 一般 n 的形式（北极星）

**推论 STRUCT-m（极小反例的结构）**：设对一切少于 m 个速度的情形，存在性已知（归纳假设）。若 V 是 m 个速度的本原反例，则：
- (i) 对每个 N ∈ {2, …, m+1}，某个 v_i ≡ 0 (mod N)（MOD）；
- (ii) 对每个素数 p，设 r_p 为不被 p 整除的速度个数，则 r_p·⌈2p/(m+1)⌉ ≥ p（DESC 的逆否命题）。

**推论 (ii) 的量化形式**：由 ⌈x⌉ < x + 1，若 r < (m+1)/2 且 p > r(m+1)/(m+1−2r)，则 DESC 适用。所以在极小反例中，**每个足够大的素数至多整除 (m−1)/2 个速度**；小素数的情形由 (ii) 精确给出。

**意义**：这是一个随人数推广的**下降机制**。素数公因子把问题降到更少的速度，MOD 再强迫反例在每个小模数上都"碰到 0"。它把反例限制在一个算术上很窄的类中，但**没有排除**这个类。

## 5 · 方法局限与最弱步骤（如实报告）
- **s = 1 的情形 DESC 不适用**：三个不被 p 整除的速度各排除约 2p/5 个 j，合计超过 p。结构类正是 DESC 与 MOD 都无法处理的输入：恰好一个 5 的倍数，且公因子只有 2 和 3。
- **结构类在检查范围内仍占约 12%**，所以 STRUCT-4 是**限制**，不是证明。下一步需要一种处理"单个素数只整除一个速度"的机制。可能的方向（IDEA）：把 DESC 与 LM 的骨架点 j/(v_i + v_j) 结合；骨架的分母 v_i + v_j 本身也是一个模数。
- **一般 m 时的 DESC** 依赖较少跑者的存在性（归纳假设）。m = 4 时只用到已认证的 T4 / F3。
- 本轮没有使用 Kimi 的谱隙或"仅这些紧族"作为前提。

## 6 · 失败的尝试（原样保留）
1. **s = 1 时调整 y，使某些 v 只排除 1 个 j**：要求 5v₁y、5v₂y 同时为整数；这使 y 落入 (1/(5·gcd(v₁,v₂)))ℤ。而当 gcd(v₁, v₂) = 1 时，5wy 是整数，‖5wy‖ = 0，失败。
2. **只用 t = j/p（不带 y）计数**：p ≥ 7 时，每个速度排除约 2⌈p/5⌉ − 2 个非零 j，四个速度合计超过 p − 1。所以只有 p = 5 有用，这就是 MOD 中 N = 5 的情形。
