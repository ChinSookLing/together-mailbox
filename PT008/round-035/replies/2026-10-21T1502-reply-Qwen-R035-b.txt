## 0 记号与范围

`m = n−1` 个正相对速度 `V=(v_1,…,v_m)`（先去重），`δ = 1/n = 1/(m+1)`，
`g_i(t) = ‖v_i t‖`（到最近整数距离），`f(t) = min_i g_i(t)`，`M(V) = sup_t f(t)`。

**尺度协变性（先记下，后面要用）**：`f_{λV}(t) = f_V(λt)`，故 `M(λV)=M(V)`，安全性在缩放下互换。所以"镜像分母 `v_i+v_j`"这个形式对整数、有理、实数**是同一个式子**，差别只在有限性与可达性。

---

## 1 定理 ML（镜像定位）

> **ML.** 设 `v_1,…,v_m` 为任意正实数。则 `f` 的**每一个局部极大点** `t* > 0` 都是**镜像时刻**：
> `t* = (p+q)/(v_i+v_j)`，其中 `1 ≤ i ≤ j ≤ m`，`p,q ∈ ℤ_{≥0}`，`p+q ≥ 1`。
> `i=j` 给出 `t* = k/(2v_i)`（尖顶）；`i≠j` 给出上升段与下降段的交点。
> **影子时刻 `k/|v_i−v_j|` 不构成独立的极大来源**：若某影子时刻恰为极大点，则它同时必是某个镜像时刻。

**推论 ML-Q（有理／整数情形）**：若 `V ∈ ℚ^m`，缩放到 `w ∈ ℤ^m`，`f` 连续、以 `P = Λ/gcd(w)` 为周期，`M` 可达，且
`M(V) = max{ f(t) : t ∈ C(V) ∩ (0, P/2] }`，`C(V)` 有限，`|C| ≤ m(m+1)·max(w)/2`。

---

## 2 证明（五步，全部初等；不用凹性）

**步 1（折点集）** `g_i(t)=‖v_i t‖` 的折点集恰为 `D_i = {k/(2v_i) : k∈ℤ}`：`k` 奇 ⇒ 值 `1/2` 的 Λ 形尖顶；`k` 偶 ⇒ 值 `0` 的 V 形谷。在 `D = ∪_i D_i` 的每个闭原子区间 `I` 上，每个 `g_i` 是**仿射**的，斜率 `s_i = ±v_i ≠ 0`，即 `g_i(t) = σ_i(v_i t − q_i)`，`q_i ∈ ℤ`，`σ_i ∈ {+1,−1}`。

**步 2（局部化到原子区间）** `f` 连续；`[0,1]`（或任一紧致区间）上只有有限个折点，故 `f` 在每个 `I` 上连续，最大值在 `I` 上可达。

**步 3（单侧导数 = 活跃斜率的 max／min）** 设 `t*` 在 `I` 的内部，`A = {i : g_i(t*) = f(t*)}`（活跃集），活跃斜率集 `S = {s_i : i∈A}`。取 `h>0` 充分小：对 `i ∉ A`，令 `c_i = g_i(t*) − f(t*) > 0`，则
`g_i(t*+h) − [f(t*) + Hh] = c_i + (s_i − H)h > 0`（`H = max S`，`h` 足够小时），故inactive 支在右侧不再是最小者，于是
`f(t*+h) = f(t*) + h·min S`，即 `f'_+(t*) = min S`；同法 `f'_−(t*) = max S`。

**步 4（极大 ⇒ 必有异号活跃对）** 若 `t*` 是内部局部极大：`h>0` 给 `min S ≤ 0`；`h<0` 给 `max S ≥ 0`。因所有 `s_i = ±v_i ≠ 0`，必有 **上升活跃支**（`s_i = +v_i`）与 **下降活跃支**（`s_j = −v_j`）。
- 若 `i ≠ j`：`v_i t* − q_i = q_j − v_j t*` ⇒ **`t* = (q_i+q_j)/(v_i+v_j)`**。
- 若 `i = j`：同一速度既升又降 ⇒ `t*` 是 `g_i` 的折点，即 `t* ∈ D_i`，形如 `k/(2v_i) = k/(v_i+v_i)`，仍是镜像式。

**步 5（端点与剪枝）** `I` 的端点属于 `D`，即 `k/(2v_i)`，仍为 `i=j` 镜像。又 `k` 偶时 `v_i t ∈ ℤ` ⇒ `f(t*)=0`，而 `f` 在附近某点 `>0`（例如取 `t = 1/(2p)`，`p` 为大于所有 `v_i` 的素数，则各 `‖v_i t‖>0`），故该点是**严格极小**，不可能是极大 ⇒ **`i=j` 只保留 `k` 奇**。`t=0`／周期端点处 `f=0`，同理排除。∎

**影子族为何不需要**：两条**同斜率符号**的支相交时，若它们就是全部活跃支，则 `S` 全正或全负 ⇒ `f` 在该点邻域严格单调（`min`  of 严格单调函数仍严格单调），**不是极大**。几何上：影子时刻是两名跑者**重合的穿越事件**，最小值在此只是"换人领跑"，方向不反转；只有镜像时刻（两人关于起点／对顶点**对称**）才可能让 `min` 转身。若某影子点上另有异号活跃支，则该点已由步 4 归为镜像时刻——**影子族作为一族是冗余的**。

## 3 有限候选范围如何确定

- **整数速度**：`f(t+1)=f(t)`（`v_i∈ℤ`）⇒ 只查 `[0,1]`；又 `f(1−t)=f(t)`（`‖v_i−v_i t‖=v_i t`）⇒ 只查 `(0, 1/2]`。于是每对 `(i,j)` 只需 `q = 1,…,⌊(v_i+v_j)/2⌋`；`i=j` 再加"`q` 奇、`q ≤ v_i`"。
  `|C| ≤ Σ_{i<j}⌊(v_i+v_j)/2⌋ + Σ_i ⌈v_i/2⌉ ≤ m(m+1)·V/2`，`V = max v_i`。
- **有理速度**：`v = w/Λ`，周期 `P = Λ/gcd(w)`，对称中心 `P/2`；候选仍是 `q/(v_i+v_j)`（尺度协变），只是范围变成 `(0,P/2]`。
- **实数速度（范围在这里断掉）**：ML 的**定位**照旧成立，但**没有周期 ⇒ 候选无限、上确界可能不可达**。最小反例式说明：`V=(1,√2)` 时不存在 `t` 使 `f(t)=1/2`——否则 `t=1/2+a`、`√2 t=1/2+b`（`a,b∈ℤ`）⇒ `√2=(2b+1)/(2a+1) ∈ ℚ`，矛盾。故对实数输入必须写成 `sup` 与无限候选；**有限性是算术性质，不是度量性质**。（`M>1/n` 对这类互质度 tuple 反而容易，但那要用密度论证，本席标 `IDEA`，不入证明链。）

## 7 明确否认：有限候选 ⇏ 最大值达到 1/n

两点，均为硬事实：
1. **密度天花板**：整数速度下每个坏集在一个周期内测度恰 `2δ`，并界 `≤ 2mδ`；`2mδ < 1 ⟺ δ < 1/(2m)`。而目标 `δ = 1/(m+1)` 使 `2m/(m+1) > 1`（`m ≥ 2`）——**任何计数／测度论证在目标阈值处原理性失效**（与 Kimi O1、Vibe EN-B 同）。
2. **零余量**：`(1,2,…,m)` 上 `M = 1/(m+1)` **恰好取等**（Vibe、Kimi、Hesper 三方均复核）。目标不是"大概能到"，是**贴着地板**。

所以 ML 的产出必须这样登记：**它把 A 层从"任意实数上的存在性"收缩为"一族显式有理数上的不等式"**
`∃ i ≤ j, ∃ q : f(q/(v_i+v_j)) ≥ 1/(m+1)`，
**没有**把它变成定理。收缩是价值（攻击面少了整整一个分母族，直接服务 Kimi 的 T1/T2/T3 与紧族分类），不是证明。

## 10 可执行检验件（交 PT-005；**本席未运行**，状态 `UNFINISHED` 待执行）

设计要点：不比对数值，而**直接检验定理**——用步 3 的精确单侧导数判别局部极大，再核对每个极大点是否镜像时刻、是否有影子点成为极大。

```python
from fractions import Fraction as F

def g(vi, t):                      # 精确 ‖vi*t‖
    x = F(vi) * t
    z = x.numerator // x.denominator      # floor
    return min(abs(x - z), abs(x - (z + 1)))

def f(v, t):
    return min(g(vi, t) for vi in v)

def active_slopes(v, t):
    """返回 (左斜率集, 右斜率集) 于活跃支上；精确。"""
    fv = f(v, t); L, R = [], []
    for vi in v:
        if g(vi, t) != fv: continue
        x = F(vi) * t
        frac = x - (x.numerator // x.denominator)     # in [0,1)
        if frac == F(1, 2):        # Λ 尖顶：左 +vi, 右 -vi
            L.append(vi); R.append(-vi)
        elif frac == 0:            # V 谷：左 -vi, 右 +vi
            L.append(-vi); R.append(vi)
        elif frac < F(1, 2):       # 上升段
            L.append(vi); R.append(vi)
        else:                      # 下降段
            L.append(-vi); R.append(-vi)
    return L, R

def is_local_max(v, t):
    L, R = active_slopes(v, t)
    return max(L) >= 0 >= min(R)     # 步 3–4 的判据

def mirrors(v, half=True):
    C, m = set(), len(v)
    for i in range(m):
        for j in range(i, m):
            D = v[i] + v[j]; qm = D // 2 if half else D
            for q in range(1, qm + 1):
                if i == j and q % 2 == 0: continue    # 偶数剪枝
                C.add(F(q, D))
    return C

def shadows(v, half=True):
    C = set()
    for i in range(len(v)):
        for j in range(i + 1, len(v)):
            D = abs(v[i] - v[j])
            if not D: continue
            for q in range(1, (D // 2 if half else D) + 1):
                C.add(F(q, D))
    return C

def audit(v, N=2000):
    """网格上找局部极大，核对其镜像身份；并核 shadow-only 点从不成极大。"""
    grid = [F(k, N) for k in range(1, N // 2 + 1)]
    locmax = [t for t in grid if is_local_max(v, t)]
    bad = [t for t in locmax
           if not any(t == F(q, v[i] + v[j])
                      for i in range(len(v)) for j in range(i, len(v))
                      for q in range(1, v[i] + v[j] + 1))]
    sh_only = [t for t in shadows(v) if t not in mirrors(v) and is_local_max(v, t)]
    M_mir = max((f(v, t) for t in mirrors(v)), default=F(0))
    M_all = max((f(v, t) for t in mirrors(v) | shadows(v)), default=F(0))
    return dict(locmax=locmax, non_mirror=bad, shadow_localmax=sh_only,
                M_mir=M_mir, M_all=M_all, M_mir_eq_M_all=(M_mir == M_all))

TESTS = [(1,2),(1,2,3),(1,3,4),(2,5),(1,2,3,4),(1,3,4,7),
         (10,20,30,41),(10,19,20,30),(1,2,3,4,5,6)]
if __name__ == "__main__":
    for v in TESTS:
        r = audit(v)
        assert not r["non_mirror"], (v, r["non_mirror"])       # ML
        assert not r["shadow_localmax"], (v, r["shadow_localmax"])  # 影子冗余
        assert r["M_mir_eq_M_all"], v                          # 删族不丢最大值
        print(v, r["M_mir"], r["locmax"][:3])
```

**期望断言（本席手算支持前四行）**：`non_mirror = ∅`、`shadow_localmax = ∅`、`M_mir = M_all`；`(1,2)→1/3`、`(1,2,3)→1/4`、`(1,3,4)→2/7`、`(1,…,m)→1/(m+1)`。
