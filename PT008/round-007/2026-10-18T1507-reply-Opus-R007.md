## SECTION B — 手工证明

**B0 情形穷尽。** 任意 0 < a < b < c，要么 c ≤ 3a，要么 c ≥ 3b，要么 b ≥ 3a，要么 (b < 3a 且 3a < c < 3b)，即属于 D。∎

**B1 S1。** at = 1/4。bt = b/(4a) ∈ (1/4, 3/4)，因为 a < b < c ≤ 3a。ct = c/(4a) ∈ (1/4, 3/4]。三个距离都 ≥ 1/4。∎

**B2 S2（Nudge）。**
(i) 由三跑者定理（PROVED），‖at₀‖, ‖bt₀‖ ≥ 1/3。
(ii) 若输出 t ≠ t₀：ct = k + σ/4，所以 ‖ct‖ = 1/4。位移为 |t − t₀| = |σ/4 − e|/c = (1/4 − |e|)/c ≤ 1/(4c) ≤ 1/(12b)，因为 c ≥ 3b。
   这里 |σ/4 − e| = 1/4 − |e|，因为 σ 与 e 同号且 |e| < 1/4。这就是"双向"：始终朝离 e 更近的那个安全边界移动。
(iii) Lipschitz 性：‖bt‖ ≥ 1/3 − b·1/(12b) = 1/4，‖at‖ ≥ 1/3 − a/(12b) > 1/4。
(iv) t > 0：bt₀ ≥ ‖bt₀‖ ≥ 1/3，所以 t₀ ≥ 1/(3b) > 1/(12b) ≥ |t − t₀|。∎

**B3 S3（PLS）。**
(i) **锁相**：pt + qt = k* := k₀ + j ∈ ℤ，所以 ‖qt‖ = ‖pt‖ = ‖k*θ‖。
(ii) **配对安全**：若 j = 0，frac(k*θ) = x₀ ∈ [1/4, 3/4]。若 j ≥ 1，jθ ∈ [Δ, Δ+θ)，所以 frac(k*θ) ∈ [1/4, 1/4+θ) ⊂ [1/4, 3/4)，因 θ < ½。
(iii) **第三者**：rt = k*η ≥ k₀η ≥ 1/4。
(iv) **上界**：k₀ < 1/(4η) + 1，j < Δ/θ + 1 < 1/(2θ) + 1，所以 k*η < 1/4 + 2η + η/(2θ)。
   代入 (p,q,r) = (b,c,a)：2η + η/(2θ) = 2a/(b+c) + a/(2b)。
   它 ≤ 1/2 ⟺ 4ab + a(b+c) ≤ b(b+c) ⟺ **a(5b+c) ≤ b(b+c)**。此时 k*η < 3/4，所以 ‖at‖ ≥ 1/4。
(v) **b ≥ 3a ⇒ 条件成立**：b(b+c) − a(5b+c) ≥ b(b+c) − (b/3)(5b+c) = 2b(c−b)/3 > 0。∎

**B4 锁相族 B(k,m)。** 令 t = k/(b+c)。
- at = k/s ∈ [1/4, 3/4]，由条件 (i)。
- bt = k/(1+r)。条件 (ii) ⟺ (4m+1)/(4k) ≤ 1/(1+r) ≤ (4m+3)/(4k) ⟺ bt ∈ [m + 1/4, m + 3/4]。
- ct = k − bt，所以 ‖ct‖ = ‖bt‖ ≥ 1/4。∎

四块的端点逐一代入公式：k=2, m=0：r ∈ [8/3 − 1, 8 − 1]；k=3, m=1：[12/7 − 1, 12/5 − 1]；k=4, m=1：[16/7 − 1, 16/5 − 1]；k=5, m=1：[20/7 − 1, 4 − 1]。

**B5 S6-A（独立审阅主席引理，含等号）。** t = 3/(a+c)。
- at = 3a/(a+c) ∈ [1/4, 3/4] ⟺ 3 ≤ c/a ≤ 11。等号两端都可取。✓
- ct = 3 − at，所以 ‖ct‖ = ‖at‖。✓

结论：**主席证明正确，等号边界正确。** 主席 R1 由 B4（k=2, m=0）给出，同样正确。∎
