## PROOF 1 · 定理 A1（共振约化；一般 k）

**陈述**：设 V 为 k 个正实数，可公度（V ⊂ gℤ，取最大的 g，P = 1/g）；δ ≤ 1/4；t₀ ∈ S_δ(V)。则对每个满足 **uP ∉ ℤ** 的实数 u > 0（u 可以是有理数，也可以是无理数），有
t = t₀ + jP ∈ S_δ(V ∪ {u})，
其中 j 由 PS 选择器给出（x = frac(uP)，φ₀ = frac(ut₀)）。

**证明**：
- 对每个 v ∈ V，vP ∈ ℤ，所以 v 的相位在 t 与 t₀ 处相同，‖vt‖ ≥ δ。
- u 的相位为 frac(φ₀ + jx)，其中 x ∈ (0, 1)。PS 的 (S0)–(S2) 证明只用到 x ∈ (0, 1) 与 δ ≤ 1/4，所以 ‖ut‖ ≥ δ。
- t ≥ t₀ > 0。∎

**推论**：对可公度的 V，"插入失败"（主席的条件 S ⊆ ⋃_m ((m−δ)/u, (m+δ)/u)）**只可能**发生在 u ∈ (1/P)ℤ_{>0}，即共振格上。

## PROOF 2 · 定理 DEC（共振的有限化；一般 k）

**证书 𝒩_δ(V)** 由四项组成：
1. 周期 P；
2. S_δ(V) 的一个分量 K\* = [α, β]，长度 ℓ\* = β − α > 0；
3. 一个点 t₀ ∈ S_δ(V)；
4. 对每个整数 1 ≤ m < M := 2δP/ℓ\*，一个见证 t_m ∈ S_δ(V ∪ {m/P})。

**可验证性**：第 2、3 项由 SPC 的精确区间运算验证；第 4 项是有限多个点，每个点逐速度检查。证书是有限的，**只依赖速度本身**，不需要知道任何新速度。

**定理 DEC**：若 𝒩_δ(V) 有效且 δ ≤ 1/4，则对**每一个**实数 u > 0，下面的规则 t(u) 都满足 t(u) ∈ S_δ(V ∪ {u})：
- **(a)** 若 uP ∉ ℤ：用 A1，从 t₀ 出发。
- **(b)** 若 u = m/P 且 m ≥ M（等价于 uℓ\* ≥ 2δ）：若 ‖uα‖ ≥ δ，取 t = α；否则取 t = α + frac(δ − uα)/u。
- **(c)** 若 u = m/P 且 m < M：取 t = t_m。

**证明**：
- (a)：即 A1。
- (b)：在 K\* 上，V 处处安全。若 ‖uα‖ < δ，则 Δ = frac(δ − uα) < 2δ，所以 t − α = Δ/u < 2δ/u ≤ ℓ\*，即 t ∈ K\*；并且 frac(ut) = δ。
- (c)：由证书的定义。
- 三种情形穷尽了所有 u > 0。∎

**意义**：对固定的 V，"对一切实数 u，插入都成功"这个**全称命题**，被化为**有限次**精确检查，次数 < M = 2δP/ℓ\*。这不是把非空性换一种说法：A1 与 (b) 用公式处理了几乎所有 u，剩下的有限部分有明确的上界。

## PROOF 3 · 更新法：证书的哪些部分自动再生

设已有 𝒩_δ(V)，δ = 1/(k+2)。加入 u，令 V′ = V ∪ {u}，t′ = t(u)。下一层的门槛为 δ′ = 1/(k+3)。

**定理 UPD**：
- (i) **P′ 自动得到**：若 u 与 V 可公度，P′ = 1/gcd(V′)。若不可公度，V′ 没有周期，DEC 的下一步不适用（见"最弱未证步骤"）。
- (ii) **t₀′ = t′ 自动有效**：t′ 处所有距离都 ≥ δ > δ′。
- (iii) **K\*′ 自动存在，且长度 ℓ\*′ ≥ 2(δ − δ′)/v′_max**：由 Lipschitz 性，t′ 的这个邻域内所有距离都 ≥ δ − v′_max·|Δt| ≥ δ′。
- (iv) **需要检查的见证个数**：M′ = 2δ′P′/ℓ\*′ ≤ 2δ′P′·v′_max/(2(δ − δ′)) = (k+2)·N′_max，其中 N′_max = v′_max·P′（化整后最大的速度）。所以至多有 ⌈(k+2)N′_max⌉ − 1 个见证。

**证明**：
- (i)–(iii) 如上所述。
- (iv)：δ − δ′ = 1/((k+2)(k+3))，所以 2δ′/(2(δ − δ′)) = (k+2)。∎

**所以**：证书中**只有第 4 项**（有限个见证 t′_m）不会自动再生。其余各项都由 t(u) 直接给出。

## PROOF 4 · 实例：对一切实数 u，(1, 2, 3, u) 都可解（门槛 1/5，手证）

V = (1, 2, 3)，P = 1，δ = 1/5。
- **K\* = [1/5, 4/15]**：在两端点处，距离分别为 (1/5, 2/5, 2/5) 与 (4/15, 7/15, 1/5)，都 ≥ 1/5。在内部，1·t ∈ [1/5, 4/15]，2t ∈ [2/5, 8/15]，3t ∈ [3/5, 4/5]，每个分量的距离都 ≥ 1/5。所以 ℓ\* = 1/15。
- **M** = 2·(1/5)·1/(1/15) = 6，需要检查 m = 1, …, 5：
  - m = 1, 2, 3：u ∈ V，取 t = 1/5；
  - m = 4：t = 1/5，四个距离为 1/5、2/5、2/5、1/5（与主席的计算一致）；
  - m = 5：t = 6/25，四个距离为 6/25；12/25；18/25 → 7/25；30/25 → 1/5。
- **结论**：对每个实数 u > 0，DEC 给出 (1, 2, 3, u) 在 1/5 下的显式安全时间。
  - 非整数 u 用 (a)，从 t₀ = 1/5 出发；
  - 整数 u ≥ 6 用 (b)，在 [1/5, 4/15] 内取点；
  - u ≤ 5 用 (c)。∎

## 失败的尝试与反例

### 反例 SF：Fourier 平坦性不变量 **DISPROVED**
**提出的不变量**：存在 S_δ(V) 上的概率测度 μ，使得对一切共振 u ≠ 0，都有 Re μ̂(u) ≤ cos(2πδ)。

**成立时的推论**（证明）：若插入 u 失败，则 S ⊆ u 的不安全带，于是在 S 上处处有 cos(2πut) > cos(2πδ)，从而 Re μ̂(u) > cos(2πδ)。所以这个不变量确实**蕴含**插入对所有 u 成功。

**否证**：V = (1, 2, 3)，δ = 1/5，S = [1/5, 4/15] ∪ {2/5, 3/5} ∪ [11/15, 4/5]。取 λ = {u = 4：0.37，u = 5：0.43，u = 15：0.20}，令 f(t) = Σ λ_u cos(2πut)。
- 由 t ↦ 1 − t 的对称性，只需考察 [1/5, 4/15] ∪ {2/5}。
- f(2/5) = 0.37·cos(2π·8/5) + 0.43 + 0.20 = 0.3307。
- 在 [1/5, 4/15] 上，min f = 0.32301，在 t = 4/15 处取得：f(4/15) = 0.37·cos(2π/15) − 0.43/2 + 0.20。

  这个最小值是计算机辅助得到的：在 2,000,001 个格点上求值，f 的 Lipschitz 常数为 2π·6.63，误差 ≤ 7×10⁻⁷。
- 所以对 S 上**任意**概率测度 μ，都有 Σ λ_u Re μ̂(u) = ∫ f dμ ≥ 0.3230 > cos(2π/5) = 0.3090，从而某个 u ∈ {4, 5, 15} 使 Re μ̂(u) > cos(2πδ)。
- 但由 PROOF 4，这三个 u 的插入**都成功**。所以 SF 比所需要的结论严格更强，而且已经在 k = 3 失败。

**补充**（CHECKED）：只取 μ = S 上的 Lebesgue 测度时，SF 在 k = 3（速度 ≤ 14）的 325 组本原整数集中有 297 组不成立。
