# Part I · 不变量 I_n(V)：安全剖面证书 SPC

## §1 定义
- V 为 n−1 个正**有理**速度（第 n 层，门槛 1/n）。
- g_V 为 V 的有理最大公约数，P_V = 1/g_V。
- **剖面** m_V(t) = min_{v∈V} ‖vt‖。

**引理 S（结构）**：
- m_V 以 P_V 为周期；
- m_V 关于 0 和 P_V/2 对称（m_V(−t) = m_V(t)）；
- 在 [0, P_V/2] 上分段线性，每段斜率为 ±v（v ∈ V）。

**证明**：每个 v·P_V 都是整数，所以每个 ‖vt‖ 以 P_V 为周期；又 ‖−z‖ = ‖z‖；‖vt‖ 本身分段线性，斜率 ±v；有限个分段线性函数取最小值仍分段线性。∎

**定义**：**I_n(V) = (P_V, B_V)**，其中 B_V 是 m_V 在 [0, P_V/2] 上全部断点 (t_i, m_V(t_i)) 的有序表（含两端点），所有分量都是有理数。在相邻断点之间，m_V 由线性插值精确给出。

## §2 有限性与规模界（证明）
令 N_v = v·P_V ∈ ℤ，σ = Σ_v N_v（即 V 化成本原整数组后的速度之和）。

**定理 SZ**：|B_V| ≤ (n−1)(σ + 1)。

**证明**：
1. m_V 的断点只可能是两类：某个 ‖vt‖ 自身的断点，或某两个 ‖vt‖ 与 ‖v′t‖ 的交点。
2. 自身断点：在 [0, P_V/2] 上，‖vt‖ 的断点为 j/(2v)，j = 0, …, N_v，共 N_v + 1 个；合计 σ + (n−1) 个。
3. 交点：对一对 v ≠ v′，把两者的断点合并，[0, P_V/2] 被分成 ≤ N_v + N_{v′} 段。每段上两者都是线性的，且斜率绝对值不同（v ≠ v′），所以至多相交一次。对所有 C(n−1, 2) 对求和，得 Σ(N_v + N_{v′}) = (n−2)σ。
4. 合计 ≤ σ + (n−1) + (n−2)σ = (n−1)(σ + 1)。∎

**注**：这个上界是**伪多项式的**：它随化整后的速度大小增长，而不是随位长增长。

## §3 允许的操作（全部是确定性、有限的有理运算）
- **(O1) ARGMAX**：κ(V) = max_i m_V(t_i)；t\* = 使 m_V(t_i) = κ(V) 的**最小正**断点。
  - **正确性**：连续分段线性函数在紧区间上的最大值，必在某个断点处取得。m_V(0) = 0，所以若 κ(V) > 0，则 t\* > 0。
  - **输出**：F_n^{SPC}(V) := t\*。
- **(O2) ADD(u)**：由 I_n(V) 和新速度 u 计算 I_{n+1}(V ∪ {u})。
  1. P′ = 1/gcd(V ∪ {u})。它是 P_V 的整数倍，因为 gcd(V ∪ {u}) 整除 g_V。
  2. 利用周期性和对称性，把 B_V 展开到 [0, P′/2]，即取所有点 kP_V ± t_i。
  3. 并入 ‖ut‖ 的断点 j/(2u)。
  4. 在合并后的每一小段上，m_V 与 ‖u·‖ 都是线性的；若两者之差在两端变号，就解一次线性方程，加入交点。
  5. 在所有候选点上计算 min(m_V, ‖u·‖)，删去共线的点，得到 B_{V∪{u}}。

  **正确性**：m_{V∪{u}} = min(m_V, ‖u·‖)。最小值函数的断点只可能是两者各自的断点或交点，第 2–4 步把它们全部包括了。∎

# Part II · N、TF、CORE 的重写

## §8 定义与定理 CORE（重写，量词写清）
**定义**：
- **𝔉_n**：所有"规则" F 的集合。F 对每个由 n−1 个正有理数组成的集合 W 给出一个 t > 0，使对所有 w ∈ W，‖wt‖ ≥ 1/n。（不要求齐次，不要求闭式。）
- **OTP 输出集**：𝒪(V) = { t > 0 : t ∈ S_{1/(n+1)}(V)，且存在 u ∈ V，使 min_{w∈V∖u} ‖wt‖ ≥ 1/n }。
- **C_n = { V : 𝒪(V) = ∅ }**。
  等价地：V 的每一个安全时间处，至少有两位跑者的距离 < 1/n。若 V 没有安全时间，则 V ∈ C_n 空洞地成立。对于五跑者（n = 4），按主席所述的已知存在性，这种情形不会出现。

**CORE-1（对所有规则、所有局外人、所有精确周期）**：对每个 F ∈ 𝔉_n、每个 u ∈ V、V∖{u} 的每个精确周期 P（即使 wP ∈ ℤ 对所有 w ∈ V∖{u} 成立的 P > 0），以及每个 j ≥ 0：若 t = F(V∖u) + jP 对 V 安全，则 t ∈ 𝒪(V)。

所以 **V ∈ C_n ⇒ 对每个 F，V ∈ E\*_n(F)**。

**证明**：
- 由周期性，V∖{u} 在 t 处的相位与在 F(V∖u) 处相同，都 ≥ 1/n。
- V∖{u} 的精确周期恰好是 (1/g_u)·ℤ_{>0}，所以"所有精确周期"不比"规范周期 1/g_u"多出任何情形。
- 若 u/g_u ∈ ℤ，则对每个精确周期，步长 x 都等于 0。∎

**CORE-2（逐点逆命题；F 允许依赖于 V）**：若 𝒪(V) ≠ ∅，则存在 F ∈ 𝔉_n，使 V ∉ E\*_n(F)。

所以 **⋂_{F∈𝔉_n} E\*_n(F) = C_n**。

**证明**：
1. 取 t ∈ 𝒪(V) 及对应的 u。令 F′ 在 W = V∖{u} 上取值 t（这是 W 的合法输出），在其他输入上任意取合法值。
2. 当 PS\* 轮到 u 时，(S0) 给出 j = 0。若排在前面的局外人已经成功，V 同样不是例外。∎

**明确不主张的内容**：
- (a) **不主张**存在**单一**的 F 使 E\*_n(F) = C_n 对所有 V 同时成立。两个不同的 V 可能共用同一个 W 而要求不同的时间。——UNFINISHED。
- (b) **不主张** C_n 对 OTP 类以外的规则（TL、FO、CLR v2、SPC）构成障碍。实际上由 DOM，C_n 对 SPC 不构成障碍。
- (c) 对固定的有限规则族 {T4}，本席 R022 报告的分类（1,689 = 11 + 1,678）**只是本席的计算报告**，Hesper 尚未独立重算，不应记为独立 CHECKED。

**状态**：CORE-1、CORE-2：PROOF CANDIDATE。

## §9 定理 TF（重写）及新增的手证
**TF**：设 n ≥ 2，V_n = (1, 2, …, n)，门槛 1/(n+1)。
- (i) S_{1/(n+1)}(V_n) = { k/(n+1) + ℤ : gcd(k, n+1) = 1 }。安全集**非空**，但只由孤立点组成。
- (ii) 在每个安全时间处，恰有两位跑者的距离等于 1/(n+1)，其余都 ≥ 2/(n+1)。
- (iii) 对每个 λ > 0，λV_n ∈ C_n。
- (iv) 当 n ≥ 3 时，对每个 F ∈ 𝔉_n，λV_n ∈ E\*_n(F)（由 CORE-1）。

**证明**：
1. 对 v = 0, …, n，令 z_v = frac(vt)，共 n+1 个点在圆周上。z_i 与 z_j 的圆周距离等于 ‖(i−j)t‖，且 |i − j| ∈ V_n。
2. 若 t 安全，则两两距离都 ≥ 1/(n+1)。n+1 段弧的长度之和为 1，每段都 ≥ 1/(n+1)，所以每段**恰好**等于 1/(n+1)，点等距分布。因此 t ≡ k/(n+1)，并且由于各点互异，gcd(k, n+1) = 1。反之，每个这样的 k 都给出等距分布，所以确实是安全时间。这证明 (i)。
3. v ↦ vk mod (n+1) 是 {1, …, n} 上的双射。所以恰有一个 v 满足 vk ≡ 1，恰有一个满足 vk ≡ −1；由于 n+1 ≥ 3，两者不同。这证明 (ii)。
4. 去掉任何一个 u，这两位中至少剩下一位，其距离 1/(n+1) < 1/n，所以 𝒪 = ∅。这证明 (iii)；(iv) 由 CORE-1 得到。∎

**新增 TF′（V₁ = (1, 3, 4, 7) ∈ C₄，手证；R022 时只是 CHECKED）**：
1. 令 x = frac(t)。由对称性 t ↦ −t，只需看 x ∈ [0, ½]。条件 ‖x‖ ≥ 1/5 给出 x ∈ [1/5, ½]。
2. **‖3x‖ ≥ 1/5**：3x ∈ [3/5, 3/2]，所以 3x ∈ [3/5, 4/5] ∪ [6/5, 3/2]，即 x ∈ [1/5, 4/15] ∪ [2/5, ½]。
3. **情形 A**，x ∈ [1/5, 4/15]：4x ∈ [4/5, 16/15]。要 ‖4x‖ ≥ 1/5，须 4x ≤ 4/5 或 4x ≥ 6/5；而 16/15 < 6/5，所以只能 x = 1/5。核对 7/5：距离 2/5 ✓。
4. **情形 B**，x ∈ [2/5, ½]：4x ∈ [8/5, 2]，要求 4x ≤ 9/5，即 x ≤ 9/20。此时 7x ∈ [14/5, 63/20]，要 ‖7x‖ ≥ 1/5，须 7x ≤ 14/5（因为 63/20 < 16/5），所以只能 x = 2/5。核对 3·2/5 = 6/5：距离 1/5 ✓；4·2/5 = 8/5：距离 2/5 ✓。
5. 所以 S_{1/5}(V₁) = {±1/5, ±2/5} + ℤ。
   - t = 1/5 处，速度 1 与 4 的距离为 1/5；

   每个安全时间都有两位跑者 < 1/4，所以 V₁ ∈ C₄。∎
