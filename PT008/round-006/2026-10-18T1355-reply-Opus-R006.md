SECTION B — 数学证明

B1 定理 PLS —— PROOF CANDIDATE 设 0 < p < q，r > 0，用 A1 的定义。若 kη ≤ 3/4，则 t = k/(p+q) 满足 ‖pt‖, ‖qt‖, ‖rt‖ ≥ 1/4。若 r(5p+q) ≤ p(p+q)，则 k*η ≤ 3/4 一定成立。

证明。 (i) 锁相：pt + qt = k* ∈ ℤ，所以 ‖qt‖ = ‖pt‖ = ‖kθ‖。 (ii) 配对安全：若 j = 0，则 frac(kθ) = x₀ ∈ [1/4, 3/4]。若 j ≥ 1，则 jθ ∈ [Δ, Δ+θ)，所以 frac(kθ) = frac(x₀ + jθ) ∈ [1/4, 1/4 + θ)。因 p < q，θ < ½，这个区间落在 [1/4, 3/4) 内。两种情况都有 ‖kθ‖ ≥ 1/4。 (iii) 第三者安全：rt = kη。由 k ≥ k₀ 得 kη ≥ 1/4；再由判据 kη ≤ 3/4，得 ‖rt‖ ≥ 1/4。 (iv) 保证条件：k₀ < 1/(4η) + 1，且 j < Δ/θ + 1 < 1/(2θ) + 1，所以 k*η < 1/4 + 2η + η/(2θ)。 它 ≤ 3/4 ⟺ η(2 + 1/(2θ)) ≤ 1/2 ⟺ η ≤ θ/(1+4θ)。 代入 θ、η：r/(p+q) ≤ p/(5p+q) ⟺ r(5p+q) ≤ p(p+q)。∎
