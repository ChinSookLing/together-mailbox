# Part I · Track A · Nested Window 的持续不变量

## A1 三个概念（定义）
固定 N（跑者总数）与 δ = 1/N。设 V 为一组非零速度。
1. **成功点**：一个 t > 0，使 ‖ut‖ ≥ δ 对全部 u ∈ V 成立。
2. **正长度安全窗口**：区间 J = [α, β]，α < β，使 J 中每一点都是成功点。
3. **对下一速度 v 的持续窗口**：一个正长度安全窗口 J，满足 v|J| > 1。这样就能在 J 里为 V ∪ {v} 再取出一个正长度安全窗口（见 A2）。如果只满足 v|J| ≥ 2δ，则只能保证得到一个成功点。

(3) 依赖下一个速度 v，所以它不是 V 自身的性质。

## A2 引理 FNW（前向嵌套窗口，PROOF CANDIDATE）
速度 u₁ < … < u_k（k = N−1），选一个首块长度 p（1 ≤ p ≤ k−1），要求 u_p ≤ (N−1)u₁。

**算法**：
1. **首块（簇窗口）**：J = [lo, hi]，lo = δ/u₁，hi = (1−δ)/u_p。
2. **中间各步** i = p+1, …, k−1：令 u = u_i，L = u·(hi − lo)，X = u·lo。
   - 若 L ≤ 1：本首块长度失败。
   - 否则令 λ = min(1−2δ, L−1)。若 frac(X) ∈ [δ, 1−δ−λ]，取 q = X；否则取 q = ⌈X − δ⌉ + δ。
   - 更新 lo = q/u，hi = lo + λ/u。
3. **最后一步** u = u_k，X = u·lo：
   - 若 ‖X‖ ≥ δ，输出 t = lo；
   - 否则，若 L = u(hi − lo) ≥ 2δ，输出 t = (round(X) + δ)/u；
   - 否则本首块长度失败。

**选择规则**：依次试 p = 1, 2, …, k−1，取第一个成功的。最多 k−1 次闭式运算，不搜索 t。

**证明**：
- **首块**：对 t ∈ [lo, hi] 与 i ≤ p，有 u_i t ∈ [u₁·lo, u_p·hi] = [δ, 1−δ]。区间非空 ⟺ u_p ≤ (N−1)u₁。
- **中间步：落在一条安全弧内**。第一种情形 frac(X) ∈ [δ, 1−δ−λ]，所以 [X, X+λ] 在一条弧内；第二种情形 q = j + δ，[q, q+λ] ⊂ [j+δ, j+1−δ]，因为 λ ≤ 1−2δ。
- **中间步：嵌套**。q ≥ X，所以新 lo ≥ 旧 lo。q < X + 1 且 λ ≤ L − 1，所以 q + λ < X + L = u·旧 hi，即新 hi < 旧 hi。
  因此新窗口在旧窗口内，此前所有速度仍然安全；u_i 也安全。新窗口长度 λ/u > 0。
- **最后一步**：若 ‖X‖ ≥ δ，lo 本身就在窗口内，成立。否则 X ∈ (k′−δ, k′+δ)，其中 k′ = round(X) 唯一（因 δ < ½），所以 0 < t − lo < 2δ/u ≤ L/u = hi − lo，t 在窗口内，且 ‖ut‖ = δ。
- **正性**：t ≥ lo ≥ δ/u₁ > 0。∎

**包含关系**：
- **FNW ⊇ GW(N)**：p = k−1，最后一步的条件 L ≥ 2δ 正是 (G2)。
- **FNW ⊇ NW(N)**：取 p = 1。对 i 归纳可证 FNW 的窗口长度 λ_i^F ≥ NW 的 λ_i^NW。基础：λ₁^F = 1−2δ ≥ λ₁^NW。归纳：L_i = (u_i/u_{i−1})λ_{i−1}^F ≥ (u_i/u_{i−1})λ_{i−1}^NW = 1 + λ_i^NW，所以 λ_i^F = min(1−2δ, L_i − 1) ≥ λ_i^NW。最后一步 L_k ≥ (u_k/u_{k−1})λ_{k−1}^NW = 2δ。∎

## A4 持续性判据（PROOF CANDIDATE）

**质量**：Q_i = u_i·|J_i|，即窗口在 u_i 相位中的长度。对单人步骤，令 ρ_i = u_i/u_{i−1}。由 A2 的算法：
**Q_i = min(1−2δ, ρ_i·Q_{i−1} − 1)**（要求 ρ_i·Q_{i−1} > 1）

**推论**：
- **(a) 必要条件**：Q_{i−1} ≤ 1−2δ，所以单人步骤要得到正长度窗口，必须 ρ_i > 1/(1−2δ) = **N/(N−2)**。N = 5 时为 5/3。
- **(b) 满弧不变**：若 Q_{i−1} = 1−2δ，则 Q_i = 1−2δ 当且仅当 ρ_i ≥ (2−2δ)/(1−2δ) = **2(N−1)/(N−2)**。N = 5 时为 8/3。
- **(c) 递减**：若 ρ_i < 2(N−1)/(N−2)，则 Q_i < Q_{i−1}。因为 Q_i − Q_{i−1} = (ρ_i − 1)Q_{i−1} − 1 ≤ (ρ_i − 1)(1−2δ) − 1 < 0。
  所以若相邻比值长期低于 8/3（N = 5），窗口会逐步缩短，最终无法持续。

**结论**：只用"单人嵌套"不能维持一个无限制的归纳不变量。可以持续的精确假设是 ρ_i·Q_{i−1} > 1，至于每一步是否满弧，由 (b) 判定。

## A5 命题：成功点不蕴含正长度窗口（PROOF CANDIDATE）
**命题**：对 V = {1, 2, …, N−1}、门槛 1/N，成功点集合 ⊂ (1/N)ℤ。所以 V 有成功点（t = 1/N），却**没有任何正长度安全窗口**。

**证明**：设 x = frac(t)，考虑圆周上的 N 个点 0, x, 2x, …, (N−1)x（mod 1）。必有两点 ix、jx 的圆周距离 ≤ 1/N，即 ‖(i−j)x‖ ≤ 1/N，其中 1 ≤ |i−j| ≤ N−1。
若 t 成功，则 ‖(i−j)x‖ ≥ 1/N，所以这一距离恰为 1/N。这对**每一对**相邻点都成立，所以 N 个点等距分布，间距 1/N。因此 x ∈ (1/N)ℤ。∎

**意义**：
- 在"每一阶段门槛 1/n"的在线框架里，紧前缀（例如 n = 4 时的 {1,2,3}）没有正长度窗口，所以以窗口为不变量的递归无法经过紧前缀。
- 在"全程使用最终门槛 1/N"的离线框架（NW / FNW）里，前缀的门槛更宽松，这个障碍不出现。但离线框架需要事先知道 N。

## A6 缺失的桥（IDEA）

# Part II · 独立非作者审阅：Qwen「a+d、τ = 2」区域

## R1 精确假设
- (H0) 0 < a < b < c < d（实数）。
- (H1) c < 4a。
- (H2) d > 4a。
- (H3) d > (5c − 2a)/2。
- (H4) d < 9a。
- (H5) d < 4c。

输出 t = 2/(a+d)。

## R2 符号证明
令 S = a + d，t = 2/S > 0。
- **a**：at = 2a/S。由 (H2)，S > 5a，所以 at < 2/5；由 (H4)，S < 10a，所以 at > 1/5。因此 at ∈ (1/5, 2/5)，‖at‖ = at > 1/5。
- **d**：at + dt = 2，所以 dt = 2 − at ∈ (8/5, 9/5)，‖dt‖ = ‖at‖ > 1/5。
- **c 的上界**：(H3) ⟺ 2d > 5c − 2a ⟺ 2S > 5c ⟺ ct = 2c/S < 4/5。
- **c 的下界**：由 (H5)，S < a + 4c，所以 ct > 2c/(a + 4c)。而 2c/(a+4c) ≥ 1/5 ⟺ 10c ≥ a + 4c ⟺ 6c ≥ a，由 (H0) 成立。所以 ct ∈ (1/5, 4/5)，‖ct‖ > 1/5。
- **b**：由 (H0)，at < bt < ct，所以 bt ∈ (1/5, 4/5)，‖bt‖ > 1/5。∎

**附注**：
- (H1) 在证明中没有用到。它由区间非空推出：(5c − 2a)/2 < 9a ⟺ c < 4a。
- d > c 也是自动的：(5c − 2a)/2 > c ⟺ c > 2a/3。

## R3 边界（每个等号单独检查）
- **d = 9a**：at = 1/5，‖·‖ = 1/5，合格。
- **d = 4a**：at = 2/5，合格。
- **d = (5c − 2a)/2**：ct = 4/5，‖·‖ = 1/5，合格。
- **d = 4c**：ct = 2c/(a + 4c) ∈ (1/5, ½)，合格（此处 LN 也适用）。

结论：**闭区域同样成立**，严格不等号可以全部改为 ≤（在 H0 下）。

**算例**：
