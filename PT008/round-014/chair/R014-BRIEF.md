Mission

Seek a reusable constructive mechanism for the unrestricted five-runner problem.

Given arbitrary real speeds:

0 < a < b < c < d,

construct t > 0 satisfying:

||at||, ||bt||, ||ct||, ||dt|| ≥ 1/5.

Do not turn the known successful examples into an unbounded candidate-time search.

* Opus NW(N)

Obtain the verbatim L2 theorem before assessing DeepSeek’s R-L2. Determine whether it is equivalent to, weaker than, or genuinely stronger than existing L2.

Priority 2 — Four Gap Witnesses

Study the following speed sets:

V1 = (1, 11/10, 3, 41/10)
V2 = (1, 2, 3, 9/2)
V3 = (1, 3, 4, 7)
V4 = (1, 30, 60, 80)

Before using any as an uncovered witness, independently recheck membership against the complete certified rule inventory.

Determine which structural feature each witness exposes.

The objective is a new formula whose sufficient region explains multiple witnesses, not a separate special-case formula for each tuple.

Track A — Opus · Nested Window

Investigate whether NW(N) can support a persistent inductive invariant.

Track C — Argon · Independent Adversarial Check

Challenge all proposed universal extensions.

Give exact symbolic counterexamples whenever possible.

Explicitly distinguish failure of one formula from failure of all constructions.

Track D — DeepSeek · Structural Comparison

Compare the original proven L2, proposed R-L2 and NW(N).

Identify the precise extra property needed to carry a construction to the next runner count.

Is that property preserved under an inductive step?

A negative answer with a proof is a useful result.
