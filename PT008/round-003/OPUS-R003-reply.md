## A. 精确命题
**A1（精确分量 Exact Component）** S_{n+1}(V) 中包含 t_x 的连通分量是 K_x = [t_x − λ, t_x + μ]，λ = min_u (f_u − δ)/|u|，μ = min_u (1 − δ − f_u)/|u|。且 K_x ⊂ (0, ∞)。
**A2（Lipschitz 窗口）** ρ_x = min_u (d_u − δ)/|u| = min_u min((f_u−δ),(1−δ−f_u))/|u|，J_x = [t_x−ρ_x, t_x+ρ_x] ⊂ K_x，且 ρ_x ≥ h = 1/(n(n+1)M)。
**A3（单窗口精确失败判据，回答 Q1）**
- J_x 失败 ⟺ ‖wt_x‖ < δ − |w|ρ_x，等价于 Nudge 位移 (δ − ‖wt_x‖)/|w| > ρ_x。
- K_x 失败 ⟺ 存在整数 k 使 k − δ < |w|(t_x−λ) 且 |w|(t_x+μ) < k + δ。
- 全局无解 ⟺ S_{n+1}(V) 的每一个分量（包括不含任何 S_n 点的分量）都失败。
**A4（双窗口引理 Two-Window Lemma）** 若 ‖w(t_a − t_b)‖ ≥ 2δ − |w|(ρ_a + ρ_b)，则 J_a 或 J_b 之一含有 S_{n+1}(V∪{w}) 的点。
**A5（推论，只用最坏窗口 h）** 若 ‖w(t_a − t_b)‖ ≥ (2/(n+1))·(1 − |w|/(nM))，则 A4 成立。当 |w| ≥ nM 时右边 ≤ 0，自动退化为 L2。

## B. 证明或反例
**B1 证明 A1、A2。** 在 t ∈ [t_x−λ, t_x+μ] 内，每个 y_u 的小数部分连续地停留在 [δ, 1−δ]，故 ‖ut‖ ≥ δ。在右端点，达到 μ 的那个 u 恰好有 frac = 1−δ，越过即 < δ；左端同理。所以 K_x 正是该分量。左端 t_x − (f_u−δ)/|u| = (⌊y_u⌋ + δ)/|u| > 0。ρ_u = min(λ_u, μ_u) 给出 J_x ⊂ K_x；d_u ≥ 1/n 给出 ρ_x ≥ (1/n − δ)/M = h。∎
**B2 证明 A3。** J_x 是区间，w·J_x 是以 wt_x 为中心、半宽 |w|ρ_x 的区间。坏集 {‖·‖ < δ} 的分量是开区间 (k−δ, k+δ)。连通的 w·J_x 不含好点 ⟺ 整段落在某一个坏分量内 ⟺ |wt_x − k| + |w|ρ_x < δ。取 k 为最近整数即得。K_x 同理（端点不对称）。∎
**B3 证明 A4（双窗口引理）。** 反设两窗口都失败。由 A3：‖wt_a‖ < δ − |w|ρ_a，‖wt_b‖ < δ − |w|ρ_b。用 ‖x − y‖ ≤ ‖x‖ + ‖y‖：‖w(t_a − t_b)‖ ≤ ‖wt_a‖ + ‖wt_b‖ < 2δ − |w|(ρ_a+ρ_b)，矛盾。∎
常数审查：只知道 (‖wt_a‖, ‖wt_b‖, ρ_a, ρ_b) 时，取 wt_a = k + (δ − |w|ρ_a − ε)，wt_b = k′ − (δ − |w|ρ_b − ε)，两窗口皆失败，且相位差 = 2δ − |w|(ρ_a+ρ_b) − 2ε。所以 2δ 不能改小。（这类配置能否由真实的 V 实现：UNFINISHED。）
**B4 实例验证（Round 002 的反例被双窗口救回）。** n=2，V={1}，w=4/3。单窗口 t_a=3/2 失败（R002 B2）。取 t_b = 1/2：ρ_a = ρ_b = 1/6，右边 = 2/3 − (4/3)(1/3) = 2/9，左边 ‖4/3‖ = 1/3 ≥ 2/9 ✓。确实 t_b 窗口成功（‖2/3‖ = 1/3）。
**B5 反例一：任意多个 Lipschitz 窗口都不够 —— DISPROVED。** V = {1,2}（n=3），w = 3，δ = 1/4。S_3({1,2}) = {1/3, 2/3} + ℤ（R001 B1 的计算）。在 t_a = 1/3：ρ = min(1/12, 1/24) = 1/24，J = [7/24, 9/24]，3J = [7/8, 9/8] ⊂ (3/4, 5/4)，失败。t = 2/3 对称失败。w 是整数，平移 ℤ 不改相位，所以所有旧窗口都失败。但 S_4({1,2,3}) = {1/4, 3/4} + ℤ ≠ ∅。换成精确分量就能救回：K = [1/4, 3/8]，|w|L = 3/4，‖3/4‖ = 1/4 ≥ δ，取 t = 1/4 ✓。
**B6 反例二：连精确分量都不够 —— DISPROVED。** V = {1,3}，w = 2。S_3({1,3}) = [4/9, 5/9] + ℤ，其 S_4 分量为 K = [5/12, 7/12]。2K = [5/6, 7/6] ⊂ (3/4, 5/4)，失败。但 S_4({1,3,2}) = {1/4, 3/4} + ℤ 非空。点 1/4 所在的 S_4({1,3}) 分量是孤立点 {1/4}，其上 g = 1/4 < 1/3，不含任何旧成功时间。结论："新解一定在某个旧成功时间的附近"是假的，即使"附近"取到精确分量也一样。
**B7** B5 与 B6 合看：插入顺序（insertion order）很关键。同一个终点集 {1,2,3}：先 {1,2} 再加 3，精确分量法成功（B5）；先 {1,3} 再加 2，失败（B6）。

## C. 构造步骤
**C1 单个精确窗口的显式 Nudge（无搜索）—— PROOF CANDIDATE** 输入 K = [L, R]，A = |w|L，B = |w|R：1. 若 ‖A‖ ≥ δ，输出 L；2. 否则若 ‖B‖ ≥ δ，输出 R；3. 否则令 k_A = round(A)，k_B = round(B)。若 k_A = k_B，本窗口失败；否则输出 t = (k_A + δ)/|w|。第 3 步正确性：k_B ≥ k_A + 1 且 B > k_B − δ ≥ k_A + 1 − δ ≥ k_A + δ，所以 t ∈ (L, R)，且 ‖wt‖ = δ。∎
**C2 双窗口规则（回答 Q3）** 给定 t_a, t_b ∈ S_n(V)：1. 由 A1 公式算出 K_a, K_b；2. 对 K_a 跑 C1；成功即输出；3. 否则对 K_b 跑 C1；4. A4 的条件保证第 2 或第 3 步至少一个成功（精确分量 ⊇ Lipschitz 窗口）。
**C3 需要的额外信息**
- 第二个旧时间从哪里来：整数（或有公共周期 P）速度时，有免费的反射时间 t_b = P − t_a，因为 ‖u(P−t)‖ = ‖ut‖。一般实数速度下没有已知的免费第二时间。这一项交给 Qwen。
- 比两个时间更根本的需求：B6 表明，必须掌握 S_{n+1}(V) 中不含旧成功时间的分量。由 R003 提案中的 T1，这些分量的峰值都位于临界时间 c/(|u|+|u′|)，可作为下一阶段的信息来源。
**C4 插入顺序 —— IDEA** B7 提示：构造 F(V) 时，应选择插入顺序，而不是按给定顺序插入。候选规则："最后插入最快的速度"。{1,2,3} 支持此规则。是否普遍成立：UNFINISHED，是 Argon 的好靶子。
