一、双窗口引理：主席独立证明

PROVED — 以下精确定义的版本成立。

设新跑者速度为 w ≠ 0，安全门槛满足：

0 < δ ≤ 1/2.

已有两个完整的闭区间窗口：

I_a = [t_a − ρ_a, t_a + ρ_a],  I_b = [t_b − ρ_b, t_b + ρ_b],

其中 ρ_a, ρ_b ≥ 0，且两个窗口都在合法时间范围内，旧跑者在窗口内始终安全。

若

‖w(t_a − t_b)‖ ≥ 2δ − |w|(ρ_a + ρ_b)

则至少一个窗口包含新跑者的安全时间。

证明

反设两个窗口都没有新跑者的安全时间。

那么在两个窗口内始终有：

‖wt‖ < δ.

由于 δ ≤ 1/2，每个连续窗口必须完全位于某个整数附近的同一段不安全区内。

因此对窗口中心：

‖w t_a‖ < δ − |w| ρ_a,
‖w t_b‖ < δ − |w| ρ_b.

利用圆周距离的三角不等式：

‖w(t_a − t_b)‖ ≤ ‖w t_a‖ + ‖w t_b‖ < 2δ − |w|(ρ_a + ρ_b).

与假设矛盾。

所以至少有一个窗口包含新跑者的安全时间。证毕。

注意： 这里证明的是「至少一个窗口中存在安全时间」，不是已经给出了无需选择或搜索便能计算该时间的完整规则。

三、为什么 Round 004 应该转向 T1？

我现在更明确地看到一个区别。

窗口路线

从已知安全时间出发，尝试寻找附近的新安全时间。

局限：新的成功时间可能位于另一个不连通的安全区。

临界时间路线（T1）

不要求新时间靠近旧时间，而是研究整组三角波的几何交汇结构。

目标：直接从速度关系确定正确的候选时间。

Opus 的 T1 候选形式是：

t = c / (|u| + |u′|)

它对 PT-008 很有吸引力，因为候选时间的形式不随跑者人数改变。

但我们必须记住：

知道候选时间的形状，不等于知道如何选择正确的候选。

而且 T1 目前仍是独立证明待完成的候选定理。

五、给 Tuzi 的研究报告

Tuzi，这一轮有一件事情，我想用最简单的话告诉你。❤️

我们原本想：

已经有一个安全时间，增加跑者后，把时间移动一点就好。

但 Opus 发现，有时候无论怎样在原来的安全区域附近移动，都不能找到新答案。

这不代表没有答案，而是答案可能在另一处。

所以，我决定改变研究重点。

不再只问「怎样移动旧时间」，而是问：

「所有可能的好时间，是否具有某种共同的数学形状？如果有，怎样直接选中正确的那个？」

这更接近你希望的「从空气中创造一个 Time Formula」。
