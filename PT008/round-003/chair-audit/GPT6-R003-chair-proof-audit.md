一、Opus 双窗口引理：严格证明核对

设旧系统有 n 位跑者，新增速度 w，新门槛为：

δ = 1/(n+1)

对两个旧成功时间 t_a, t_b，分别构造对所有旧速度安全的闭窗口：

J_a = [t_a − ρ_a, t_a + ρ_a]
J_b = [t_b − ρ_b, t_b + ρ_b]

其中 ρ_a, ρ_b 均非负。

Opus 的命题是：

‖w(t_a − t_b)‖ ≥ 2δ − |w|(ρ_a + ρ_b)

则两个窗口至少有一个包含新增跑者也安全的时间。

PROOF — 主席重建证明

假设两个窗口都失败。

由于窗口内没有新人安全时间，整个闭窗口必须严格落在某一个开放危险区内。

所以：

‖w t_a‖ + |w| ρ_a < δ

以及：

‖w t_b‖ + |w| ρ_b < δ

两式相加：

‖w t_a‖ + ‖w t_b‖ < 2δ − |w|(ρ_a + ρ_b)

利用圆周距离的三角不等式：

‖w(t_a − t_b)‖ ≤ ‖w t_a‖ + ‖w t_b‖

因此：

‖w(t_a − t_b)‖ < 2δ − |w|(ρ_a + ρ_b)

与假设矛盾。

证毕。

主席判断：证明成立，包括等号边界。

这里没有使用有限搜索，也没有额外假设整数速度。

三个重点审计项目

项目 | 结果 | 原因
安全端点 | PASS | 危险区是开区间，等号属于安全
是否迫使安全点进入窗口 | PASS | 两窗口同时失败会产生严格矛盾

特别解释第三项：

如果 w(t_a − t_b) 恰好是整数，那么左边是零。

当右边为正时，引理的前提不成立，不能宣称成功。

当右边小于或等于零时，引理仍然成立，因为任何一个 Lipschitz 窗口都已经足够宽，无法完全装进一个开放危险区。

所以整数周期重合不构成 A4 的反例。

三、Qwen：发现两处需要正式修正的问题
1. Prop 1 的整数判据错误

Qwen 给出的：

⌈|w|β − δ⌉ ≤ ⌊|w|α + δ⌋

不能等价于窗口完全失败。

原因是：这个表达式可能把危险区的端点也算作危险。

举一个直接反例：

w = 1, δ = 1/4, W = [1/4, 1/4]

窗口中的时间满足：

‖1/4‖ = 1/4

所以它是安全的。

但 Qwen 的整数判据得到：

⌈0⌉ ≤ ⌊1/2⌋

即：

0 ≤ 0

它会错误地判定窗口失败。

正确条件： 必须存在整数 k，严格满足：

|w|β − δ < k < |w|α + δ

保留两个严格不等号即可避免端点错误。

因此，Qwen Prop 1 的区间形式正确，但整数取整形式必须撤回并修正。

2. Qwen 的双窗口反例确实失败

对于：

V = {1, 2}, w = 1/3, δ = 1/4

取：

t = 3/4

得到：

‖t‖ = 1/4, ‖2t‖ = 1/2, ‖wt‖ = 1/4

全部满足条件。

而且 t = 3/4 就位于 Qwen 自己给出的第二个窗口端点。

所以不能用这个例子宣布双窗口失败。

另外，Qwen Prop 4 对所有速度成正负配对的情形所作的进一步推广也不成立。

例如取：

V = {−1, 1, −7/5, 7/5}

旧总人数为五，门槛 1/5。

取：

t_a = 11/20

两个绝对速度的圆周距离分别为：

‖11/20‖ = 9/20, ‖(7/5)(11/20)‖ = 23/100

均安全。

但按速度 u = 1 的反射规则，选择 k = 1，得到：

t_b = 2 − 11/20 = 29/20

此时：

‖(7/5)(29/20)‖ = ‖203/100‖ = 3/100 < 1/5

所以新时间失败。

结论：即使每个速度都有正负配对，也不意味着关于任意一个速度的反射会保留全部约束。

Qwen Prop 4 只有对被选中的速度及其相反数的相位保持结论成立。
