## 1 · FPLC-2 限制了哪些算术结构（提取；PROOF CANDIDATE）

**(1a) 分离条件化为与缩放无关的形式**：由 τ₂ = (r/s)τ₁，可得 1/(rτ₁) = 1/(sτ₂)，于是
η₁ + η₂ ≤ 1/(rτ₁) ⇔ δ/(m₁τ₁) + δs/(m₂rτ₁) ≤ 1/(rτ₁) ⇔ **δ(r/m₁ + s/m₂) ≤ 1**。

结论：比例的分子、分母必须很小，满足 r ≤ m₁(1/δ) 且 s ≤ m₂(1/δ)。又由 m_i ≤ 1/δ − 1 = k+1，得 r, s < (k+1)(k+2)。

**(1b) 排除条件推出区间必须够长**：由 C − η ≥ U = 2δ/ℓ，得 ℓ ≥ 2δ/(C − η) > 2δ/C = **2δτ₁/s**。

所以证书要求：存在一个区间分量，其长度至少是"共同中心间距" C = s/τ₁ 所对应的扫描长度。

**(1c) 锁点的可得性**：τ 与 mτ 都要落在 S ⊂ [δ/a, (1−δ)/a] 中，所以 mτ ≤ (1−δ)/a，从而 τ ≤ (1−δ)/(ma)。锁点必须在首窗的前一部分，倍数 m 越大，可用的 τ 越少。

**(1d) 反射时间对与 LOCK 的关系**（按 A1 分别证明）：
- 设 H = 1/a。(τ, H − τ) 是反射时间对，(τ, mτ) 是 LOCK 对。**两者重合当且仅当 (m+1)τ = H**。证明：mτ = H − τ ⇔ (m+1)τ = H。∎
- PCL-T 中的 (1/(k+1), k/(k+1)) 正是 m = k、H = 1 时的重合情形；而 (1/(k+2), (k+1)/(k+2)) 是 m = k+1 时的重合情形。
- 与 PT-005 对跖结构的联系：IDEA，不作主张。

3. **共同中心间距**：可能的 (τ₁, τ₂) 及其比例为：

## 3 · 替代证书 2CC（双分量窗证书）

**定义**：对 S 中的一个分量 K = [L, R]（L ≤ R，允许孤立点），令 W_q(K) = ((q−δ)/L, (q+δ)/R)（左端 ≥ 右端时为空集），W(K) = ⋃_{q≥0} W_q(K)。

**引理 W（单分量窗的有限性；PROOF CANDIDATE）**：若 ℓ_K = R − L > 0，则 W_q(K) ≠ ∅ ⇔ q < δ(L+R)/ℓ_K。所以 W(K) 只有有限个窗口，并且 W(K) ⊂ (0, 2δ/ℓ_K)。

**证明**：
- (q−δ)/L < (q+δ)/R ⇔ q(R − L) < δ(L + R)。
- 若 uℓ_K ≥ 2δ，则 [uL, uR] 的长度 ≥ 2δ，装不进长为 2δ 的开带。∎

**定理 2CC-A（正确性；一般 k，任意实数）**：若 S 中有两个分量 K₁、K₂，其中至少一个有正长度，且
**W(K₁) ∩ W(K₂) ∩ (b, ∞) = ∅**，
则每个 u > b 都有首窗安全时间。

**证明**：
1. 若 u > b 在 K₁ 上没有安全点，则（同 FWB）[uL₁, uR₁] 整个落在某个不安全带中，所以 u ∈ W(K₁)。K₂ 同理。
2. 若两者都没有安全点，则 u ∈ W(K₁) ∩ W(K₂) ∩ (b, ∞) = ∅，矛盾。
3. 所以某个 K_i 上有安全点 t。t ∈ S ⊂ (0, H)，并且 u > b ≥ a，a 仍是最慢者，所以 t 在首窗内。∎

**选择器（问题 C）**：
1. 对 K₁ 计算 z = ⌈uL₁ − (1−δ)⌉。若 z ≤ ⌊uR₁ − δ⌋，输出 t = max{L₁, (z+δ)/u}。
2. 否则对 K₂ 做同样的计算并输出。

由定理 2CC-A，两步之中必有一步成功。区间公式来自主席首窗证书（Kimi 非作者 VERIFIED，未经主席认证，在此标注）。**至多 2 次检查**，与 u 无关。

**实例（手算）：(1, 3, 4)，K₁ = [2/5, 9/20]，K₂ = [11/20, 3/5]**：
- **K₁**：q < (1/5)(17/20)/(1/20) = 17/5，所以 q ∈ {0, 1, 2, 3}。窗口为 (0, 4/9)、(2, 8/3)、(9/2, 44/9)、(7, 64/9)。
- **K₂**：q < (1/5)(23/20)/(1/20) = 23/5，所以 q ∈ {0, …, 4}。窗口为 (0, 1/3)、(16/11, 2)、(36/11, 11/3)、(56/11, 16/3)、(76/11, 7)。
- **在 (4, ∞) 中**：
  - K₁ 的窗口为 (9/2, 44/9) ≈ (4.5, 4.889) 与 (7, 64/9)；
  - K₂ 的窗口为 (56/11, 16/3) ≈ (5.091, 5.333) 与 (76/11, 7)。
  - 第一对不相交；第二对的两个开区间在 7 处只是端点相接，也不相交。

所以 W(K₁) ∩ W(K₂) ∩ (4, ∞) = ∅。由 2CC-A，**对每个实数 u > 4，(1, 3, 4, u) 在 K₁ ∪ K₂ 中都有首窗解**。∎

**与锁的比较**：在这个例子里，锁只能把坏速度限制在 (19/4, 21/4) 附近；而两个**区间分量**的窗口错开，直接封死了全部 u > 4。也就是说，冲突来自两个分量的**长度与位置**（相当于两个"区间锁"），而不是倍数关系。
