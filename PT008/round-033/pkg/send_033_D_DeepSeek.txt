## 0 · C-INIT 与较弱目标的区别（按主席要求）
- **C-INIT**：B_δ(V) = (0, δ/R_max)。它涉及**所有** u > 0，包括比 a 还慢的 u。
- **较弱目标**：B_δ(V) ∩ (b, ∞) = ∅，只涉及按速度递增加入的 u > b。

逻辑关系：
- C-INIT ⇒ 较弱目标，因为 δ/R_max < a ≤ b（R031）。
- 反方向不成立。若出现一个 u ∈ (δ/R_max, b] 的坏速度，它推翻的是 C-INIT，**不**推翻较弱目标。本席不会把前者当作后者的反例。

## 1 · PROOF CANDIDATE：锁相引理 LOCK（一般 k，任意实数）

**陈述**：设 δ ∈ (0, ½)，S = S_δ(V) ∩ (0, H)。若 τ ∈ S 且 mτ ∈ S（m 为整数，m ≥ 2，(m+1)δ ≤ 1），则对每个坏速度 u ∈ B_δ(V)，都有
**‖uτ‖ < δ/m**。

**证明**：
1. u 是坏速度，所以 ‖uτ‖ < δ。写 uτ = M + θ，M ∈ ℤ，|θ| < δ。
2. u 是坏速度，所以 ‖muτ‖ < δ。而 muτ = mM + mθ，所以 ‖mθ‖ < δ。
3. |mθ| < mδ ≤ 1 − δ。对 |x| ≤ 1，有 ‖x‖ = min(|x|, 1 − |x|)。若 |mθ| ∈ [δ, 1−δ)，则 ‖mθ‖ ≥ δ，矛盾。所以 |mθ| < δ，即 |θ| < δ/m。∎

**相位冲突的含义**：一个点被遮住，只要求 u 的相位落在宽 2δ 的带里；而**一对**倍数点同时被遮住，要求相位落在宽 2δ/m 的窄带里。这是由安全集**内部**的乘法关系 (τ, mτ) 产生的约束。

**可推广性**：LOCK 只用到 τ、mτ ∈ S，**不依赖**特殊速度，对任意实数 V 都成立。

## 2 · PROOF CANDIDATE：定理 PCL-T（V = (1, …, k)，一切 k ≥ 2）

**设定**：V_k = (1, …, k)，δ = 1/(k+2)，a = 1，首窗 (0, 1)，J = [δ, 1−δ]。

**第 1 步（四个锁点与一个区间都在 S 中）**：
- τ = 1/(k+1) 与 kτ = k/(k+1)：每个 ‖v/(k+1)‖ ≥ 1/(k+1) > δ（v ≤ k），‖vk/(k+1)‖ 同理。
- τ′ = 1/(k+2) 与 (k+1)τ′ = (k+1)/(k+2)：对 v ≤ k，v 与 v(k+1) 都不是 k+2 的倍数，所以距离 ≥ 1/(k+2) = δ。
- 区间 I = [τ − h, τ + h]，h = 1/(k(k+1)(k+2))：‖vt‖ ≥ 1/(k+1) − k·h = 1/(k+2)；又 τ − h > δ（因为 1/(k+1) − 1/(k+2) = 1/((k+1)(k+2)) > h），所以 I ⊂ S。
- 这四个点都在 J 中，其中 (k+1)/(k+2) = 1 − δ 是 J 的右端点。

**第 2 步（两次锁相）**：用 LOCK，先取 (τ, m = k)，条件 (k+1)δ = (k+1)/(k+2) ≤ 1 成立；再取 (τ′, m′ = k+1)，条件 (k+2)δ = 1 ≤ 1 成立。得到：
u/(k+1) = M + θ，|θ| < δ/k = 1/(k(k+2))；u/(k+2) = M′ + θ′，|θ′| < 1/((k+1)(k+2))。

**第 3 步（中国剩余式冲突）**：由 u = (k+1)M + (k+1)θ = (k+2)M′ + (k+2)θ′，得
|(k+1)M − (k+2)M′| = |(k+2)θ′ − (k+1)θ| < 1/(k+1) + (k+1)/(k(k+2))。
- 当 k ≥ 2 时，右边 < 1。（k = 2 时为 1/3 + 3/8 = 17/24；对 k 递减。）
- 所以 (k+1)M = (k+2)M′。由于 gcd(k+1, k+2) = 1，M = (k+2)s，M′ = (k+1)s，s ∈ ℤ_{≥0}。
- 因此 **u ∈ ((k+1)(k+2)s − 1/(k+1), (k+1)(k+2)s + 1/(k+1))**，这里用的是 |ε| = |(k+2)θ′| < 1/(k+1)。

**第 4 步（区间封死 s ≥ 1）**：若 s ≥ 1，则 u > (k+1)(k+2) − 1/(k+1) > k(k+1)，于是 u·|I| = 2uh > 2k(k+1)·h = 2/(k+2) = 2δ。u 的相位在 I 上扫过一段长度 > 2δ 的闭弧，必有一点满足 ‖ut‖ ≥ δ，与"u 是坏速度"矛盾。

**第 5 步（结论）**：坏速度只能满足 s = 0，即 u < 1/(k+1)。反过来，R_max = 1 − δ = (k+1)/(k+2)，所以 δ/R_max = 1/(k+1)；对 u < 1/(k+1) 与一切 t ≤ R_max，都有 ut < δ，所以这些 u 都是坏速度。故
**B_δ(V_k) = (0, 1/(k+1)) = (0, δ/R_max)**。∎

**推论（对一切实数 u > 0，(1, …, k, u) 都有首窗解，门槛 1/(k+2)）**：
- **u ≥ 1/(k+1)**：u ∉ B，所以在 J ⊂ (0, 1) 中有解，而首窗 ⊇ (0, 1)。
  - **直接见证**：在 1/(k+1)、k/(k+1)、1/(k+2)、(k+1)/(k+2) 中取第一个满足 ‖ut‖ ≥ δ 的点；若都不满足，取 t = max{τ − h, (q + δ)/u}，其中 q = ⌈u(τ − h) − (1 − δ)⌉（主席的区间公式，未经主席认证，在此标注）。由第 2–4 步，二者必居其一。
- **u < 1/(k+1)**：u 是最慢者，首窗为 (0, 1/u)。取 t = 1/(k+1) + j，j = ⌈(δ − u/(k+1))/u⌉。整数平移不改变 1, …, k 的相位；而 u·t ∈ [δ, δ + u) ⊂ [δ, 1 − δ)，所以 u 安全，且 ut < 1，t 在首窗内。∎

**量词**：同一组 4 个点加 1 个区间，对**所有** u 都适用；不需要随 u 改换分量。

**依赖特殊速度的步骤**：
- 第 1 步：锁点 1/(k+1)、1/(k+2) 来自 V_k 的格结构；
- 第 3 步：gcd(k+1, k+2) = 1。

**可推广的步骤**：LOCK、"两次锁相 + 中国剩余"的冲突模式，以及"区间封死高速"。

## 3 · 一般化命题 PCL-2（作者陈述，供审）
**陈述**：设 S ⊇ {τ, mτ, τ′, m′τ′}（(m+1)δ ≤ 1，(m′+1)δ ≤ 1），并且 S 含有长度 ℓ > 0 的闭区间。令
Λ = { u ∈ (b, 2δ/ℓ) : ‖uτ‖ < δ/m 且 ‖uτ′‖ < δ/m′ }。
若 Λ = ∅，则 B_δ(V) ∩ (b, ∞) = ∅。

**证明**：由 LOCK，任何坏速度 u > b 都在 Λ 中，除非 u ≥ 2δ/ℓ；而后一种情形由区间扫描排除（与第 4 步相同）。∎

**特点**：
- 对任意实数 V 成立；
- Λ 是 u 轴上有限个开区间的交，可以精确计算；

## 4 · 失败的尝试（原样保留）
1. **只用两个锁点（不用区间）**：第 3 步之后，s ≥ 1 的窗口仍然存在，必须靠区间才能排除。仅凭点无法封死高速。
2. **起初误用单个"倍数对"跨不同的 τ**：曾试图用 1/(k+2) 与 k/(k+1) 构成一对，但它们不是同一个 τ 的倍数，LOCK 不适用。改用两个独立的锁之后才得到第 3 步。
3. **对一般 V，曾希望"τ = 1/(v+v′) 与 2τ 总同时安全"**：上述 30 组反例否定了"骨架上总有足够的锁"这一期望（指的是 PCL-2 的这一实现，不是 FW₄ 本身）。
