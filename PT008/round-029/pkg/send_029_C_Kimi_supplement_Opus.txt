## PROOF 1 · 引理 FW-SO（慢局外人接近最慢者；一般 k）

**陈述**：设 k ≥ 1，W 为 k 个正实数，最小者为 b；设 t₁ ∈ (0, 1/b)，且 W 在 t₁ 处全部 ≥ 1/(k+1)（即 W 的首窗见证）。设 0 < a < b 且 **a/b ≥ (k+1)/(k+2)**。则 t₁ ∈ (0, 1/a)，且 W ∪ {a} 在 t₁ 处全部 ≥ 1/(k+2)。所以 FW_{k+1}(W ∪ {a}) 成立，见证时间就是 t₁。

**证明**：
1. 由 0 < bt₁ < 1 与 ‖bt₁‖ ≥ 1/(k+1)，得 bt₁ ∈ [1/(k+1), k/(k+1)]。
2. 于是 at₁ = (a/b)·bt₁ ∈ [(a/b)/(k+1), (a/b)·k/(k+1)]。
   - 下界：(a/b)/(k+1) ≥ 1/(k+2) ⇔ a/b ≥ (k+1)/(k+2)，这正是假设。
   - 上界：(a/b)·k/(k+1) < k/(k+1) < (k+1)/(k+2)。
   - 所以 ‖at₁‖ ≥ 1/(k+2)。
3. W 中各速度 ≥ 1/(k+1) > 1/(k+2)。
4. t₁ < 1/b < 1/a。∎

**k = 3（FW₄）**：取 W = (b, c, d)，t₁ = T4(b, c, d)。由 FW₃，t₁ ∈ (0, 1/b)。条件为 a/b ≥ 4/5，即 **b ≤ 5a/4**。
