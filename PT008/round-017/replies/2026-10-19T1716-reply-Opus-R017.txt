# 【2】Track A · Cluster Extension

## 2.1 符号相位的精确区间（A1 的展开，PROOF CANDIDATE）
对任意 τ > 0，令 t = τ/(b+c)，则 at = τ/s，bt = τθ，ct = τ(1−θ)，dt = τw。t 成功当且仅当：
- **a**：τ ∈ s·⋃_{j≥0}[j + 1/5, j + 4/5]；
- **b**：τθ ∈ ⋃_j [j + 1/5, j + 4/5]；
- **c**：τ(1−θ) ∈ ⋃_j [j + 1/5, j + 4/5]；
- **d**：τw ∈ ⋃_j [j + 1/5, j + 4/5]。

τ 是整数时，b 的条件推出 c 的条件。τ 不是整数时，b、c 各自独立检查。

**解耦**：a 的条件只依赖 s；b、c、d 的条件只依赖簇形状 (θ, w)，与 s 无关。记**簇安全集**
**Σ(θ, w) = {τ > 0 : τθ, τ(1−θ), τw 的小数部分都在 A 内}**。
于是成功 ⟺ τ ∈ Σ(θ, w) 且 τ/s ∈ A + ℤ。这正是"先控制较快的簇，再让最慢者进入"的精确形式。

## 2.2 换锚 = 换相位格（PROOF CANDIDATE）
对任意两对 (p, q′) 与 (b, c)：t = τ′/(p + q′) = τ/(b+c) ⟺ **τ = τ′·(b+c)/(p+q′)**。
所以换锚点永远等价于换相位。两者的差别只在于**限制相位所在的格**：(b,d) 上的整数锁，等于 (b,c) 上相位格 ((b+c)/(b+d))·ℤ 的锁。
**V5**：(b+c)/(b+d) = (15/2)/10 = 3/4，所以 3/(b+d) = (9/4)/(b+c)，正是主席的发现。∎

## 2.3 定理 CLR：簇阶梯（PROOF CANDIDATE）
**数据**：
- 参考形状 (θ₀, w₀)；
- 相位步长 1/m（m ≥ 1 为整数）；
- 周期 Q ≥ 1，满足**周期性条件 (P)**：Qθ₀/m ∈ ℤ，且 Qw₀/m ∈ ℤ；
- 非空余数集 R ⊂ ℤ/Q；
- 余量 μ_bc, μ_d > 0，使得对每个 k mod Q ∈ R，在 τ = k/m 处：‖τθ₀‖, ‖τ(1−θ₀)‖ ≥ 1/5 + μ_bc，且 ‖τw₀‖ ≥ 1/5 + μ_d。
  （由 (P)，这些相位只依赖 k mod Q，所以只需逐个检查 R 中的有限个余数。）
- G = R 在 ℤ/Q 上的最大循环间隔（|R| = 1 时 G = Q）。

**规则**（闭式，不试整数）：
- k₀ = ⌈ms/5⌉；
- k = k₀ + min_{ρ∈R} ((ρ − k₀) mod Q)，即不小于 k₀、余数落在 R 中的最小整数，由查表得到，调整量 ≤ G − 1；
- **τ = k/m，t = τ/(b+c)**。

**结论**：若
- (i) s ≥ 5G/(3m)，
- (ii) |θ − θ₀| ≤ μ_bc/τ，
- (iii) |w − w₀| ≤ μ_d/τ，

则 t 成功。

**证明**：
- **a**：τ ≥ k₀/m ≥ s/5；τ < (ms/5 + 1 + G − 1)/m = s/5 + G/m ≤ 4s/5，由 (i)。所以 τ/s ∈ [1/5, 4/5]。
- **b**：τθ = τθ₀ + τ(θ − θ₀)，偏移 ≤ μ_bc；由 Lipschitz 性，‖τθ‖ ≥ 1/5。
- **c**：τ(1−θ) = τ(1−θ₀) − τ(θ − θ₀)，同理。
- **d**：τw = τw₀ + τ(w − w₀)，偏移 ≤ μ_d。
- t > 0。∎

**结构说明**：对固定的参考形状，**一条公式覆盖所有 s ≥ 5G/(3m)**，这是多个比例区域，不是单个盒子。形状容许半径为 μ/τ ≈ 5μ/s，随 s 变大而收窄，形成一根"尖管"。
