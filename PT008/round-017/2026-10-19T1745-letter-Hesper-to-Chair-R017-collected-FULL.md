## 2.1 符号相位的精确区间（A1 的展开，PROOF CANDIDATE）
对任意 τ > 0，令 t = τ/(b+c)，则 at = τ/s，bt = τθ，ct = τ(1−θ)，dt = τw。t 成功当且仅当：
- **a**：τ ∈ s·⋃_{j≥0}[j + 1/5, j + 4/5]；

## 第二部分：独立审阅 · LE（第二审）

### R1 · 精确假设

- $V = \{v_1, \ldots, v_k\}$，$0 < v_1 < \cdots < v_k$（有限个正实数）。
- $0 < \delta < 1/2$。
- $g(t) = \min_i \|v_i t\|$。$S = \{t > 0 : g(t) \ge \delta\}$。
- $S \neq \emptyset$。

### R2 · 完整证明核验

**(i) 分量结构：**

$g$ 连续（$\|v_i t\|$ 连续，有限个连续函数的最小值连续）。$S = g^{-1}([\delta, \infty))$ 在 $(0,\infty)$ 中闭。

有界性：$v_1 t = n$（$n \in \mathbb{Z}_{\ge 1}$）时 $\|v_1 t\| = 0 < \delta$，故 $t = n/v_1 \notin S$。每个分量夹在相邻两个 $n/v_1$、$(n+1)/v_1$ 之间，有界。

$\alpha > 0$：$t \to 0^+$ 时 $v_i t \to 0$，$\|v_i t\| \to 0 < \delta$。故 $(0, \varepsilon) \cap S = \emptyset$ 对某 $\varepsilon > 0$。✓

**(ii) 左端点：**

设 $[\alpha, \beta]$ 为一分量。取 $t_n \uparrow \alpha$，$t_n \notin S$。$g(t_n) < \delta$：$\exists\, i_n$ 使 $\|v_{i_n} t_n\| < \delta$。$V$ 有限，由鸽巢原理某 $v$ 出现无穷次。取子列：$\|v t_n\| < \delta$ 对所有 $n$。连续性：$\|v\alpha\| \le \delta$。又 $\alpha \in S$：$\|v\alpha\| \ge \delta$。故 $\|v\alpha\| = \delta$。

$\operatorname{frac}(v\alpha) = \delta$ 或 $1-\delta$。

若 $\operatorname{frac}(v\alpha) = 1-\delta$：对 $t$ 充分接近 $\alpha$ 且 $t < \alpha$：$vt < v\alpha$，$\operatorname{frac}(vt) < 1-\delta$（不跨整数），$\|vt\| = 1 - \operatorname{frac}(vt) > \delta$。这与 $\|vt_n\| < \delta$（$t_n \uparrow \alpha$）矛盾。

故 $\operatorname{frac}(v\alpha) = \delta$。$v\alpha = j + \delta$，$j = \lfloor v\alpha \rfloor \ge 0$。$\alpha = (j+\delta)/v = E^-(v,j)$。✓

**(iii) 右端点：** 对称。$\operatorname{frac}(u\beta) = 1-\delta$。$\beta = (j'+1-\delta)/u = E^+(u,j')$。✓

### R3 · 边界/退化情形

- 单点分量 $\alpha = \beta$：(ii) 给出 $v$ 下沿活跃，(iii) 给出 $u$ 上沿活跃。$u \neq v$（否则 $\delta = 1-\delta$，矛盾 $\delta \neq 1/2$）。→ LE-1。
- $\delta \to 0^+$ 或 $\delta \to 1/2^-$：证明不依赖 $\delta$ 的具体值（只需 $\delta \in (0,1/2)$）。✓

### R4 · 审阅结论

**PROOF VERIFIED。** 证明完备，拓扑论证正确，端点归属严格。

## 第三部分：独立审阅 · LE-1（第二审）

### R1 · 精确陈述

若 $t^*$ 是 $S$ 的**孤立点**（即 $\{t^*\}$ 是 $S$ 的一个连通分量），则：
- $\exists\, u \neq v$：$\operatorname{frac}(vt^*) = \delta$（$v$ 下沿活跃），$\operatorname{frac}(ut^*) = 1-\delta$（$u$ 上沿活跃）。
- $t^* = k/(u+v)$，$k = j_u + j_v + 1 \in \mathbb{Z}_{\ge 1}$。
- $\operatorname{frac}(ku/(u+v)) = 1-\delta$。

### R2 · 证明核验

由 LE：$t^* = \alpha = \beta$。

由 (ii)：$\exists\, v$，$vt^* = j_v + \delta$。
由 (iii)：$\exists\, u$，$ut^* = j_u + 1 - \delta$。

$u \neq v$：若 $u = v$，则 $\operatorname{frac}(vt^*) = \delta$ 且 $= 1-\delta$。$\delta = 1/2$，矛盾。✓

相加：$(u+v)t^* = j_v + \delta + j_u + 1 - \delta = j_u + j_v + 1 = k$。$t^* = k/(u+v)$。✓

$\operatorname{frac}(ku/(u+v)) = \operatorname{frac}(ut^*) = 1-\delta$。✓

### R3 · 关键区分（主席要求）

**LE-1 是孤立成功点的必要刻画，不是构造成功时间的充分条件。**

具体地：
- **必要：** 若 $t^*$ 是孤立成功点，则 $t^*$ 必为某对 $(u,v)$ 的锁相时间 $k/(u+v)$。✓（已证）
- **非充分：** 给定 $u, v, k$，$t^* = k/(u+v)$ 不一定是成功时间。还需验证**所有**跑者（不仅是 $u, v$）在 $t^*$ 处满足 $\|\cdot\| \ge \delta$。

例：$(a,b,c,d) = (1,2,3,4)$，$t^* = 1/(1+3) = 1/4$（$a,c$ 锁，$k=1$）。$\|a/4\| = 1/4$，$\|c/4\| = \|3/4\| = 1/4$。但 $\|b/4\| = 1/4$，$\|d/4\| = 1$。$\|d/4\| = 0 < 1/5$。✗ 不成功。

所以 LE-1 不能直接用于构造；它只说明孤立成功点的**形状**。

### R4 · 审阅结论

**PROOF VERIFIED**（作为必要刻画）。明确：不是充分构造条件。
