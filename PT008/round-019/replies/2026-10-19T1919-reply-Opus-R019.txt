## 1 定理 PS：周期平移（PROOF CANDIDATE）

### 1.1 陈述
**假设**：
- 0 < a < b < c < d；
- 存在 g > 0 与整数 0 < B < C < E，使 (b, c, d) = g(B, C, E)（簇可公度）。

令 P = 1/g，t₀ = F₄(b, c, d)，x = frac(aP)，φ₀ = frac(at₀)。

**选择器**（闭式，无搜索）：
- (S0) 若 φ₀ ∈ A：n = 0。
- (S1) 否则若 0 < x ≤ ½：n = ⌈frac(1/5 − φ₀)/x⌉（a 的相位向前移动）。
- (S2) 否则若 ½ < x < 1：令 y = 1 − x，n = ⌈frac(φ₀ − 4/5)/y⌉（a 的相位向后移动）。
- (E) 若 x = 0 且 φ₀ ∉ A：不适用（这就是例外集）。

输出 **t = t₀ + nP**。

**结论**：在 (S0)–(S2) 下，t > 0，且 ‖at‖, ‖bt‖, ‖ct‖, ‖dt‖ ≥ 1/5。

### 1.2 证明
- **b、c、d（相位精确不变）**：bP = B，cP = C，dP = E 都是整数，所以 u(t₀ + nP) ≡ ut₀ (mod 1)，u ∈ {b, c, d}。由 T4，三者距离都 ≥ 1/4 ≥ 1/5。
- **a**：at = at₀ + n·aP，所以 frac(at) = frac(φ₀ + nx)。
  - (S0)：n = 0，直接成立。
  - (S1)：令 Δ = frac(1/5 − φ₀) ∈ (0, 1)。由上整的定义，nx ∈ [Δ, Δ + x)，所以 φ₀ + nx ∈ [φ₀ + Δ, φ₀ + Δ + x)。而 φ₀ + Δ ≡ 1/5 (mod 1)，所以 frac(at) ∈ [1/5, 1/5 + x) ⊂ [1/5, 7/10) ⊂ A，因为 x ≤ ½。
  - (S2)：每走一步 P，a 的相位按模 1 减少 y < ½。令 Δ′ = frac(φ₀ − 4/5)，n·y ∈ [Δ′, Δ′ + y)，所以 frac(at) ∈ (4/5 − y, 4/5] ⊂ A。
- **正性**：n ≥ 0，t ≥ t₀ > 0。∎

**步数界**：φ₀ ∉ A 时 Δ, Δ′ < 2/5，所以 n < 2/(5e) + 1，其中 e = min(x, 1−x)。这个界**与 s 无关**，只取决于 a 相对周期 P 的相位步长。

### 1.3 例外集（精确）
**E_PS = {aP ∈ ℤ 且 frac(a·F₄(b,c,d)) ∉ A}**。此时 a 与簇的公度单位也可公度，平移不改变 a 的相位。
例：(1, 2, 3, 4)。g = 1，aP = 1，t₀ = F₄(2,3,4) = 1/8（T4 的 S1，因 4 ≤ 3·2），at₀ = 1/8 ∉ A，所以 PS 不适用。这一组由已认证的 TN 处理（d = 4a）。

## 2 推论 LS：相位格的确定性选择（PROOF CANDIDATE）

### 2.1 陈述（回答"保证安全余数集非空的充分判据"）
对任意有理参考形状，写成整数簇 0 < B < C < E（θ₀ = B/(B+C)，w₀ = E/(B+C)），令
- **τ* = (B + C)·F₄(B, C, E)**；
- **m = τ* 的分母**（化为最简分数）；
- **Q = m(B + C)**。

则：
- (P2) 成立：Q/m = B + C，Qθ₀/m = B，Qw₀/m = E，都是整数；
- 余数 ρ* = mτ* mod Q 属于安全余数集 R；
- 在 ρ* 处，三个余量 μ_b, μ_c, μ_d ≥ 1/4 − 1/5 = **1/20**。

所以 **CLR v2 的 R 永不为空，并且余量有不依赖 Q 的下界 1/20**。

### 2.2 证明
在 τ* 处，τ*θ₀ = B·F₄(B,C,E)，τ*(1−θ₀) = C·F₄(B,C,E)，τ*w₀ = E·F₄(B,C,E)。由 T4，这三个距离都 ≥ 1/4。
(P2) 由定义直接验证。对 k ≡ ρ* (mod Q)，由 CLR v2 引理 1，三个相位与 τ* 处相同。∎

### 2.3 "从整数格切换到分数格而不扫描分母"
m 由 T4 的分支**直接给出**。V5 形状 (B, C, E) = (1, 2, 3)：T4 的 S1（3 ≤ 3·1）给出 F₄ = 1/4，所以 τ* = 3·(1/4) = 3/4，**m = 4**。
这正是整数格失败、四分之一格成功的原因：T4 在这个形状上落在 S1，其输出的分母 4 决定了相位格。整个过程是一次计算，没有扫描 m = 1, 2, 3, …。

另两个形状（本席计算）：
- (3, 6, 8)（V4 形状）：S1（8 ≤ 9），F₄ = 1/12，τ* = 9/12 = 3/4，m = 4。
- (2, 5, 6)（主席反例的形状）：S1（6 ≤ 6），F₄ = 1/8，τ* = 7/8，m = 8。

**注**：Hesper 指出 V5 形状的最小可用分母是 m = 3。LS 给出的是一个**确定的、可证明的** m，不声称它最小。

### 2.4 LS 与 PS 的关系
- PS 用 a 的步长 x 选择平移步数，不需要 CLR v2 的条件 s ≥ 5G/(3m)。
- LS 把同一个参考相位放进 CLR v2 的余数框架；单余数时 G = Q，条件 (i) 为 s ≥ 5(B+C)/3。
- 两者覆盖的速度集可以不同，本席未求并集。

## 3 定理 APS：近似周期平移（PROOF CANDIDATE）

### 3.1 陈述
**假设**：0 < a < b < c < d，并给定参考整数 0 < B < C < E。令
- P = B/b（所以 bP = B 精确）；
- r_c = cP − C，r_d = dP − E（残差）；
- x = frac(aP)，e = min(x, 1−x) > 0。

用 PS 的选择器 (S0)–(S2)（t₀ = F₄(b,c,d) 取**真实**速度）算出 n。若
**n·|r_c| ≤ ‖ct₀‖ − 1/5，且 n·|r_d| ≤ ‖dt₀‖ − 1/5**，
则 t = t₀ + nP 成功。

**纯不等式的保证版本**：若
**(2/(5e) + 1)·max(|r_c|, |r_d|) ≤ 1/20**，
则判据自动成立（因为 n < 2/(5e) + 1，且由 T4，‖ct₀‖, ‖dt₀‖ ≥ 1/4）。

### 3.2 证明
- b：bP = B，相位不变，距离 ≥ 1/4。
- c：c(t₀ + nP) = ct₀ + nC + n·r_c，相位偏移 n·r_c；由判据与 Lipschitz 性，‖ct‖ ≥ 1/5。d 同理。
- a：与 PS 相同（只用到 x，不需要周期性）。
- t > 0。∎

### 3.3 V4 的开邻域
取 (B, C, E) = (3, 6, 8)。区域
**{ e = ‖3a/b‖ > 0，(2/(5e) + 1)·max(|3c/b − 6|, |3d/b − 8|) ≤ 1/20 }**
是开集，且包含 V4：e = 1/10，残差为 0。
在 V4 附近（e ≈ 1/10），条件约为 max(|c/b − 2|, |d/b − 8/3|) ≤ 1/300。

（自测：20,000 个满足保证版本的随机精确分数点（b 在 30 附近浮动，a/b ∈ [0.005, 0.33]），零失败。）

### 3.4 限制（必须写明）
半径 ∝ e/(2/5 + e)。当 a ≪ b 时，e ≈ Ba/b 很小，半径随之缩小。这与 CLR 的"尖管"现象相同，只是参数从 1/s 换成了 e。所以 APS 本身**不能**覆盖全部速度。

## 4 适用边界与剩余缺口
1. **PS**：覆盖全部可公度簇，即 (θ, w) 都是有理数，对一切 a 成立（例外集 E_PS 除外）。在 (s, θ, w) 空间中它是可数多条"线"，测度为零，不是开集。
2. **APS**：在可公度簇附近给出开区域，但半径受 e 限制。
3. **缺口：参考整数 (B, C, E) 的确定性选择**。对一般实数形状，需要同时满足"残差小"与"e 不太小"。前者要求 B 的分母大（逼近质量），后者取决于 ‖Ba/b‖，与 B 相互牵制。本席**没有证明**存在只依赖速度、闭式的 B 选择规则。——**UNFINISHED**
4. 无限制 F5：**UNFINISHED**。
