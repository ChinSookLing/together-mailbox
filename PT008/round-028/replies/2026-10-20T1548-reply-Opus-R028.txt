## Part I · FW₃ 的逐分支证明

**陈述（FW₃）**：对任意实数 0 < a < b < c，令 t = T4(a, b, c)（主席认证的八段构造，按附件给出的"T4 原式"顺序取第一个命中的分支）。则 0 < t < 1/a，且由 T4 的认证，‖at‖、‖bt‖、‖ct‖ ≥ 1/4。因此 S_{1/4}(a, b, c) ∩ (0, 1/a) ≠ ∅。

**先记录各分支的前提**：分支按顺序判定，所以到达某一分支时，前面各分支的条件都不成立。
- 到达 B2 之后：c > 3a；
- 到达 B3 之后：c > 3a，c < 3b；
- 到达 B4–B8 之后：c > 3a，c < 3b，b < 3a。

**B1**（c ≤ 3a）：t = 1/(4a)，所以 a·t = 1/4 < 1。✓

**B2**（c ≥ 3b，并且 c > 3a）：
1. **t₀ = F3(a, b)**：设 m = ⌈(a+b)/(3a)⌉，t₀ = m/(a+b)。由 m < (a+b)/(3a) + 1，得 a·t₀ < 1/3 + a/(a+b) < 1/3 + 1/2 = 5/6（因为 b > a，所以 a/(a+b) < 1/2）。若 T4 直接输出 t₀，即 B2a，则 a·t < 5/6。✓
2. **调整后的输出**（B2b，此时 nd(X) < 1/4，X = c·t₀）：令 k = ⌊X + ½⌋，e = X − k，则 |e| = nd(X) < 1/4。输出 t = (k + sg/4)/c，其中 sg = 1（e ≥ 0）或 −1（e < 0）。
   - e ≥ 0 时，t − t₀ = (1/4 − e)/c ∈ (0, 1/(4c)]；
   - e < 0 时，t − t₀ = −(1/4 + e)/c ∈ (−1/(4c), 0)。

   总之 t ≤ t₀ + 1/(4c)。又 c ≥ 3b > 3a，所以 a/(4c) < 1/12。于是 a·t < 5/6 + 1/12 = 11/12。✓

**B3**（b ≥ 3a，并且 3a < c < 3b）：θ = b/(b+c)，k₀ = ⌈(b+c)/(4a)⌉，x₀ = frac(k₀θ)；若 x₀ ∈ [1/4, 3/4] 则 j = 0，否则 j = ⌈Δ/θ⌉，Δ = frac(1/4 − x₀)。输出 t = (k₀ + j)/(b+c)。
1. **Δ < 1/2**：若 x₀ ∈ [0, 1/4)，Δ = 1/4 − x₀ ∈ (0, 1/4]；若 x₀ ∈ (3/4, 1)，Δ = 5/4 − x₀ ∈ (1/4, 1/2)。
2. 因此 j < Δ/θ + 1 < (b+c)/(2b) + 1；又 k₀ < (b+c)/(4a) + 1。
3. t < 1/(4a) + 1/(2b) + 2/(b+c)。由 b ≥ 3a，得 1/(2b) ≤ 1/(6a)；由 b ≥ 3a、c > 3a，得 b + c > 6a，所以 2/(b+c) < 1/(3a)。
4. 合计 a·t < 1/4 + 1/6 + 1/3 = 3/4。✓

**B4**（c/b ≤ 7/5）：t = 3/(b+c)。由 c > 3a 与 b > a，b + c > 4a，所以 a·t < 3/4。✓

**B5**（c/b ≥ 5/3，s ≤ 8）：t = 2/(b+c)，b + c > 4a，所以 a·t < 1/2。✓

**B6**（9/7 ≤ c/b ≤ 11/5，s ≥ 16/3）：t = 4/(b+c)，a·t = 4/s ≤ 4·3/16 = 3/4。✓

**B7**（c/b ≥ 13/7，s ≥ 20/3）：t = 5/(b+c)，a·t = 5/s ≤ 5·3/20 = 3/4。✓

**B8**（其余情形）：t = 3/(a+c)。由 c > 3a，a + c > 4a，所以 a·t < 3/4。✓

**正性**：每个分支的输出显然都 > 0（B2b 的输出 > 0 由 T4 的认证保证，因为它是一个安全时间）。∎

**推论**：对 k = 3，首窗时间可以直接用 T4 给出（**直接公式，不需要枚举**），并且 a·t < 11/12。

**失败的尝试（如实报告）**：本席起初只用 t₀ 的上界 5/6 处理 B2，后来发现调整步可能使 t 增大至多 1/(4c)，必须再用 c > 3a 才能得到 11/12。最终证明已包含这一步。

## Part II · 首窗能否逐层传递

### II-1 引理 FW-FO（快局外人保持首窗）
**陈述**：设 V 为 k 个正实数，t₀ ∈ (0, 1/v_min)，并且 V 在 t₀ 处全部 ≥ 1/(k+1)（旧层成功，且在首窗内）。设新速度 u ≥ (k+1)·v_max。令 t 为 FO（R022 第 7 项，取 n = k+1）的输出。则：
- t 对 V ∪ {u} 在 1/(k+2) 下安全；
- 0 < t < 1/v_min；
- v_min(V ∪ {u}) = v_min(V)。

所以 FW_{k+1}(V ∪ {u}) 成立，并且见证时间由公式直接给出。

**证明**：
1. 安全性与 t > 0：由 FO 与 H3（已有非作者审阅）。
2. 记 μ = 1/((k+1)(k+2))，δ′ = 1/(k+2)。FO 的平移量满足 |t − t₀| ≤ μ/v_max。
3. 假设 t ≥ 1/v_min。由于 t₀ < 1/v_min，有 1/v_min ≤ t < 1/v_min + μ/v_max，于是 ‖v_min t‖ ≤ v_min(t − 1/v_min) < μ·v_min/v_max ≤ μ < δ′，与安全性矛盾。所以 t < 1/v_min。
4. u > v_max，所以最慢的速度不变。∎

**推论**：FW₃（T4）配合 FW-FO，给出所有满足 d ≥ 4c 的 (a, b, c, d) 的首窗解。这正是已认证的 LN 区域，所以**不是新覆盖**。

### II-2 PS 不保持首窗（反例，手算）
V = (1, 4/3, 2, 4)。
- 簇 (4/3, 2, 4) = (2/3)·(2, 3, 6)，所以 g = 2/3，P = 3/2。
- t₀ = T4(4/3, 2, 4)：4 ≤ 3·(4/3) = 4，命中 B1，t₀ = 3/16。
- a = 1：φ₀ = 3/16 < 1/5；x = frac(3/2) = 1/2，进入 S1；j = ⌈(1/5 − 3/16)/(1/2)⌉ = ⌈1/40⌉ = 1。
- **PS 输出 t = 3/16 + 3/2 = 27/16 > 1 = 1/a**，四个距离为 5/16、1/4、3/8、1/4，都安全，但**不在首窗内**。
- 但首窗内另有解：**t = 1/3**。四个距离为 1/3；(4/3)(1/3) = 4/9，距离 4/9；2/3，距离 1/3；4/3，距离 1/3。FWS 在 (0, 1] 的 23 个候选中选出的正是 t = 1/3（本席代码，与手算一致）。

**结论**：PS 是一个合法的 F₅ 规则，但它**不传递**首窗性质。首窗性质要逐层传下去，就需要另外的选择方法（FWS 或 FW-FO）。

## Part III · FWS 完整文本（供 DeepSeek 第二次审阅）

**设定**：V 为 k 个两两不同的正实数；v_min = min V；δ = 1/(k+1)；C(V) 为 R026 的算术骨架。

**定义**：C₁(V) = C(V) ∩ (0, 1/v_min]；**F^{FW}(V) = min{ t ∈ C₁(V) : g_V(t) = max_{C₁(V)} g_V }**。

**FWS(i)（计数）**：|C₁(V)| ≤ Σ_{v<v′} ⌊(v+v′)/v_min⌋ + Σ_v ⌊v/v_min + ½⌋ ≤ kΣv/v_min + k/2（计重数）。

**证明**：
1. 第一类：j/(v+v′) ≤ 1/v_min ⇔ j ≤ (v+v′)/v_min。满足条件的正整数 j 有 ⌊(v+v′)/v_min⌋ 个。
2. 第二类：(2j+1)/(2v) ≤ 1/v_min ⇔ j ≤ v/v_min − ½。满足条件的非负整数 j 的个数为 max(0, ⌊v/v_min − ½⌋ + 1) ≤ ⌊v/v_min + ½⌋。
3. 求和并用 ⌊x⌋ ≤ x：
   - 第一类之和 ≤ Σ_{v<v′}(v+v′)/v_min = (k−1)Σv/v_min；
   - 第二类之和 ≤ Σv/v_min + k/2。
   - 相加得 kΣv/v_min + k/2。∎

（这个上界只依赖速度比，在缩放下不变。Kimi 的手算实例：V = {1, 2}，计数为 6，上界为 7。）

**FWS(ii)（选择）**：若 FW_k(V) 成立，即 S_δ(V) ∩ (0, 1/v_min) ≠ ∅，则 F^{FW}(V) ∈ S_δ(V)。

**证明**：
1. 取 t₀ ∈ S_δ(V) ∩ (0, 1/v_min)，K 为 S_δ(V) 中含 t₀ 的连通分量。
2. 由于 S_δ(V) ⊂ ⋃_{i≥0} [(i+δ)/v_min, (i+1−δ)/v_min]，而右边各区间互不相交且是闭区间，K 只能落在其中一个之内。因为 t₀ < 1/v_min，这个区间只能是 i = 0 的那一个，所以 K ⊂ [δ/v_min, (1−δ)/v_min] ⊂ (0, 1/v_min]。
3. 由 HS（主席内部认证），K ∩ C(V) ≠ ∅。取 c ∈ K ∩ C(V)，则 c ∈ C₁(V)，且 g_V(c) ≥ δ。
4. F^{FW} 在 C₁(V) 上取最大值，所以 g_V(F^{FW}) ≥ g_V(c) ≥ δ。∎

**FWS(iii)（计算量）**：需要 O(k·|C₁(V)|) 次比较。实数速度需要能精确判断 ‖vt‖ ≥ δ（例如有理或代数数速度）。

**FWS 的适用范围**：
- **k ≤ 3**：FW 已证（FW₁、FW₂，以及本轮的 FW₃），所以 FWS **无条件**成立。
- **k ≥ 4**：以 FW_k 为条件。
