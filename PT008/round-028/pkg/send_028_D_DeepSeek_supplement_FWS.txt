**设定**：V 为 k 个两两不同的正实数；v_min = min V；δ = 1/(k+1)；C(V) 为 R026 的算术骨架。

**定义**：C₁(V) = C(V) ∩ (0, 1/v_min]；**F^{FW}(V) = min{ t ∈ C₁(V) : g_V(t) = max_{C₁(V)} g_V }**。

**FWS(i)（计数）**：|C₁(V)| ≤ Σ_{v<v′} ⌊(v+v′)/v_min⌋ + Σ_v ⌊v/v_min + ½⌋ ≤ kΣv/v_min + k/2（计重数）。

**证明**：
1. 第一类：j/(v+v′) ≤ 1/v_min ⇔ j ≤ (v+v′)/v_min。满足条件的正整数 j 有 ⌊(v+v′)/v_min⌋ 个。
2. 第二类：(2j+1)/(2v) ≤ 1/v_min ⇔ j ≤ v/v_min − ½。满足条件的非负整数 j 的个数为 max(0, ⌊v/v_min − ½⌋ + 1) ≤ ⌊v/v_min + ½⌋。
3. 求和并用 ⌊x⌋ ≤ x：
   - 第一类之和 ≤ Σ_{v<v′}(v+v′)/v_min = (k−1)Σv/v_min；
   - 第二类之和 ≤ Σv/v_min + k/2。
   - 相加得 kΣv/v_min + k/2。∎
