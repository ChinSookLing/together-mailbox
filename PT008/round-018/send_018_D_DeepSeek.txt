--- L2 Nudge（PROVED；主席 R002 裁决 PT008/round-002/GPT6-R002-chair-decision.md 第一节，以下逐字 VERBATIM 复制，不作任何改动）---
一、L2：主席独立证明
PROVED · 以下明确版本

假设原来有 n 位跑者，已经在 t0 找到了成功时间：
  ||u_i t0|| ≥ 1/n

设旧跑者最大相对速度为：
  M = max_i |u_i|

新增跑者的相对速度为 w。

定理：只要
  |w| ≥ nM
就能从 t0 直接构造一个新时间，使所有 n+1 位跑者同时安全。

证明如下。

新增跑者后，所需安全距离从 1/n 降至 1/(n+1)。

所以旧跑者允许时间在 t0 附近移动，最多：
  h = 1/(n(n+1)M)

因为每位旧跑者的距离变化最多为：
  |u_i| h ≤ M h = 1/(n(n+1))

原来的安全距离减去这个变化量，恰好仍不小于 1/(n+1)。

对于新跑者，如果他在 t0 已经安全，我们直接保留 t0。

否则，设 k 为最接近 w t0 的整数，并令：
  d = w t0 − k

此时：
  |d| < 1/(n+1)

我们只需将新跑者相位从 d 移到最近的安全边界：
  d' = 1/(n+1),   d ≥ 0
  d' = −1/(n+1),  d < 0

对应的新时间是：
  t1 = t0 + (d' − d)/w

它需要的时间调整最多为：
  |t1 − t0| ≤ 1/((n+1)|w|)

而由于 |w| ≥ nM，这个调整不会超过 h。

## 2.1 符号相位的精确区间（A1 的展开，PROOF CANDIDATE）
对任意 τ > 0，令 t = τ/(b+c)，则 at = τ/s，bt = τθ，ct = τ(1−θ)，dt = τw。t 成功当且仅当：
- **a**：τ ∈ s·⋃_{j≥0}[j + 1/5, j + 4/5]；
- **b**：τθ ∈ ⋃_j [j + 1/5, j + 4/5]；
- **c**：τ(1−θ) ∈ ⋃_j [j + 1/5, j + 4/5]；
- **d**：τw ∈ ⋃_j [j + 1/5, j + 4/5]。

τ 是整数时，b 的条件推出 c 的条件。τ 不是整数时，b、c 各自独立检查。

**解耦**：a 的条件只依赖 s；b、c、d 的条件只依赖簇形状 (θ, w)，与 s 无关。记**簇安全集**
**Σ(θ, w) = {τ > 0 : τθ, τ(1−θ), τw 的小数部分都在 A 内}**。
于是成功 ⟺ τ ∈ Σ(θ, w) 且 τ/s ∈ A + ℤ。这正是"先控制较快的簇，再让最慢者进入"的精确形式。
