## 1 CLR v2（修正后的定理）

### 1.1 陈述
**数据**：
- 参考形状 θ₀ ∈ (0, ½)，w₀ > 0；
- 相位步长 1/m（m ≥ 1 为整数）；
- 周期 Q ≥ 1；
- 非空余数集 R ⊂ {0, 1, …, Q−1}，且 0 ∉ R。

**周期假设 (P2)**：**Q/m ∈ ℤ，Qθ₀/m ∈ ℤ，Qw₀/m ∈ ℤ。**
（等价地：Qθ₀/m、Q(1−θ₀)/m、Qw₀/m 均为整数。）

**参考余量**：对每个 ρ ∈ R，令 τ_ρ = ρ/m，要求
- ‖τ_ρ θ₀‖ ≥ 1/5 + μ_b
- ‖τ_ρ (1−θ₀)‖ ≥ 1/5 + μ_c
- ‖τ_ρ w₀‖ ≥ 1/5 + μ_d

其中 μ_b, μ_c, μ_d ≥ 0。

**间隔**：G = max_{ρ∈R} g(ρ)，其中 g(ρ) 是从 ρ 沿 ℤ/Q 前进到 R 中下一个元素的步数。|R| = 1 时 G = Q。

**规则**：k₀ = ⌈ms/5⌉，k = k₀ + min_{ρ∈R} ((ρ − k₀) mod Q)，**τ = k/m，t = τ/(b+c)**。

**结论**：若 0 < a < b < c < d，s = (b+c)/a，θ = b/(b+c)，w = d/(b+c)，并且满足
- (i) s ≥ 5G/(3m)
- (ii) τ·|θ − θ₀| ≤ min(μ_b, μ_c)
- (iii) τ·|w − w₀| ≤ μ_d

则 t > 0，且 ‖at‖, ‖bt‖, ‖ct‖, ‖dt‖ ≥ 1/5。

### 1.2 证明（第一原理）
**引理 1（三个坐标都周期）**：对整数 k 与 j，令 k′ = k + jQ。对 u ∈ {θ₀, 1−θ₀, w₀}，有 (k′/m)u = (k/m)u + j·(Qu/m)。由 (P2)，Qθ₀/m 与 Qw₀/m 是整数，且 Q(1−θ₀)/m = Q/m − Qθ₀/m 也是整数。所以三个相位的小数部分只依赖 k mod Q。∎

**引理 2（间隔界）**：调整量 δk = min_{ρ∈R} ((ρ − k₀) mod Q) ≤ G − 1。
证明：若 k₀ mod Q ∈ R，则 δk = 0。否则 k₀ mod Q 严格落在两个循环相邻的余数 ρ_i 与 ρ_{i+1} 之间，所以 δk = ((ρ_{i+1} − k₀) mod Q) ≤ g(ρ_i) − 1 ≤ G − 1。∎

**主证明**：
- **a**：τ = k/m ≥ k₀/m ≥ s/5。又 k₀ < ms/5 + 1，所以 k ≤ k₀ + G − 1 < ms/5 + G，τ < s/5 + G/m ≤ 4s/5，最后一步用到 (i)。所以 at = τ/s ∈ [1/5, 4/5)，‖at‖ ≥ 1/5。
- **b**：令 ρ = k mod Q ∈ R。由引理 1，frac((k/m)θ₀) = frac(τ_ρ θ₀)，所以 ‖τθ₀‖ ≥ 1/5 + μ_b。而 τθ = τθ₀ + τ(θ − θ₀)，由 (ii)，偏移 ≤ μ_b。由 Lipschitz 性，‖bt‖ = ‖τθ‖ ≥ 1/5。
- **c**：ct = τ(1−θ) = τ(1−θ₀) − τ(θ − θ₀)。由引理 1（**这里用到 Q/m ∈ ℤ**），‖τ(1−θ₀)‖ ≥ 1/5 + μ_c；偏移 ≤ μ_c，所以 ‖ct‖ ≥ 1/5。
- **d**：dt = τw₀ + τ(w − w₀)，同理，‖dt‖ ≥ 1/5。
- **正性**：τ ≥ s/5 > 0。∎

### 1.3 逐项检查
- **单余数情形** |R| = 1：G = Q，δk ≤ Q − 1，条件 (i) 为 s ≥ 5Q/(3m)。证明不变。
- **端点**：
  - (i) 取等号时，τ < s/5 + G/m = 4s/5 仍是严格不等式，合格。
  - (ii)(iii) 取等号时，偏移恰好等于余量，距离 ≥ 1/5，合格。
  - μ = 0 也允许，此时形状必须与参考形状完全相同。
- **三个坐标**：b、c、d 各用自己的余量。R017 的错误正是只检查了 b、d 的周期，c 的周期没有被保证。

## 2 周期假设能否放宽为"只对所选余数"？

**结论：不能**，原因如下。
- 证明中真正用到的是：对规则实际选出的每一个 k（它与 ρ ∈ R 同余，但 k 可以远大于 ρ），三个相位与参考点 ρ 相同。
- k − ρ = jQ，相位的变化是 j·(Qu/m)。只要某个坐标的 Qu/m ∉ ℤ，这个变化就是 j·frac(Qu/m)，**与 ρ 是哪个余数无关**，并且随 j（也就是随 s）累积。所以"对所选余数"的任何条件，都不能代替"对每个坐标"的周期条件。
- 主席的反例正是这种情形：ρ = 4 在参考点安全，但 c 的坐标 Q(1−θ₀)/m = 5/2 ∉ ℤ，k = 11（j = 1）就失败了。

**可以成立的放宽（PROOF CANDIDATE）：近似周期，s 有界**。
若对每个坐标 u，有 |Qu/m − n_u| ≤ η_u（n_u ∈ ℤ），则在规则选出的 k 处，相位的累积偏差 ≤ ⌊k/Q⌋·η_u < ((ms/5 + G)/Q)·η_u。只要
**((ms/5 + G)/Q)·η_u + τ·|形状偏差| ≤ μ_u**
对三个坐标都成立，证明照样成立。
- 这只对**有界**的 s 成立，因为左边随 s 增长。
- 它本质上等价于选一个更近的有理参考形状，所以不是新的机制。

## 3 研究问题：依赖速度的一般选择机制

**状态：UNFINISHED。** 下面是本席能给出的精确约化方向。

**IDEA（相位格连接不同簇形状）**：
1. 对任意实数形状 (θ, w)，由同时逼近（Dirichlet 型），存在分母 Q′ ≤ L 的有理形状 (θ₀, w₀) = (p/Q′, p′/Q′)，误差约为 L^{−1/2} 量级。
2. CLR v2 需要两件事：
   - (i) s ≥ 5G/(3m)，而 G ≤ Q；
   - (ii)(iii) 误差 × τ ≤ μ，而 τ ≈ s/5。
3. 两者兼容的前提，是对分母为 Q′ 的有理三速度簇 (Q′θ₀, Q′(1−θ₀), Q′w₀)，存在余量 **μ ≳ s·L^{−1/2}** 的安全余数。

**缺口**：本席**无法证明**有理簇必有这样大的余量。分母为 Q′ 时，相位是 1/(mQ′) 的倍数，安全余数的余量可以小到 0。所以这条链在第 3 步断开。这也正好指出了真正缺少的引理："有理三速度簇在门槛 1/5 下，存在余量不小于某个 c(Q) 的安全相位"，并且需要 c(Q) 下降得比逼近误差慢。
