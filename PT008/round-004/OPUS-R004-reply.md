## SECTION A — 数学推导

**A1 g 的结构。** 每个 d_a 连续、分段线性，斜率 ±a，转折点在 k/(2a)。在任意有界区间内，转折点只有有限个。不同 a 的两条线性分支斜率不同，最多相交一次，所以 g 在有界区间内也只有有限段，**每段斜率都属于 {±a}，从不为 0**。

**A2 单侧导数。** 设 Act(t) = {a : d_a(t) = g(t)}（活跃集，active set）。对足够小的 s > 0，不活跃的函数严格大于 g，于是
g′₊(t) = min_{a∈Act} d_a′₊(t)，g′₋(t) = max_{a∈Act} d_a′₋(t)。
（由 g(t±s) 在小 s 时等于活跃函数的最小值、各自线性展开直接得到。）

**A3 两类交点。** 上升分支：d_b(t) = bt − p，适用于 bt ∈ [p, p+½]。下降分支：d_a(t) = q − at，适用于 at ∈ [q−½, q]。
- **对向交点（opposite-slope）**：bt − p = q − at ⇒ **t = (p+q)/(a+b)**，交点值 **v = (bq − ap)/(a+b)**。
- **同向交点（same-slope）**：bt − p = at − p′ ⇒ t = (p−p′)/(b−a)。差型分母。

## SECTION B — 证明或反例

### B1 定理 T1′（局部极大点的完整刻画）—— PROOF CANDIDATE

t* > 0 是 g 的局部极大点，**当且仅当**存在 a, b ∈ A（允许 a = b）与整数 p, q，满足：
1. t* = (p+q)/(a+b)；
2. bt* − p ∈ (0, ½]，且 q − at* ∈ (0, ½]（两条分支在 t* 处确实分别是上升分支、下降分支）；
3. 对所有 e ∈ A：‖et*‖ ≥ v = (bq − ap)/(a+b)（两条分支都在下包络上）。

此时 g(t*) = v，且 t* 是**严格**局部极大点。

**证明（⇐）**：由 2 和 3，d_b、d_a 都活跃。d_b 左斜率 = +b，d_a 右斜率 = −a。由 A2，g′₋(t*) ≥ b > 0，g′₊(t*) ≤ −a < 0，所以是严格局部极大。
**证明（⇒）**：设 t* 是局部极大点。
(i) g(t*) > 0：d_a 的零点是离散的，g 不可能在一个邻域内恒为 0。
(ii) 由 A1，g 没有水平段，所以 g′₋(t*) > 0 且 g′₊(t*) < 0。
(iii) 由 A2，存在活跃的 b，其左斜率为 +b，即 bt* ∈ (p, p+½]；也存在活跃的 a，其右斜率为 −a，即 at* ∈ [q−½, q)。
(iv) 两者都活跃，所以 bt* − p = g(t*) = q − at*，得到 1；值 v 由 A3 给出；条件 3 就是活跃性。∎

**退化情况逐一检查**
- **负速度**：d_u = d_{|u|}。✅
- **u 与 −u 同在 V 中**：两者在 A 中合并，函数相同。✅
- **a = b（峰顶，A 类）**：只有 p = k、q = k+1 满足条件 2，得 t* = (2k+1)/(2a)，v = ½。✅
- **斜率相同的不同分支**：只可能来自同一个 a，属于同一个函数，不会出现"重合分支"。✅
- **端点 t = 0**：g(0) = 0，且 g 在 0 右侧递增，所以 t = 0 是全局极小，不是极大。✅
- **有界区间 [T₀, T₁] 的端点**：g 在该区间上的最大值 = max{g(T₀), g(T₁), 区间内满足 T1′ 的点}。**端点不能漏掉**，它们不一定是 T1′ 点。

### B2 推论：存在性 ⇒ 临界时间 —— PROOF CANDIDATE
若 S_δ = {t ≥ 0 : g(t) ≥ δ} 非空（δ > 0），则 S_δ 中含有一个 T1′ 点。
证明：取 t₀ ∈ S_δ，K 为 {g ≥ δ} 中含 t₀ 的连通分量。因 g(k/a) = 0，K 是紧区间。g 在 K 上的最大点 t*：若 t* 在 K 内部，它是局部极大点；若 t* 是 K 的端点，则 max = δ，于是 g 在 K 上恒等于 δ。由于 g 没有水平段，K 只能是单点，而单点的分量本身就是局部极大点。∎

### B3 反例：B 类（‖ut‖ = ‖vt‖）不等于局部极大 —— DISPROVED（"所有分支交点都是极大点"）
V = {1,2,3}，t = 1/3：‖1/3‖ = 1/3，‖2/3‖ = 1/3，两者相等（d_1 上升、d_2 下降，是对向交点）。
但 ‖3·(1/3)‖ = ‖1‖ = 0，所以 g(1/3) = 0。这个交点不在下包络上，违反 T1′ 条件 3。
同向交点（差型 (p−p′)/(b−a)）在两个上升分支交汇处，g 的两侧斜率同号，**永远不是**局部极大。
**修正**：Round 003 提案中写的"k/(uᵢ ± uⱼ)"应改为**只有和型** c/(|uᵢ| + |uⱼ|)。

### B4 反例：实数速度下最优时间可能不存在 —— DISPROVED（"F = argmax g 有定义"）
V = {1, √2}。
- g(t) = ½ 需要 t = k + ½ 且 √2·t = j + ½，于是 √2 = (2j+1)/(2k+1) 为有理数，矛盾。所以 g(t) < ½ 对所有 t 成立。
- 由 Kronecker 定理（经典结果，WEB OFF 未重新查证），(t, √2t) mod 1 在环面上稠密，所以 sup g = ½。
结论：sup 达不到，**"最优时间"不存在**。统一公式只能要求 g(F(V)) ≥ 1/n，不能要求 F 是最优解。

### B5 定理：三跑者的显式公式（m = 2）—— PROOF CANDIDATE
设 A = {a, b}，0 < a < b。令
**c = ⌈(a+b)/(3a)⌉，F(V) = c/(a+b)。**
则 ‖aF‖ = ‖bF‖ ≥ 1/3。（若 A 只有一个元素，F = 1/(2a)。）

证明：
1. aF + bF = c ∈ ℤ，所以 bF ≡ −aF (mod 1)，‖aF‖ = ‖bF‖。（这正是 T1′ 的对向交点结构。）
2. 令 θ = a/(a+b) ∈ (0, ½)。则 aF = cθ。
3. 由取上整的定义：c ≥ (a+b)/(3a) = 1/(3θ)，所以 cθ ≥ 1/3；且 c < 1/(3θ) + 1，所以 cθ < 1/3 + θ < 1/3 + ½ = 5/6。

还需要 cθ ≤ 2/3。分两种情况：
- 若 c = 1：cθ = θ < ½。✓
- 若 c ≥ 2：则 (c−1)θ < 1/3（否则 c 不是最小的满足条件的整数），所以 cθ < 1/3 + θ。又 c ≥ 2 推出 1/(3θ) > 1，即 θ < 1/3，所以 cθ < 2/3。✓

因此 cθ ∈ [1/3, 2/3]，‖cθ‖ ≥ 1/3。∎

**展示计算**：
- {1,2}：c = ⌈3/3⌉ = 1，t = 1/3，‖1/3‖ = ‖2/3‖ = 1/3。✓
- {1,3}：c = ⌈4/3⌉ = 2，t = 2/4 = 1/2，‖1/2‖ = ‖3/2‖ = 1/2。✓
- {1,4}：c = ⌈5/3⌉ = 2，t = 2/5，‖2/5‖ = 2/5，‖8/5‖ = 2/5 ≥ 1/3。✓（R003 提案中 c=1 失败的反例，这里被公式直接解决）
