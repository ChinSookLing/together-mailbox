SETUP. A configuration k = 8 footprints (c_i, v_i): c_i even in Z/32, v_i odd in 1..15 (v ~ -v). It is a doublable exact 2-cover: the sets U_i = c_i + {±v_i, ±3v_i} cover every odd residue mod 32 exactly twice. Mixed = strides not all in {1,7} mod 8 and not all in {3,5} mod 8. There are 7,168 mixed doublable configurations.
Level parity beta in {0,1}. Put h_i = c_i/2 mod 16. Each runner gives a DOMINO of two residues of parity beta+1:
- Type I (h_i ≡ beta mod 2): {h_i - v_i, h_i + v_i}
- Type II (h_i ≢ beta mod 2): {h_i, h_i + 2·eps_i·v_i}, eps_i = ±1 free.
R16(k, beta): some choice of the eps_i makes the 8 dominoes mod 16 cover each of the 8 residues of parity beta+1 exactly twice.
PROVED: every real exact k=5 tiling satisfies R16, and R16 holds on exactly the 640 realized configurations (5 affine orbits). Affine group: (c,v) -> (a c + 2t, a v), a odd. Translation tau_t: c -> c + 2t (so h -> h + t).
PROVED by hand: R16(tau_t k, beta) = R16(k, beta + t mod 2), and R16(a·k, beta) = R16(k, beta).
CHECKED only (exhaustive, two solvers): R16(k,0) = R16(k,1) for all 7,168 k.
