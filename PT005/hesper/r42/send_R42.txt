R16(k,beta): Type I runner (h_i ≡ beta mod 2) gives domino {h_i - v_i, h_i + v_i}; Type II runner gives {h_i, h_i + 2 eps_i v_i}, eps_i = ±1 free; some eps-choice covers each residue of V_beta exactly twice.

NEW REFORMULATION (immediate from the definition). Every Type II runner always covers its anchor h_i; its only freedom is h_i + 2v_i versus h_i - 2v_i. So let
 fixed_beta(r) = #(Type I dominoes containing r) + #(Type II anchors h_i = r), d(r) = 2 - fixed_beta(r) on V_beta,
 G_beta(k) = multigraph on V_beta with one edge {h_i + 2v_i, h_i - 2v_i} per Type II runner.
Then R16(k,beta) ⇔ d ≥ 0 and G_beta can be ORIENTED so each vertex r has in-degree d(r) (each edge points to the end it covers). By Hakimi's theorem: ⇔ d ≥ 0, |E(G)| = Σd, and e(S) ≤ d(S) for every vertex set S.

TRANSLATION tau_1 at the SAME beta flips every runner's type. So G_beta(tau_1 k) has one edge {h_i + 1 ± 2v_i} for each runner that was Type I in k, and its fixed counts come from {h_i + 1 ± v_i} (old Type II) plus anchors h_i + 1 (old Type I).
