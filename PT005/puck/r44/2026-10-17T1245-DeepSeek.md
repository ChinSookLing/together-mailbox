## Updated assumption list for the F3 lemma

1. **FACT — Fact C scope.** Fact C applies to non-frozen coordinates \(w=2^k j\). It must not be applied blindly to deep coordinates with \(v_2(w)<k\).

2. **FACT — Fact C count.** The number of covering residues is \(2\lfloor(p-1)/16\rfloor+1\). It varies with \(p\); assuming 3 is wrong for larger \(p\).

3. **IDEA — parent vs child coverage.** Parent improperness covers \(T=1,\dots,M/2\); child improperness needs \(T=1,\dots,M\). A proof must cover the new half-range, not inherit it.

4. **IDEA — odd/even \(T\).** Fact C concerns odd \(T\). Even \(T\) must be handled separately or by a valid reduction.

5. **PROOF — odd coordinates persist.** Since \(M\) is even, adding \(M\) preserves parity. Thus the “at least two odd coordinates” condition is automatic under lifting.

6. **PROOF — depth monotonicity is partial.** For \(v_2(w)<k\), adding \(M\) preserves \(v_2\), so depth grows by 1. For \(v_2(w)\ge k\), child depth can be 0 or 1, never \(\ge3\). So \(F3(\text{child})=F2(\text{parent})\) is safe, but “all depths grow by 1” is not.

7. **PROOF — distinctness.** Lifting \(w_i\mapsto w_i\) or \(w_i+M\) preserves distinctness of the 15 coordinates. This should be stated if \(F3\) is counted after lifting.

8. **PROOF — old L7 divisors.** If \(D\mid M\), then \(w_i+M\equiv w_i\pmod D\), so \(E_D\) and \(g_i=\gcd(D,w_i)\) are unchanged. Old \(D\)'s L7 status is lift-invariant.

9. **IDEA/GAP — new L7 divisors.** For \(D'\mid 2M\) with \(D'\nmid M\), invariance can fail. A proof must check these separately; ignoring them is a GAP.

10. **PROOF — \(D=2\) cannot close an improper node.** For \(D=2\), \(g_i=1\) for odd \(w_i\), and \(\lceil(2/1)/8\rceil=1\). The sum is the number of odd coordinates, at least 2, so it is not \(<2\). Thus \(D=2\) is never an L7 witness for an improper node.

11. **IDEA — open child needs both conditions.** To rule out an open child, one must rule out either improperness or non-L7-closure. Proving only coverage or only L7 is insufficient.

12. **IDEA — \(F3\ge9\) forces \(k\ge3\).** For \(k<3\), \(F3=0\). A proof may silently assume \(k\ge3\); it should state it.

13. **IDEA — corollary uses only \(F1\) coordinates.** \(F1\ge9\) means \(v_2(w)<k\), so those nine coordinates gain depth under lifting; at \(4M\) they contribute \(F3\ge9\). This is safe, but it depends on the partial monotonicity in item 6.

14. **IDEA — no p=17 transfer.** The \(p=17\) witnesses disprove the all-\(p\) version. They cannot be used as evidence for \(p\ge19\), and the \(p=17\) tree computation K11 is separate.

15. **IDEA — data is not proof.** Puck’s 42,572 open nodes with no \(F3\ge3\) open child for \(p\ge19\), and the \(p=47,53,59,61\) tables, are evidence only. The lemma must be proved uniformly or by valid case splits over \(p\).
