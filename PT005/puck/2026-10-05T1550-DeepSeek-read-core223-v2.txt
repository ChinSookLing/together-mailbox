(A) Unit-orbit argument — HOLDS.
The CRT choice b ≡ a^{-1} mod p, b ≡ 1 mod 16 exists. Since b is odd and coprime to 16p, multiplication by b permutes the time grid T mod 16p, so good/improper witnesses map bijectively. (B) Forced-family lemma — HOLDS.
For p | T, w_i = 16u_i gives w_i T/(16p) = u_i T/p integer, so distance 0 and bad. For p ∤ T, w_i T/(16p) = u_i T/p, and since w_i ≡ s_i mod p, this is exactly the condition that class s_i covers time class 16^{-1}T. If Z covers all nonzero time classes, some i ∈ Z is bad for every T. No gap found.
Caveat: the reverse statement ("only forced families survive") is explicitly marked as an observation/open bridge, not proved by this lemma; the verdict above is only for the forced-family lemma itself.
