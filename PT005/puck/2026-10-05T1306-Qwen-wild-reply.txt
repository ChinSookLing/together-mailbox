[IDEA] The constant 496,000 is not a row-count accident. It is:

    improper lifts = local multiplier × pairwise collision count

where the pairwise collision count is the number of unordered pairs of core-speed covering copies that land on the same time class.

Define, for a core C, the covering multiplicity

    m_C(x) = number of speeds in C whose shifted bad-shape covers time class x.

Then define the collision number

    K(C) = Σ_x C(m_C(x), 2).

The claim is:

    K(C) = C(32, 2) = 496

for every one of the 65 small cores, after removing any universal contribution such as the zero time class. The remaining local lift multiplicity is

    L = 1000,

so

    improper lifts = 1000 × 496 = 496,000.

[IDEA] Geometric picture:

```
continuous circle:
    runner 1: forbidden arc with endpoints e1, e2
    runner 2: forbidden arc with endpoints e3, e4
    ...
    16 runners -> 32 endpoints -> C(32,2) endpoint pairs

discrete log picture at p=223:
    each speed = shifted copy of the same bad shape S
    a collision = two shifted copies cover the same time class
    collision <-> endpoint-pair witness
```

The 65 cores look different as sets of speeds, but in the discrete-log picture they are shifted or re-labelled copies of the same overlap pattern. Therefore they have the same K(C).

[IDEA] The enumeration-free replacement is to compute K(C) instead of checking lifts.

Let G = Z/(p−1) = Z/222 for the nonzero time classes in discrete-log order. Let S ⊂ G be the bad shape in log coordinates. For a core C ⊂ G with |C| = 13,

    m_C = 1_C * 1_S

is the covering multiplicity function.

Then exactly:

    K(C) = Σ_x C(m_C(x),2)
         = 1/2 ( Σ_x m_C(x)^2 − Σ_x m_C(x) ).

Also, by autocorrelation,

    Σ_x m_C(x)^2 = Σ_d μ_C(d) A_S(d),

where

    μ_C(d) = #{(a,b) ∈ C×C : a − b = d}

and

    A_S(d) = |S ∩ (S + d)|.

So

    K(C) = 1/2 ( Σ_d μ_C(d) A_S(d) − |C||S| ).

[FACT, algebra] This formula is exact once S and C are fixed.

[IDEA] The 65 cores likely have the same weighted difference multiset μ_C on the support of A_S, or at least the same weighted sum Σ μ_C(d)A_S(d). That is why every core gives the same improper-lift count.

[IDEA] The factor 1000 is not the deep part. It is the local number of forbidden lift states attached to one collision witness. It may factor as 2^3·5^3, suggesting three binary and three quinary local constraints, but that part is optional. The main invariant is K(C) = 496.
